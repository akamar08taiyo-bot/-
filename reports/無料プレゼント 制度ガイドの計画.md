# 無料プレゼント「制度ガイド」の計画（先の計画）

（前提）作った日：2026年10月5日。**試作を作りました**：プレビュー https://claude.ai/artifact/6n3arH81sbf5GmaoSQbHaq ／ソースは `prototypes/制度ガイド/`。入口のページには「動画で見る」も足しました（偉人編の5本を制度ごとの短い動画19本に分け、「いつの制度か」と「だれ向けか」で選んで、その場で再生できる）。ユーザーの希望「無料プレゼントの中に、制度改正のまとめ、助成金制度の一覧、自分で選んでいくと『あなたはこの制度が向いています』と出る簡単なアプリを入れたい（先の計画でよい）」を、作る順番と中身に落としたものです。まだ作っていません。制度の中身は、偉人編の台本づくりで調べた内容を `reports/制度データ 2026-10.json` にまとめてあり、3つのプレゼントで同じデータを使います。

## 結論

- **3つとも同じデータから作る**：制度ごとに「いつから・だれに関係・いくら・やること・損するポイント・出典・決まった度合い（決定／法案／検討中）」を1行ずつ持つ。動画の台本も同じデータから数字を取るので、数字がずれない。
- **作る順番**：①制度改正まとめ → ②「あなたに合う制度」診断 → ③助成金・給付金の一覧。①はもう調べた内容でほぼ書ける。②は①のデータに質問をつけるだけ。③は市区町村ごとに違う制度が多く、いちばん手間がかかる。
- **置き場所**：「おかねの地図」の無料プレゼント（いまのPDFガイド・逆算アプリ・証券会社えらび・申し込みサポートの並び）に足す。動画の締め「プロフィールのリンクから」の先がそのまま入口になる。

## 3つのプレゼント

### ① 制度改正まとめ（2026年11月〜2027年度）

- **形**：スマホで読む1ページ（Web）と、保存用のPDF。いまの特典PDFと同じ見た目にそろえる。
- **並べ方**：時期順（11〜12月／1〜3月／2027年4月〜）。各制度に「決定」「法案」「検討中」の札をつけ、法案のものは成立したら札を変える。
- **1つの制度に書くこと**：いつから／だれに関係／いくら／やること（手続きの有無と期限）／知らないと損するポイント／出典リンク。
- **最初に入れる候補（データにある22件から）**：12月の所得税の精算、iDeCoの上限アップ、こどもNISA、OTC類似薬の負担増、食料品の消費税1%（法案）、就業者負担軽減支援金（法案）、高額療養費、子ども・子育て支援金、パートの社会保険、住民税がかからない年収、介護保険の2割負担（検討中）など。
- **動画とのつながり**：改正編1・2の説明文に「まとめはプロフィールのリンクから」。動画で言いきれない条件（企業年金がある人のiDeCo、地域で違う住民税など）をここで補う。

### ② 「あなたに合う制度」診断（簡単なアプリ）

- **流れ**：質問に答える（5〜7問・全部タップだけ）→「あなたに関係する制度」が多い順に出る→それぞれ「やること」と期限→最後に「損しないチェックリスト」を保存。
- **質問の案**：
  1. 働き方（会社員・公務員／パート・アルバイト／自営業・フリーランス／年金生活／働いていない）
  2. 会社に企業年金（DB・企業型DC）があるか（会社員だけ。わからないも選べる）
  3. 子どもはいるか（0〜17歳／19〜22歳の学生／いない）
  4. 親の介護をしている・しそうか
  5. よく通院する・薬を使うか
  6. 今年、仕事を辞めた・変えたか（年末調整がない人を見つける）
  7. 公金受取口座を登録しているか（わからないも選べる）
- **結果の出し方**：データの `who` の札と答えを照らし合わせる。「法案」「検討中」の制度は「決まったらお知らせ」の欄に分ける。
- **守ること**：答えは端末の中だけで使い、どこにも送らない（名前・年収の金額・住所は聞かない）。「目安です。手続きの前に窓口で確かめてください」を毎回出す。個別の会社や商品の名前は出さない（いまの特典と同じ決まり）。
- **作り方**：いまの逆算アプリ（goal.html）・証券会社えらび（choose.html）と同じ作り（1つのHTMLとJS、外のサービスを使わない）。データはJSONなので、制度が変わったらJSONを直すだけで済む。

### ③ 助成金・給付金の一覧（だれ向け別）

- **分け方**：会社員／パート・アルバイト／自営業・フリーランス／子育て／年金生活／親の介護／住まい。
- **国の制度**（全国共通）は、データにある年金生活者支援給付金・介護保険の住宅改修・高額療養費・iDeCo・こどもNISAなどから始め、骨組みの回（付加年金・特定福祉用具購入・企業型DCの移換など）を確かめながら足す。
- **市区町村の制度**（地域で違う）は、一覧にせず「調べ方」をのせる：市区町村のサイトでの探し方、窓口で聞くこと、期限の見方。全国の自治体の一覧を作ると、確かめきれず古くなるため。
- **注意**：「誰でももらえる」と書かない（条件を必ず書く）。手数料やセミナーが要る話は扱わない、と一言入れる。

## データの持ち方（`reports/制度データ 2026-10.json`）

| 項目 | 中身 | 使う場所 |
|---|---|---|
| name・category | 制度の名前と分類（税金・医療・社会保険など） | ①の見出し、③の分類 |
| start・end | 始まる月（終わる月） | ①の時期順、②の「期限」 |
| status | 決定／法案／検討中／要確認 | ①の札、②の分け方 |
| who | 関係する人の札（会社員・パート・自営業・年金・子育て・介護・通院など） | ②の照らし合わせ、③の分類 |
| amount・action・loss | いくら・やること・損するポイント | ①②③の本文、動画の台本 |
| sources | 出典リンク | ①③の出典、確かめ直し |
| video | 使った動画（改正編1・制度編5など） | 動画とプレゼントの行き来 |

## 直すタイミング

- **法案が決まったとき**：食料品の消費税1%・就業者負担軽減支援金（臨時国会は2026年12月12日までの予定）。
- **12月の税制改正大綱**（2027年度の改正が出る）と、**年度替わり**（4月）。
- **介護保険の2割負担**の結論（年末の予定）。
- 直したら、改正編の動画の説明文と台本帳の数字も合わせる。
- 改正編2を作り直したら、短い動画（2位・1位など）も切り直す（`prototypes/制度ガイド/動画づくり/` の手順）。
