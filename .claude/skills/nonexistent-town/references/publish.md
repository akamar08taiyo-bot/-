# タイトル・概要欄・投稿の設定

## タイトル（3 案出して選んでもらう）
- 町名を必ず入れる。30 字前後まで。煽り（衝撃・閲覧注意など）や、実在と誤解させる言い方（「実在した」「本当にあった」）はしない
- 型の例：
  - `【存在しない街】凪ヶ浦町の記憶 ― 一九八九年 夏の終わり`
  - `知らないのに懐かしい町、凪ヶ浦町`
  - `存在しない町の、最後の夏休み｜凪ヶ浦町 #003`
- 参考動画・同じジャンルの人気動画のタイトルをそのまま型にしない（言い回しをまねない）

## 概要欄（`out/<id>_概要欄.txt`）
```
存在しない町「凪ヶ浦町（なぎがうらちょう）」の、ある夏の終わりの記憶。
（2〜3 行：この回の芯を、ネタばらしせずに）

※この町は実在しません。登場する町・場所・出来事はすべて架空です。
※映像・語り・音楽は AI（画像：Gemini、語り：Gemini TTS、音楽：Lyria）で生成し、編集して制作しています。
（BGM・効果音に外部素材を使った回は、ここに素材名とクレジット）

00:00 （チャプター：語りや区切りがある回だけ。最初は 00:00、3 つ以上、各 10 秒以上）

#存在しない街の記憶 #架空の街 #存在しない記憶 #ノスタルジー #<時代：昭和レトロ／平成レトロ>
```
- ハッシュタグは 3〜5 個。関係ないタグ・実在の地名のタグは付けない
- チャプターは render の `out/<id>_check/timeline.json` の場面の時刻から作る

## YouTube Studio での設定（ユーザーに伝える）
- **改変または合成されたコンテンツ**：写真のように本物らしい画や声を AI で作った回は「はい」。実在しない町を本物の記録映像のように見せる内容なので、開示しておくのが安全（ラベルが付いても、それだけで表示回数や収益が下がるものではないとされている）
- **子ども向け**：「いいえ」（子ども向けに作っていないため）
- 字幕：`out/<id>.srt` があればアップロード（日本語）
- サムネイル：`out/thumb.jpg`（1280×720・2MB 以下）
- 再生リストに「存在しない街の記憶」をまとめる。ショートは本編と同じ町名を入れ、関連動画に本編を指定する

## 量産・繰り返しに見せない（収益化のルール）
YouTube パートナープログラムでは、大量生産・繰り返しのような内容（ほぼ同じ作りの動画の連投、素材の使い回しだけの動画など）は収益化の対象外になる。次を守る：
- 毎回ちがう街・ちがう記憶・ちがう画。画像・BGM を別の回で使い回さない
- 作り手の視点を入れる（語りの言葉、場面の選び方、概要欄のひとこと）
- 投稿の数より質。ambient（作業用）型は特に、似た回を続けて出さない

## 投稿前のチェック
- [ ] タイトルに町名、誤解を招く言い方なし
- [ ] 概要欄に「実在しない」「AI で生成」、外部素材のクレジット
- [ ] 改変・合成コンテンツの設定を伝えた
- [ ] サムネイルが縮小しても読める、偽の文字やロゴが紛れていない
- [ ] 台帳（towns.json）に記録した
