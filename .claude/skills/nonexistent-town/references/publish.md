# タイトル・概要欄・投稿の設定

参考動画のタイトル・概要欄の型はまだ確かめていない（YouTube のページを読めたら style-bible.md の A-7 に書き、この型を見直す）。それまでは次の型で。

## タイトル（3 案出して選んでもらう）
- 町名を必ず入れる。40 字前後まで。煽り（衝撃・閲覧注意など）や、実在と誤解させる言い方（「実在した」「記録映像」）はしない
- 型の例：
  - `存在しない町「凪ヶ浦町」の四季｜環境音・作業用`
  - `【存在しない街の記憶】凪ヶ浦町 ― 坂と港のある町の一年`
  - `知らないのに懐かしい町、凪ヶ浦町で過ごす 20 分`
- 参考動画・同じジャンルの人気動画のタイトルの言い回しをまねない

## 概要欄（`out/<id>_概要欄.txt`）
```
存在しない町「凪ヶ浦町（なぎがうらちょう）」の、春から冬までの暮らしと景色。
（1〜2 行：この回の芯を、ネタばらしせずに）

※この町は実在しません。登場する町・場所・人物・出来事はすべて架空です。
※映像と音は AI（画像：Gemini、動画：Veo、音楽：Lyria）で生成し、編集して制作しています。
（外部の効果音・音楽を使った回は、ここに素材名とクレジット）

00:00 町に入る
02:31 通りと人の行き来
…（章をチャプターに。最初は 00:00、3 つ以上、各 10 秒以上）

#存在しない街の記憶 #架空の町 #環境音 #ノスタルジー #作業用
```
- チャプターの時刻は `out/<id>_check/timeline.json` の各章の最初の場面の `start` から作る（episode.json の `chapters[].shots` の 1 つ目）
- ハッシュタグは 3〜5 個。関係ないタグ・実在の地名のタグは付けない

## YouTube Studio での設定（ユーザーに伝える）
- **改変または合成されたコンテンツ**：「はい」。本物らしい画と音を AI で作り、実在しない町を本物のように見せる内容なので、開示しておく（ラベルが付いても、それだけで表示回数や収益が下がるものではないとされている）
- **子ども向け**：「いいえ」
- サムネイル：`out/thumb.jpg`（1280×720・2MB 以下）
- 再生リスト「存在しない街の記憶」にまとめる。ショートには本編と同じ町名を入れ、関連動画に本編を指定する

## 量産・繰り返しに見せない（収益化のルール）
YouTube パートナープログラムでは、大量生産・繰り返しのような内容（ほぼ同じ作りの動画の連投、素材の使い回しだけの動画など）は収益化の対象外になる。
- 毎回ちがう町・ちがう章立て・ちがう画。画像・AI 動画・BGM を別の回で使い回さない
- 作り手の選択が見えるようにする（町の設定、章の並び、場面の選び方、概要欄のひとこと）
- 投稿の数より質。似た回を続けて出さない

## 投稿前のチェック
- [ ] タイトルに町名。誤解を招く言い方なし
- [ ] 概要欄に「実在しない」「AI で生成」、章のチャプター、外部素材のクレジット
- [ ] 改変・合成コンテンツの設定を伝えた
- [ ] サムネイルが縮小しても読める、偽の文字やロゴが紛れていない
- [ ] 台帳（towns.json）に記録した
