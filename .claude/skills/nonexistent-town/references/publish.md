# チャンネルの設定・投稿・投稿後の運用

**1 本ごとの投稿の中身は `scripts/make-publish-kit.mjs` が「投稿セット」にまとめる**（`out/<id>_概要欄.txt`・`out/<id>_投稿セット.md`）。このファイルは、その中身の根拠と、タイトル・概要欄の最初の文を書くときの型。完成した回は、動画・サムネイル・概要欄・入力の値を必ずセットで渡す（SKILL.md の 8 章）。

参考動画のタイトル・概要欄の型はまだ確かめていない（YouTube のページを読めたら style-bible.md の A-7 に書き、ここを見直す）。
画面の名前は YouTube Studio の日本語表示。YouTube の画面は変わることがあるので、見つからなければ近い名前を探す。

## 1. チャンネルの初期設定（最初の 1 回）

### カスタマイズ → プロフィール（基本情報）
- 名前：チャンネル名（決まったもの）
- ハンドル：英数字の短いもの（例 `@sonzaishinai-machi`。空いているかはその場で表示される）
- 説明（例。そのまま貼れる）：
  ```
  実在しない町の、季節をまたいだ暮らしと景色を、映像と町の音だけで描いています。
  語りもテロップもありません。作業中や眠る前、遠い記憶をたどるような時間にどうぞ。

  ※登場する町・場所・人物・出来事はすべて架空です。
  ※映像と音は AI で生成し、編集して制作しています。
  ```

### 設定 → チャンネル → 基本情報
- 居住国：実際に住んでいる国（日本）。YouTube の説明では、収益化（パートナープログラム）の条件に使われる設定。おすすめの相手を決める設定とは書かれていない
- キーワード（カンマ区切り）：
  ```
  存在しない街の記憶, 架空の町, 存在しない記憶, 環境映像, 環境音, 作業用, 睡眠用, ノスタルジー, 昭和レトロ, AI映像
  ```
  効果は小さい（見つけてもらう主な材料はタイトル・サムネイル・説明・見た人の反応）が、チャンネルの分野を伝える助けにはなる。関係ない言葉は入れない

### 設定 → チャンネル → 詳細設定
- 視聴者：「いいえ、このチャンネルを子ども向けとして設定しません」（子ども向けに作っていないため。法律に関わる申告なので事実どおりに）

### 設定 → アップロード動画のデフォルト設定
- タイトル：空欄（毎回考える）
- 説明：2 章の概要欄の型の「※」の 2 行（毎回の書き忘れを防ぐ）
- 公開設定：非公開（できてから予約公開にする）
- 詳細設定：カテゴリ「エンターテイメント」、動画の言語「日本語」、コメント「不適切な可能性があるコメントを保留して確認する」

### 設定 → コミュニティ
- ブロックする単語（例）：`副業, 稼げる, LINE, 投資, 儲かる, http` （宣伝・詐欺のコメントを自動で保留）
- 困ったコメントの人は、コメントの「︙」→「チャンネルに表示しないユーザー」（削除より、相手に気づかれにくく荒れにくい）

### 再生リスト（コンテンツ → 再生リスト → 新しい再生リスト）
- 「存在しない街の記憶｜本編」：全回をここへ。説明「実在しない町を、一本に一つずつ。」
- 「存在しない街の記憶｜ショート」：ショートをここへ
- 作ったら、それぞれの URL を `<シリーズ>/channel.json` の `playlists.main`・`playlists.shorts` に貼る（概要欄に自動で入る）。初期設定が全部済んだら `setupDone` を `true` に
- 回が増えたら「季節で選ぶ（春・夏・秋・冬）」などの再生リストも

## 2. 動画ごとのアップロード

### タイトル（3 案出して選んでもらう）
- 町名を必ず入れる。40 字前後まで。煽り（衝撃・閲覧注意など）や、実在と誤解させる言い方（「実在した」「記録映像」）はしない
- 型の例：`存在しない町「凪ヶ浦町」の四季｜環境音・作業用`／`【存在しない街の記憶】凪ヶ浦町 ― 坂と港のある町の一年`／`知らないのに懐かしい町、凪ヶ浦町で過ごす 20 分`
- 参考動画・同じジャンルの人気動画のタイトルの言い回しをまねない

### 概要欄（`out/<id>_概要欄.txt`）
```
存在しない町「凪ヶ浦町（なぎがうらちょう）」の、春から冬までの暮らしと景色。
（1〜2 行：この回の芯を、ネタばらしせずに）

▼ほかの町
存在しない街の記憶｜本編：<再生リストの URL>

※この町は実在しません。登場する町・場所・人物・出来事はすべて架空です。
※映像と音は AI（画像：Gemini、動画：Veo、音楽：Lyria）で生成し、編集して制作しています。
（外部の効果音・音楽を使った回は、ここに素材名とクレジット）

00:00 町に入る
02:31 通りと人の行き来
…（章をチャプターに。最初は 00:00、3 つ以上、各 10 秒以上）

#存在しない街の記憶 #架空の町 #環境音
```
- 自分で書くのは最初の 1〜2 行（episode.json の `publish.summary`）とタイトル案（`publish.titles`）。残りは make-publish-kit.mjs が組み立てる
- チャプターの時刻は、各章の最初の場面が出きった時刻（前の章とのつなぎが終わった時刻）を秒に切り上げたもの（章は episode.json の `chapters[].shots`、名前は `chapters[].title`。無ければ `theme`）。書き出しと同じ計算で自動で入る。条件（最初が 0:00・3 つ以上・各 10 秒以上）を満たさないときは入れない
- ハッシュタグは 3〜5 個。関係ないタグ・実在の地名のタグは付けない

### アップロード画面で選ぶもの
| 画面 | 項目 | 入れる値 |
|---|---|---|
| 詳細 | サムネイル | `out/thumb.jpg` |
| 詳細 | 再生リスト | 「存在しない街の記憶｜本編」 |
| 詳細 | 視聴者 | 「いいえ、子ども向けではありません」 |
| 詳細 | 年齢制限 | 「いいえ」 |
| 詳細 → すべて表示 | 改変または合成されたコンテンツ | **「はい」**（本物らしい町・人を AI で作っているため。正しく申告するのが規約。開示のラベルは、それだけで表示回数や収益を下げるものではないとされている） |
| 詳細 → すべて表示 | 有料プロモーション | チェックしない |
| 詳細 → すべて表示 | 撮影場所 | 入れない（架空の町） |
| 動画の要素 | 終了画面 | 最後の 20 秒に「動画（最新のアップロード）」＋「再生リスト（本編）」＋「チャンネル登録」。動画の最後は 20 秒の締めのカード（上に町名、下は空き）になっているので、要素は下半分へ。始める時刻（カードが出きった時刻）は投稿セットに出る |
| 動画の要素 | カード | 中ほど（真ん中にいちばん近い章の頭の 2 秒後）に 1 枚：再生リスト「本編」。時刻は投稿セットに出る |
| 公開設定 | 公開 | 予約（毎回なるべく同じ曜日と時間） |

- 終了画面は動画が 25 秒以上ないと付けられない。付けられないと表示されたら、収益化の条件などを YouTube Studio の案内で確かめる

### ショート
- 本編と同じ町名を入れ、アップロード画面の「関連動画」に本編を指定する（episode.json の `publish.mainVideoUrl` に本編の URL を入れておくと投稿セットに出る）
- ショートの概要欄やコメントのリンクは押せない（YouTube の仕様）ので、本編へは「関連動画」でつなぐ。概要欄は短く、開示の 2 行とハッシュタグ
- サムネイルは、アップロード画面で動画の中から町名がいちばん映える 1 コマを選ぶ

## 3. 公開したあと

### 固定コメント（投稿者として書いて「固定」）
答えやすい問いを 1 つ（`publish.pinnedComment`。書かなければ下の例から回の番号で選ばれる）。例：
- 「この町で、いちばん歩いてみたかった場所はどこでしたか？」
- 「あなたの“存在しない記憶”の町は、どんな季節でしたか？」
- 「次はどんな町を見てみたいですか？（海辺・山あい・雪国…）」
コメントは見た人どうしの話が生まれるのが目的。コメント自体が再生時間を延ばすわけではないので、問いかけで煽らない

### 宣伝のしかた
- 興味を持ちそうな人（環境音・ノスタルジー・作業用の動画が好きな人）に届く場所で紹介する
- 身内や知人に頼んで再生してもらうことはしない（興味のない人の短い再生は、チャンネルの役に立たない）。見てもらうこと自体がチャンネルを悪くする、という公式の根拠は無い

### 見ること（YouTube Studio → アナリティクス）
- 最初の 30 秒で離れる人の割合（冒頭の画が弱いと増える → 次回は最初の 1 枚を一番強い画に）
- 平均視聴時間と、終了画面・カードのクリック
- 結果は style-bible.md の B 章や formats.json に反映して型を育てる

## 4. 量産・繰り返しに見せない（収益化のルール）
YouTube パートナープログラムでは、大量生産・繰り返しのような内容（ほぼ同じ作りの動画の連投、素材の使い回しだけの動画など）は収益化の対象外になる。
- 毎回ちがう町・ちがう章立て・ちがう画。画像・AI 動画・BGM を別の回で使い回さない
- 作り手の選択が見えるようにする（町の設定、章の並び、場面の選び方、概要欄のひとこと）
- 投稿の数より質。似た回を続けて出さない

## 5. 投稿前のチェック
- [ ] タイトルに町名。誤解を招く言い方なし
- [ ] 概要欄に「実在しない」「AI で生成」、章のチャプター、本編の再生リスト、外部素材のクレジット
- [ ] 改変または合成されたコンテンツ「はい」、子ども向け「いいえ」
- [ ] 終了画面（最後の 20 秒）とカード
- [ ] サムネイルが縮小しても読める、偽の文字やロゴが紛れていない
- [ ] 公開後：固定コメント、台帳（towns.json）に記録
