# 検品（2 人のエージェントに並列で頼む）

書き出しのあと、下の 2 つをそれぞれ general-purpose エージェントに渡して並列で起動する。渡すもの：動画（mp4）・サムネイル・episode.json・plan.md・シリーズの style-bible.md と towns.json のパス、`<SKILL>` の絶対パス。返事は「PASS」か「直すことの一覧（場所・時刻・理由・直し方）」。

---

## 1. 品質の検品（quality）

役目：見た目と音の不具合を見つける。直すのは作り手なので、具体的に指摘する。

やること：
1. 4 秒おきのコマを抜いて、4×4 のシートにして全部見る
   `ffmpeg -i <mp4> -vf "fps=1/4,scale=480:-2,tile=4x4" -q:v 3 <作業>/qa_%02d.jpg`
   AI 動画の場面（episode.json の video）は、1 秒おきに抜いて動きの崩れも見る
2. 見るところ
   - 画：真っ黒・真っ白のコマ（つなぎ以外）、ちらつき、急な明るさの跳ね、同じ構図・同じ距離の連続、崩れ（手・顔・線路・電線・窓）、偽の文字やロゴ
   - AI 動画：形が溶ける・増える、速すぎる動き、静止画の場面との色や質感の差
   - 文字：最初の名札と最後のカードの誤字、読みにくさ、画面の端で切れていないか
   - つなぎ：章の境のディゾルブ、意図しない一瞬の別画像、最後の暗転が途中で切れていないか
3. 音：`ffmpeg -i <mp4> -af ebur128=peak=true -f null -` で平均（目標 ±1 LU）とピーク（-1.0 dBTP 以下）。章の変わり目で音が急に途切れたり跳ねたりしないか（`-v verbose -af ebur128=framelog=verbose` の M 値を章の境の前後で）
4. 長さ：`ffprobe` で映像と音の長さがそろっているか（差 0.25 秒以内）
5. サムネイル：320×180 に縮小して町名が読めるか

返す形：PASS／指摘の表（時刻｜何が｜なぜ｜直し方）

---

## 2. オリジナリティと安全の検品（originality）

役目：参考動画や過去回の写しになっていないか、実在や誤解を招く要素がないかを見る。

やること：
1. style-bible.md の A-8（避けること）・A-9（借りてよいもの／借りないもの）を読む
2. 参考動画と比べる：設定（海上都市・水没都市）、実在の名所、人物の物語、看板や店名、タイトルとサムネイルの型が似すぎていないか
3. towns.json と比べる：町名・色・最初と最後の画・サムネイルの構図が直近 5 回とかぶっていないか
4. 画像・AI 動画（4 秒おきのシート）とサムネイル：読める文字、ロゴ、ブランドを思わせる配色や形、実在の名所に見える構図、実在の人物に似た顔
5. AI 動画の音：意味のある言葉（実在の地名・人名・宣伝のような言葉）が聞こえないか
6. 概要欄：「この町は実在しません」「AI で生成」、外部素材のクレジットがあるか。実在と誤解させる言い方がないか

返す形：PASS／指摘の表（どこ｜何が問題か｜直し方）
