# 検品（2 人のエージェントに並列で頼む）

書き出しのあと、下の 2 つをそれぞれ general-purpose エージェントに渡して並列で起動する。渡すもの：動画（mp4）・サムネイル・episode.json・plan.md・シリーズの style-bible.md と towns.json のパス、`<SKILL>` の絶対パス。返事は「PASS」か「直すことの一覧（場所・時刻・理由・直し方）」。

---

## 1. 品質の検品（quality）

役目：見た目と音の不具合を見つける。直すのは作り手なので、具体的に指摘する。

やること：
1. 2 秒おきのコマを抜いて、4×4 のシートにして全部見る
   `ffmpeg -i <mp4> -vf "fps=1/2,scale=480:-2,tile=4x4" -q:v 3 <作業>/qa_%02d.jpg`
2. 見るところ
   - 文字：誤字・脱字、読めない（背景と同化）、テロップどうしや日付スタンプとの重なり、画面の端で切れている、表示が短すぎる（3 秒未満）
   - 画：真っ黒・真っ白のコマ（つなぎ以外）、ちらつき、急な明るさの跳ね、同じ動き・同じ構図の連続、画像の崩れ（手・線路・電線・窓）、偽の文字やロゴ
   - つなぎ：ぶつ切れ、意図しない一瞬の別画像、最後のフェードが途中で切れる
3. 音：`ffmpeg -i <mp4> -af ebur128=peak=true -f null -` で平均（目標 ±1 LU）とピーク（-1.0 dBTP 以下）。声があるなら、声の区間の前後で BGM が下がって戻っているか（`-v verbose -af ebur128=framelog=verbose` の M 値）
4. 長さ：`ffprobe` で映像と音の長さがそろっているか（差 0.25 秒以内）
5. サムネイル：320×180 に縮小して町名が読めるか

返す形：PASS／指摘の表（時刻｜何が｜なぜ｜直し方）

---

## 2. オリジナリティと安全の検品（originality）

役目：参考動画や過去回の写しになっていないか、実在や誤解を招く要素がないかを見る。

やること：
1. style-bible.md の「借りてよいもの／借りないもの」「スタイルカード」を読む
2. 参考動画と比べる（分析メモ・サムネイルがあれば）：台詞や文章の言い回し、町名、特定の構図、サムネイルの構図、タイトルの言い回しが似すぎていないか
3. towns.json と比べる：町名・色・オープニングの画・サムネイルの構図が直近 5 回とかぶっていないか
4. 画像（2 秒おきのシート）とサムネイル：読める文字、ロゴ、ブランドを思わせる配色・形、はっきりした顔、実在の名所に見える構図
5. 語り・テロップ・概要欄：実在の地名・店名・人名・事件、実在と誤解させる言い方（「実在した」「記録映像」など）
6. 概要欄に「この町は実在しません」「AI で生成」があるか。外部素材のクレジットがあるか

返す形：PASS／指摘の表（どこ｜何が問題か｜直し方）
