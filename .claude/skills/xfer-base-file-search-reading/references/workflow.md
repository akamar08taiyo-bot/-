# 実務手順と受入条件

## 実行可能性
まず入力素材と利用できるツールを確認する。ファイル名、画像の存在、APIの接続、スケジュール登録を推測しない。必要な範囲だけ扱い、秘密情報を不要に取得しない。
## 手順
対象に合った最小の手段を選ぶ。通常の数値計算はコードで確認する。外部事実は出典と日付を残す。編集なら原本と変更範囲を保持する。OCRは画像・言語に対応する手段が必要な場合に限定する。
## 検証
実際の出力を開き、内容と期待結果を比較する。実行ログや計算結果など検証可能な証拠を残す。画像、文書、動画、登録済み通知と、それらのための指示文を混同しない。
## 限界
調査できない情報や利用できない接続は明示し、その部分を実行済みにしない。手元でできる下書き、設計、検査は続ける。
