# 請求書の発行（マネーフォワード）

お金に関わる作業なので、途中で必ず止まって人間に確認する。

## 前提

- マネーフォワード クラウドの MCP（コネクター）が接続されていること。キーが必要な場合は 1Password に入れ、`.env` には `op://` の参照だけを書く。
- 接続されていなければ作業を止め、`ai-ecosystem/SETUP.md` の手順を人間に案内する。代わりの方法で勝手に作らない。

## 手順

1. **依頼の確認**: 宛先（取引先）・対象月・品目・金額・支払期限を依頼から抜き出す。抜けていれば先に聞く。
2. **取引先を探す**: マネーフォワードの MCP で取引先を検索し、正式名称・敬称・送付先を確認する。候補が複数あれば人間に選んでもらう。
3. **金額の確認表を作る**: 前月の請求書や契約メモ（`ai-ecosystem/knowledge/clients/<取引先>.md`）と照らし、次の表を作る。
   | 品目 | 数量 | 単価 | 小計 | 前月との差 |
   税率・端数処理・源泉徴収の有無も書く。
4. **人間の承認（必須）**: 確認表を見せて「この内容で作成してよいか」を聞き、はっきり OK をもらうまで作成しない。
5. **作成**: 承認された内容で請求書を作成し、PDF を `ai-ecosystem/output/invoices/<YYYY-MM>/` に保存する。
6. **報告**: 宛先・金額（税込）・支払期限・PDF の場所をまとめる。送付（メール送信）は人間が行うか、送信前にもう一度承認をもらう。
7. **最終判定**: `jeb-judge` に確認表と作成結果を渡し、金額・宛先・日付が一致しているか判定させる。

## してはいけないこと

- 承認前の請求書作成・送付、既存の請求書や取引先の削除・上書き（`guard.mjs` が削除系の操作を止める）。
- 金額の推測。分からない値は空欄にして聞く。
