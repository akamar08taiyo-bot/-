# 移植スキルの選択

## 入力
今回の目的、利用可能なファイル、プロジェクト、接続済みサービス、許可された操作。

## 実行手順
1. 依頼を調査・分析・文書・デザイン・実装・動画・運用・検査に分類する。
2. [全スキル索引](references/catalog.md)から名称と用途を検索する。全本文を一括読込しない。
3. 目的に必要な最小限のスキルを選ぶ。重複する提供元は対象環境に合うものを優先し、同じ作業を二重に行わない。
4. 導入済みか確認する。索引に掲載されていても未導入・未接続なら、その違いを明示する。
5. 手動専用と表示されたスキルは自動呼出しない。本文をファイル読取して制限を迂回しない。必要ならユーザーへ該当コマンドを示す。
6. 実際の操作権限、データの正本、完了条件を確認してから実行する。結果を実施・未実施に分ける。

## 出力契約
選択したスキル、選択理由、必要な入力・接続、承認が必要な操作、検査結果。

## 完了チェック
- [ ] 選択した手順が今回の目的と一致する。
- [ ] スキルの存在とサービス接続を区別した。
- [ ] 公開・送信・課金・削除を包括承認と解釈していない。

## 停止・代替
未知の接続、必要資料の欠落、高リスク操作の未承認では該当操作を止める。安全な設計と説明は続ける。

## 由来
この移植セット向けに新規作成した案内スキル。元の登録264件とは別枠。モデルの能力や外部サービスそのものを追加するものではない。
