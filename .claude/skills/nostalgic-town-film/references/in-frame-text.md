# 画面の中の文字（カード・日記・柱・額の札・黒板・お守りの紙・空中のタブレット）

「説明しない」作品では、物語を画面の中の物に書いてある字で伝える（カードの年、日記の日付、柱の傷）。
AI の画像・動画は日本語の字を正しく書けないので、**原画では紙を白紙にしておき、字は後から重ねる**。
第二章（`videos/ai-human-coexistence-2`）で作った道具と、その使い方。

## 目次

## 1. 道具の選び方

| 場面 | 道具 |
|---|---|
| 紙や板が動く・手が前を通る・ページをめくる（ほとんどの場合） | **`scripts/bake_ink.py`**（クリップに焼き込む。手の下に隠れ、影もかかる） |
| 空に浮かぶ電子版、実物の板にぴったり貼る表示 | `holo`（Remotion。references/timeline.md） |
| 動かない板に、隠れる物なしで字を出すだけ | `ink`（`bake` なし。Remotion の `src/fx/Ink.tsx` が四隅に貼る） |
| 話すと字が刻まれる空中のタブレット | `voice`（Remotion の `src/fx/Voice.tsx`） |

焼き込みは、Remotion の合成より前に、スロー映像（`public/clips/<ID>.mp4`）そのものを作り直す。元は `work/raw/<ID>.mp4` に移して残る。

## 2. 手順

1. **原画では白紙に**：画像と Veo の指示に「Keep the pages/paper completely blank」。字が出たら、その字を消す（下の 4）
2. **四隅を測る**：手が重ならない、きれいなコマを選び、細かいマス目（0.5〜1%）を描いて四隅（左上→右上→右下→左下、画面の割合）を読む。紙の色で塗り分けて輪郭を出す方法も使える（白い紙なら HSV で明るく彩度の低い所）
3. **追う**：`python3 -I scripts/track_plane.py <ID>@<名前> x1,y1,x2,y2,x3,y3,x4,y4 --start <測った秒> [--pad 0.5] [--exclude …] [--apply 右ページ=…]`
   - 紙そのものの動き（手に持ったカードの傾き、めくるページ）を射影変換で追う。測ったコマから前へも後ろへも追う
   - 紙に模様が少ないときは `--pad` で机など一緒に動く物も使う。手は `--exclude` で外す（RANSAC が外れ値として捨てるので、たいていは要らない）
   - 見開きの右ページなど、手で隠れがちな面は `--apply 名前=四隅` で同じ動きに乗せる
4. **確かめる**：`python3 -I scripts/plane_check.py <ID>@<名前> work/check.jpg 0.1,0.1,0.9,0.9`（6コマに四隅を描く）
5. **試し焼き**：`BAKE_DEBUG=1 python3 -I scripts/bake_ink.py <ID> --preview 1,4,8,12` → `work/bake/<ID>_<秒>.jpg`（と、隠す所の白黒 `<ID>_keep*.png`）
6. **焼き込み**：`python3 -I scripts/bake_ink.py <ID>`（16秒で2〜5分）。`memory: true` のカットは昭和の色もここでかかる（文字のないカットも通す）

注意：`--preview` を一度でも走らせると、元のクリップは `work/raw/` に移る。焼き込みを最後まで走らせるまで `public/clips/<ID>.mp4` は無いので、静止画の確認や書き出しは失敗する。

## 3. ink の書き方（timeline.json のカットに `"ink": [ … ]`）

```json
{"bake": true, "quad": [0.4454, 0.5965, 0.5983, 0.569, 0.630, 0.761, 0.4614, 0.8004], "track": "A2@card", "aspect": 1.4,
 "t0": 1.0, "t1": 13.0, "soft": 0.7,
 "occlude": {"mode": "chroma", "c0": 6, "c1": 12, "grow": 1,
             "refs": [{"until": 5.0, "ref": [1.6, 2.0, 2.4]}, {"ref": [10.4, 10.8, 11.2, 11.6]}]},
 "patch": {"mode": "paper", "ref": [10.4, 10.8, 11.2, 11.6], "rects": [[0.285, 0.64, 0.975, 0.935]], "feather": 5, "relight": true, "grain": 1.2},
 "items": [
   {"text": "昭和61年　夏休み", "x": 0.63, "y": 0.665, "size": 0.115, "font": "print", "align": "center", "color": "#3b3a78"},
   {"kind": "line", "x0": 0.445, "y0": 0.405, "x1": 0.578, "y1": 0.405, "width": 0.006, "color": "#2c3530"},
   {"kind": "stamp", "t": 7.45, "x": 0.512, "y": 0.51, "size": 0.165, "text": "済", "color": "#b5452f"}]}
```

| キー | 意味 |
|---|---|
| `quad` | `--start` のコマでの四隅（割合）。`track` があればそれで動く。無ければカメラ全体の追跡（track.py）で動く |
| `aspect` | 紙の縦横比（幅/高さ）。文字の位置と大きさは紙の割合（x は幅、y と size は高さに対する割合） |
| `items` | いつも書いてある字。`text`（改行で複数行）, `x`, `y`（上端）, `size`, `font`, `color`, `opacity`, `rot`, `align`, `spacing`（em）, `line`（行の高さ）, `shaky`（0..1.3、年をとった手のふるえ） |
| `kind: "line"` | 線（柱の背くらべ、表の枠を描き直す） |
| `kind: "stamp"` | はんこ（`t` 秒から。朱肉のかすれつき）。`t: -1` で最初から押してある |
| `kind: "glare"` | ガラスの映り込みの光（`blend: "screen"` の面で。額の写真の顔をやわらげる） |
| `pages` | 時間で入れ替わる字 `[{t0, t1, items}]`、`fade`（秒）。ページをめくる場面は、めくっている間（手とページが隠す）に入れ替える |
| `blend` | `multiply`（既定。紙に書いた字）／`screen`（黒板のチョーク）／`normal`（不透明） |
| `soft` | にじみ（画面上の px くらい） |
| `t0`, `t1` | 全体の出る・消える時刻（クリップの時刻、0.6 秒でフェード） |

## 4. 隠す・影をのこす・下の模様を消す

**occlude（手や物が前を通ったら、字を隠す）**：基準のコマ（`ref`：秒の一覧か `"median"`＝全体の中央値）の紙と、今のコマの紙を、紙の座標で比べる。

- `mode` 省略（Lab の差）：手・めくれるページを見分ける。`d0`〜`d1`、`wl`（明るさの重み）、`open`（Veo が動かす細い傷や罫線は無視する大きさ）
- `mode: "chroma"`：**日なたの紙に手の影がかかる場面**はこちら。明るさでわった色の差（`c0`, `c1`）と明るさの比（`r_lo`, `r_hi`）で見分け、「暗くなって青みがかった所」は影とみなして隠さない（`shadow`、既定 true）。日なたの影は空の光で青くなるので、色の差だけだと影まで隠してしまった
- `refs: [{until, ref}, …]`：時刻で基準を変える（はんこを押す前と後で紙の中身が変わるとき）
- `grow`：隠す所を少し広げる（指の縁に字が残らないように）

**patch（下にある模様や、Veo が描いた偽の字を消す）**：`blend` の前に、紙の色で塗る。

- `mode: "paper"`：基準のコマ（`ref`）の紙から、線やはんこ（まわりより暗い所）を消して（inpaint）なめらかにした紙。表の枠の段を白紙に戻すときなど
- `mode: "clone"`：`regions [[sx0,sy0,sx1,sy1,dx0,dy0], …]` で、きれいな所を写す（柱の木目など模様のある面）。明るさは写し先に合わせる（`match`）
- `mode: "blur"`：ぼかした紙（細い線だけのとき）
- `rects`：塗る範囲（紙の割合）。省略時は `inset` を除いた全体
- `relight: true`：基準の紙と今のコマの明るさの比をかける（手の影がかかっても、塗った所だけ明るく浮かない）。`grain`：粒子
- 人の指や手が、塗る範囲にいつもかかっている所（カードを持つ親指）は、基準のコマにも写っているので「紙」とみなされ、上から塗られてしまう。`rects` から外す

## 5. 字の書き分け（フォント）

| `font` | フォント | 使う人 |
|---|---|---|
| `maru` | Hachi Maru Pop | 子どもの丸い字（女の子の交換日記、お守りの紙） |
| `pencil` | Yomogi | 鉛筆の子どもの字（少年） |
| `pen` | Klee One | 大人のペン字（年をとったら `shaky` を上げ、`opacity` を下げる） |
| `robot` | Zen Maru Gothic Bold | ロボットの四角くていねいな字 |
| `mincho` | Zen Old Mincho Bold | 墨・額の札 |
| `print` | Zen Maru Gothic Bold | 印刷（カードの題） |
| `chalk` | Klee One（白） | 黒板（`blend: "screen"`） |
| `scratch` | Yomogi（うすい色） | 柱に刻んだ字 |

手書きのフォント（SIL OFL）は GitHub から落とせなかった（403）。**Google Fonts の CSS API に古いブラウザの User-Agent と `&text=使う字` を付けて頼む**と、その字だけの部分集合（WOFF）が返る → fontTools で TTF にして `/usr/local/share/fonts/hand/` に入れ、`fc-cache -f`。字を足したら、全部の字で頼み直す（足りない字は別のフォントで出て、すぐ分かる）。配るときは OFL の全文を添える（`videos/ai-human-coexistence-2/assets/fonts_hand/OFL.txt`）。

## 7. 話すだけで書ける空中のタブレット（`voice`）

```json
"voice": [{"x": 0.80, "y": 0.47, "w": 0.2, "tilt": -18, "t0": 3.4,
           "lines": ["もし　雨がふったら", "　洗濯物を　とりこむ", "　「ピ。」と鳴らす"]}]
```

声の波形が揺れているあいだ、行番号つきで一文字ずつ刻まれる（`rate` 0.12秒／字、行の間 `pause` 0.7秒、行頭の全角スペースは字下げ）。音（build_mix.py）は、出る音・聞き取れない話し声・一文字ごとの小さな音を、同じ時刻で自動で入れる。話している人の顔の前に置くと、顔も隠れる。

## 8. 顔を暗がりに沈める（shade と grade）

夜の場面で、人物の横顔や子どもの顔が見えてしまったときは、作り直さずに、カットに次の2つを書いて `bake_ink.py` を通す（第二章の線香花火 E2）。

```json
"grade": "curves=all='0/0 0.3/0.08 0.55/0.16 0.75/0.34 0.9/0.66 1/1'",
"shade": [{"x": 0.423, "y": 0.488, "rx": 0.017, "ry": 0.036, "k": 0.3, "soft": 0.6},
          {"x": 0.47, "y": 0.55, "rx": 0.026, "ry": 0.048, "k": 0.3, "soft": 0.6}]
```

- `grade`：夜を深くする（暗い所をさらに暗く、明るい光は残す）。夜空がほぼ黒になるので、次の楕円の暗がりの縁が見えなくなる。花火・ランタン・ロボットの光の帯は残り、人はシルエットになる
- `shade`：顔の所だけを小さな楕円で暗くする（`k` 倍）。楕円は顔だけを囲む大きさに。大きくすると体まで消え、背景の家並みに丸い暗がりが出る
- `grade` なしで楕円だけをかけると、夜空に暗い輪が見えた。肌の色だけを暗くする `skin: true` は、煙まで暗くなり、子どもの顔（色の薄い肌）は残ったので使わなかった
- 昼の場面では不自然になるので使わない（顔の入らない所だけを切り出すか、使う所を短くする）

## 9. 看板の色を塗り替える

実在のチェーン店に似た配色（緑と青のしまのコンビニなど）は、Veo が「他社のコンテンツ」として動画にしない。名前を変えても色で弾かれる。
`python3 -I scripts/recolor_region.py <元> <出力> --box x0,y0,x1,y1 --map 45-90:9:150:0.85 --map 92-128:12:120:0.55`
（色相の範囲:新しい色相:彩度の上限:明るさの倍率）。縁に残った色は、彩度の下限（`--smin`）を下げて、もう一度かける。記録は `assets/gen/ledger.json` に残る。
