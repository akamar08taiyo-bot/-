# 実務手順と受入条件

## 数字の正本
報告値、調整値、予測値を別項目で管理する。通貨・桁・会計年度・基準日をそろえ、元資料のページと計算箇所を記録する。売り手や経営陣の主張は検証済み事実と区別する。
## モデルの設計
入力、計算、出力、チェックを分離する。資金調達と使途、貸借一致、現金増減、EVと株主価値の橋渡しなど、モデル種類に必要な恒等式を設ける。合理的な上下振れケースを作る。
## レビュー
外部リンク切れ、ハードコード、単位誤り、期間ずれ、二重計上を検査する。主要出力の感度を示し、確率や投資収益を根拠なく保証しない。
## 人間判断
財務上の整理を法律意見や取引承認と称さない。顧客向け送信、契約、発注、融資判断、支払は明示された権限の範囲で人間の承認を残す。
