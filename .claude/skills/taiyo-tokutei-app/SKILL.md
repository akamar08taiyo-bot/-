# 特定福祉用具 購入申請書・見積もり作成（太陽シルバーサービス 行橋営業所）

介護保険の特定福祉用具の販売で、仕切り一覧表から商品マスタを作り、★お気に入りから選ぶだけで、定価の2割引きの見積書（介護保険の内訳つき）を作るアプリ。
使うのは行橋営業所の福祉用具専門相談員（プログラマーではない）。スマホとパソコンで使い、スクリーンショットに丸を付けて頼んでくる。
このスキルは 2026年10月のセッション（見積書を Excel で保存・申請書・販売見積書の原本・カタログ・住宅改修との ⇔・受注残への受け渡し。2026-10-26 まで）の知識をまとめたもの。

ポータル全体に共通のこと（公開の流れ・ユーザーの好み・報告のしかた）は `taiyo-portal` スキル、Excel の作り方の詳しいことは `taiyo-excel-export` スキルにある（入っていれば一緒に読む）。

## 計算の決まり（`calc.ts` の1か所だけで計算する）

金額は印刷・Excel・これから作る申請書・受注簿で同じでなければならないので、`saleTotals(sale, settings)` 以外で計算しない。
- 販売単価：定価×(100−割引率)%（割引率は設定の 20 → 定価×0.8）、1円未満切り捨て。品目の単価を手で入れたら（`unitPrice`）それを使う。定価がない商品は 仕切×1.25（`markupRate`）。
- 消費税は行ごとに切り捨て。非課税の品目は消費税の欄が「非課税」。
- **歩行器・歩行補助つえ（多点杖・クラッチ）は非課税**（身体障害者用物品。介援隊カタログでも金額の横に「非課税」。ユーザーの指示「歩行器（ピックアップ）や四点杖は非課税…しっかりと全ての商品で認識する」2026-11-03）。
  決まりは `category.ts` の `TAX_FREE_CATEGORIES` と `calc.ts` の `taxOf`・`categoryTaxPatch` の1か所。カタログ・型番から入れる（`catalogItemPatch`）・商品マスタから入れる（`itemFromProduct`・`findByCode`）・
  種目を変える・取り込む・読み込む（`storage.ts`）のどれでも通す。前は `catalogItemPatch` が税区分を入れず、非課税の多点杖が 10% のままだった。税込の横の「非課税」ボタンで手で決めた商品（`taxByHand`）は自動で変えない。
- 利益率＝（販売単価−仕切）÷販売単価（`marginRate`）。利益率から単価は 仕切÷(1−利益率) の切り上げ（`priceFromMargin`）＝手で入れた単価と同じ扱い（`unitPricePatch` で割引率も）。
  備考（算出根拠）は手で入れた単価でも割引率を書く（小数2けたまででちょうど合えばその%、合わなければ「約」。`basisNote`。2026-11-03「当然備考の部分も連動して数字が変わる」）。
- 介護保険の対象＝購入金額と「今年度の残り」の小さい方。**残りが空欄なら限度額 10万円**として計算する（ユーザーの指示）。**0 は「もう残っていない」**で、空欄とは別。超えた分は全額ご負担。
- 利用者負担＝対象×負担割合（1〜3割）を**切り上げ**、保険者負担＝対象−利用者負担。整数で計算するので 3割でも1円もずれない。
- **負担割合は新しい案件では未選択（`burdenRatio: null`）**（2026-10-27。ユーザーの話「1割負担、2割負担、3割負担が分からないと売上伝票の発行はできない」・決めたこと「（選ぶまで自己負担額は）出さない」）。
  前は初めから1割で、確かめないまま1割で出すおそれがあった。前からの案件の 1〜3 はそのまま（読み込みで null だけ未選択のまま。項目のない古いデータは1割）。
  未選択のあいだ `saleTotals` は1割で数えるが `ratioSet: false` で、割合で決まる金額（利用者負担・介護扶助・保険者負担・お客様のお支払い・払い戻し・委任状の保険給付額）は**出さない**
  （`estimateBook.ts` の `insuranceLines`・見積もりの画面の右・一覧・`shinsei.ts` の `benefit`）。欄は薄い黄色。販売受注簿へは選んでから送る（承認にしても未選択なら送らず、選んだときに送る・「📤 販売受注簿に転記」も止める。`SaleEditor.tsx` の `queueIfReady`）。
- 個別切り上げ（品目ごとに切り上げ）：みやこ町は最初からオン（要確認）。超えた分がなく、金額のある品目が2つ以上のときだけ効く。
- 生活保護：利用者のお支払いは 0、負担割合の分（`aid`）は画面・見積書・Excel とも「生活保護（1割）」、売上伝票の窓は「利用者負担（生活保護・1割）」、受注簿の備考は「生活保護（1割 ○円）」。**「介護扶助」という言葉は画面・帳票に出さない**（ユーザーの指示「生活保護のときは、介護扶助という文言は不要」、見積書からも「外します」2026-10-28。売上伝票発行依頼書は「対象内利用者負担額（生活保護・1割・切り上げ）」。コードの名前・コメントは介護扶助のまま）。償還払い：「お支払いいただく金額（いったん全額）」と「あとで保険者から払い戻される金額」。
- 利益率が 20% 未満なら知らせる（`minProfitRate`）。
- 計算の例（テストで確かめている）：35,000円と13,800円の2品・1割 → 合計 42,944円、利用者 4,295円、保険者 38,649円。
