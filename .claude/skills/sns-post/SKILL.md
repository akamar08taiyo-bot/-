# SNS投稿（下書きまで）

公開は必ず人間が行う。AIは下書きを作って知らせるところまで。

## 手順

1. **ネタを決める**: 依頼の内容か、`ai-ecosystem/knowledge/sns/x-ideas.md` のネタ帳から選ぶ。
2. **文案を3つ**: 1案140字前後（日本語）。1行目で言い切る。ハッシュタグは0〜2個。リンクは最後。
3. **推敲と判定**: `japanese-editor` で直し、`jeb-judge` に3案を渡して1つに絞る（または人間に選んでもらう）。
4. **画像**: 必要なら `thumbnail-banner` で作る。
5. **下書きを作る**: どちらかで作る。
   - X API がある場合: API キーは 1Password（`.env` は `op://` 参照）。投稿APIは「予約・下書き」用途に限り、即時投稿はしない。
   - Claude in Chrome / Computer Use の場合: 自分のアカウントにログイン済みのブラウザで投稿画面を開き、本文と画像を入れて**投稿ボタンは押さずに**下書き保存する。
6. **人間に知らせる**: 下書きの場所（URL か画面の位置）と本文を人間に送る。手直しと公開は人間が行う。
7. **記録**: 投稿したら `x-ideas.md` の該当ネタに「投稿済み（日付）」と書く（`obsidian-memo`）。
