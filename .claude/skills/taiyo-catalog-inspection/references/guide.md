# 検品の手引き（カタログと読み取りの照合）

あなたは介護用品カタログ（介援隊）・住宅改修の部材カタログ（マツ六・TOTO・矢崎化工）の検品担当です。
アプリはカタログのページから商品・品番・金額などを読み取っています。前回の点検で、読み取りの誤りが70商品以上で見つかりました。
同じ種類の誤りが残っていないか、**カタログの絵だけを正**として、1つずつ確かめます。推し量らず、絵に書いてあることだけを書きます。
読めない・はっきりしないときは推測で埋めず、note に「読めない」「どちらか分からない」と書きます。

## 前回見つかった誤りの種類（ここを重点的に見る）
1. **金額のまとまり**：「各¥」の金額が何行の品番にかかるか。表の横線（罫線）で区切られた範囲だけにかかる。となりのまとまりの金額を取っていないか（例：SAV・SAVS 各¥A ／ SAVH・SAVA 各¥B）。
2. **税込と税抜**：大きい金額（例「¥1,100」）は税込、かっこの「（税抜¥1,000）」が税抜（例の金額は架空）。非課税の商品は「非課税 ¥…」の金額だけ。取り違えない。
3. **金額の印**：「↑」（値上げ）、「★」、「～」（〇〇円から）、「各」。
4. **注文番号と品番**：「261-S0339」「261-W1257」のような 261- で始まる紺の帯の番号は注文番号（介援隊の番号）で、品番ではない。品番はメーカーの型番（536-440、PN-L10201A、No.5022、KSC-2/ST など）。品番が写真の横・下にしか書いていない商品もある。
5. **品番の字**：0（ゼロ）とO、1とIとl、5とS、8とB、2とZ、-（ハイフン）と ー、/ の有無、末尾の文字（A・BR・D など色の記号）。2行に割れた品番（「EA4-」「102」）。
6. **色・サイズ・タイプの付け違い**：となりの行の色を付けていないか。表の見出し（標準タイプ・やわらか便座・フラットタイプ(長さ100cm) など）、左の見出し、写真の横の色名が、その品番のものか。
7. **抜け**：色・サイズ・タイプが抜けていないか。1つの品番で色がいくつもある（「各色」、写真に色見本だけ）商品。
8. **TAIS**：「TAIS/00054-000179」の番号が、その品番の行のものか（行ずれ）。2行に割れた番号、「取得中」、TAIS がない品番。
9. **メーカー**：商品の枠の右下などにあるメーカー名（「アロン化成（株）」など）。寸法や材質の字をメーカーと読んでいないか。
10. **商品名**：見出しの商品名と、そのすぐ下・右の（ ）付きの副題（「(薄型)」「(超ミニ)」など）。途中で切れていないか。
11. **印**：「介・購入」（特定福祉用具販売の対象）、「介・住宅」、「非課税」、「在庫商品」など。
12. **取りこぼし・余計なもの**：ページに載っている商品・品番が全部あるか。カタログにないものが入っていないか。
13. **押せる枠**：アプリの枠がその商品の範囲（見出し・写真・品番の表・金額）を囲んでいるか。となりの商品にかかっていないか。
14. （住宅改修）**品番の字と枠**：枠の中の印刷された品番と、アプリの品番が1字もちがわないか。色の記号（USL・SGD・#NW1 など）の付け違い、入り数の札（3ﾎﾞﾝｲﾘ）、枠が品番以外（ページ番号・寸法）を囲んでいないか。

15. **名前が似た商品の取りちがえ（肘付き・肘なし など）**：パナソニックのシャワーチェアは、肘付きが名前に「SP」の2字があるだけ（「コンパクトSPおりたたみN」＝肘付き、「コンパクトおりたたみN」＝肘なし）。
    肘掛けの有無は、枠の下の機能アイコン（「ひじ掛け」「ひじ掛け跳ね上げ」「座面回転」など。黒い地＝あり、灰色の地＝なし）でしか分からない。
    2026-11-09 に、肘付きを見積もるはずが肘なしの型番が見積もりに入り、値引きをすることになった（ユーザーの指摘）。
    → 名前が1〜2字だけちがう商品（SP・U型・回転・腰当付・背付き／背無し・ワイド／ミドル／コンパクト）は、アイコンと名前の両方を見て、どちらの品番か書く。アイコンのあり・なしも書き取る。
16. **印刷の字と PDF の文字**：絵で読みにくい字（ポとボ、パとバ、ー と －）は、目で読んだだけで決めない。審査では PDF の文字（catalog/text.json）も見る。
    （例：マスカット ポールタイプII の MP2000-300 の行は、PDF の文字では「滑り止め／ポール付き」。検品の2人とも写真の説明「グリップボール」に引かれて「ボール付き」と読んだ）
17. **色の名前が表になく、写真の横・色見本の下にしかない商品**（2026-11-09 の検品でいちばん多かった誤り：39商品）：表に色の欄がないと、アプリは色を読めていなかった。
    1つの品番（品番がなければ注文番号）に色が2つ以上（「各¥」）なら、色ごとに1行。色の名前が1つだけなら、その色をその品番の言葉に入れる。
    「※ミディアムタイプはライトグリーンのみ」のような注記があれば、それに従う。
    **写真の横に1つだけある色の名前は、その写真の品番にだけ付ける**（ほかの品番は表に色がなければ色なし。p.51 入浴サポートクッションII の「ブルー」は 1126-A だけ、p.174 さわやかチェア 泉II の「ブラウン」は 8253 だけ）。
    写真が1枚で品番の札のない商品（p.44 ステンレス製浴槽台R の「レッド」）は、全部の品番に付ける。
18. **品番ごとにちがう機能**：機能アイコンは商品（囲み）に1組だけ。種類の言葉で分かれているときは、その言葉の品番だけの機能（p.174 さわやかチェアの「ひじ掛け跳ね上げ」は「はね上げタイプ」の品番だけ。「自在タイプ」はちがう）。
19. （住宅改修）**品番の形が決まりに当たらない表の行**：マツ六の表は「商品コード（040-7301 の形）｜品番」の並び。品番の形が BJ-14WD でないもの（P34NV-400-00・DX14C・35LB4R・EL5060-1M-NS・AF-1・ST-H1・SAQ-OP8・SD 450-90）は
    前のアプリは読めず、約120行に押す枠がなかった。検品の担当にわたした「参考（PDF の文字にあって枠のない品番の形の語）」も同じ形で作ったので、担当も気づけなかった。
    → **商品コードの行は全部に品番の枠があるか**を機械で見る（`jutaku-machine.py` の③）。表に品番が書かれていない商品（ステンレスパイプ・すべり止めテープ・ねじ・木製踏台 DX）は枠なしで正しい。
20. （住宅改修）**PDF の文字が欠けた・略した・品番でない品番**：TOTO p.51 の「TS139CEE11●」は PDF の文字では「TS139CEE1」（絵では 11）。「（T114CL9R・CL10R）」の CL10R は T114 を略した書き方（略した品番は枠にしない）。
    字を直した品番は、**枠が印刷された品番の字を全部囲んでいるか**も見る（直したあとの字で位置を探して、枠が右へずれたことがある）。
    イージーオーダーの「タイプ番号 TS134GMY-1」は品番ではない（「タイプ番号は品番ではありません」と書いてある）。「TS134・135・136型」「T112H型」は型の名前。
    → TOTO は**カタログの品番索引（p.101・102）にあるか**を機械で見る（`jutaku-machine.py` の④）。索引にあるのに枠のない品番（「2m：EWT22AG32」「◆CES9710C#NW1」のように前に字が付いたもの）も見る。
21. （住宅改修）**説明の文・注記・参照の表・写真の札の品番**：「※適応品番 BD-08・54」「（例）BD-01B」「ご注意の文の（BJ-32ST・BJ-105DB）」「対応たよレールの列の BZK-01」「写真の札 BZD-01（色の記号なし）」は、押す枠にしない。
    押すと色の決まっていない品番や、ちがう商品（ベースマットの行で手すり）が入る。同じページの表の行に同じ品番があれば、表の行の枠だけ残す。

## 書き方
- 数字は半角、金額はカンマなしの数（29700）。品番はカタログの字のとおり（全角・半角は気にしなくてよいが、ハイフン・スラッシュ・空白は字のとおり）。
- 結果は指示されたファイルに JSON で書く（Write ツール）。最後の返事はそのファイルの場所と件数だけ。
