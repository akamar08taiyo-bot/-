# 実務手順と受入条件

## 環境
SwiftPMかXcodeプロジェクトかを確認する。コンパイル、起動、実行時、テスト、署名、配布時の失敗を別に切り分ける。Linux上の構文検査をmacOS動作確認とは報告しない。
## 実装方針
状態の所有者と寿命を明確にし、SwiftUIで足りない範囲だけAppKitへ橋渡しする。複数ウィンドウ、設定、メニュー、キーボード、復元と画面外配置を確認する。
## 検査
小さい再現例からログを取得し、狭いテスト、関連テスト、アプリ動作へ進める。アクセス権やSandboxを解除して不具合を隠さない。個人情報をログへ残さない。
## 配布
ローカル開発署名と配布用署名を区別する。エンタイトルメントを最小化し、認証情報をパッケージへ同梱しない。公証と別環境起動は実施した範囲だけ報告する。
