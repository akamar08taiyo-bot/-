# 調査エージェントへの指示文の型

1観点につき1エージェント。`{ }` を埋めて、全エージェントを同じターンで起動する（順番に起動すると終わる時刻がばらつき、待ち時間が延びる）。
道具の確認結果（使える道具・使えない道具・回数の割り当て）は、先に自分で確かめてから埋める。各エージェントが同じ確認をくり返さずに済む。

```
{観点名}について、{開始日}〜{終了日}に公開された日本のお金系動画のうち、バズったものを調べてください。

目的：{誰を・何を調べるか。代表的なチャンネル名を例として挙げる}。名前を挙げたチャンネルは出発点です。期間中に伸びた新顔も探してください。

知りたいこと：
- 期間中に再生数が大きかった動画と、チャンネルのふだんの再生数（直近の中央値）より大きく伸びた動画（目安3倍以上）。タイトル原文・公開年月・再生数と出典・確認日・URL。
- タイトル・サムネ・冒頭フックで繰り返し出てくる型。
- 構成と尺で繰り返し出てくる型。
- どのトピックが、どの出来事・季節のときに伸びたか。
- {その観点に固有の問い}

守ること：
- 日本語の発信者・日本向けの動画に限る。期間外の動画は「期間外（参考）」と明記する。
- タイトルや数字を作らない。確かめられないものは「未確認」、出典で食い違うものは両方を書く。
- 道具：{例：WebSearch はこのエージェントの割り当て20回まで。WebFetch は遮断。Gemini は url_context での再生数取得に使ってよい。動画を見せるのは冒頭3分・2本まで。Google検索つき回答は手がかりのみ。402が出たら以後は使わない}
- メモは早めに保存し、進めながら更新する（上限で途中で止まっても成果が残るように）。

メモの形（日本語）：
- 冒頭に「できなかったこと」（上限で止まった調べもの、見られなかった動画）
- バズ動画の表（チャンネル／タイトル原文／公開年月／再生数／倍率／出典・確認日／URL）
- 見つかった型（タイトル／サムネ／フック／構成と尺／トピックと時期）。事実と推測を分ける
- 最後に「動画ネタへの示唆」を5〜10個（仮タイトル＋切り口＋なぜ伸びそうか＋借りた型）

保存先：{作業フォルダ}/research_notes/{レポートのタイトル}/{番号}_{観点名}.md
```

## 観点ごとの固有の問い（例）

1. 夫婦・家計・FIRE系：家計の実数や家族構成をどう見せると伸びるか。シリーズ名（「〜編」など）の効き方。
2. アニメ・漫画・合成音声：役割分担（無知役と解説役、ツッコミ）の型。2025年7月のYouTube収益化ポリシーの影響と、伸びているAI活用チャンネルの独自性の出し方。
3. 顔出し・講義系：オルカン対S&P500、高配当対インデックス、暴落時の行動など、くり返し伸びる論点。切り抜きの役割。
4. 経済ニュース・対談：どの出来事に結びついて伸びたか。伸びるゲスト。出来事から何時間以内に出すと効くか。
5. 実数公開系：数字を明かすタイミング。他人を撮らずに「実数の魅力」を出す方法（自分の数字、統計、アンケート）。
6. ショート：最初の1〜3秒のフック。長尺チャンネルのショートの使い方。各SNSと法令のルール。
7. 時事・制度カレンダー：期間中の需要の山（日付つき）と、この先の決定済み・検討中の制度変更と季節行事。
