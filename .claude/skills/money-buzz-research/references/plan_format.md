# 企画案の書き方

ユーザーが「少しだけ参考に」と渡してくれた形式（2026年10月）がもと。形式はこれに合わせ、中身は毎回の調査結果から作る。

## 長尺（Long-form）

```
### 【企画N】<企画をひと言で>
* **動画タイトル案**:
  1. <案1>
  2. <案2>
  3. <案3>
* **サムネイル文字案**:
  * 【左側】<短い言葉>
  * 【右側】<短い言葉>
* **構成要点**:
  * OP: <最初に何を言うか。フックの種類も（本音の代弁／損失回避／意外な事実／数字の連打）>
  * 本編: <見出しの並び。数字やシミュレーションの条件も>
  * ED: <まとめと、コメント・次の動画への誘導>
* **根拠**: <借りたバズ動画と型（チャンネル・タイトル・再生数）>
* **今出す理由**: <時期ネタとのつながり／定番>
* **注意**: <断定・仮定の条件・実体験の有無など。なければ省く>
```

- タイトル案の3つは型を変えて出す（例：数字＋〇選／逆張り・警告／シミュレーション・実録）。どの型が伸びるか試せるようにするため。
- サムネ文字は左右それぞれ10文字前後。タイトルと同じ言葉を繰り返さず、補い合う言葉にする。
- 構成要点の本編は、見出しを並べるだけでなく、使う数字や比較の軸まで書く。台本にするときに迷わないため。

### 例（ユーザー提供の形式から）

### 【企画1】資産500万突破時のマインド変化
* **動画タイトル案**:
  1. 【人生激変】資産500万円を超えた瞬間に「急に買わなくなったもの」TOP7
  2. 貯金ゼロから500万貯めて分かった「金持ち体質になるための断捨離」
  3. 【実体験】資産500万達成で散財がピタッと止まる理由と買わなくなったモノ
* **サムネイル文字案**:
  * 【左側】500万超えて「捨てた」
  * 【右側】買わなくなったモノ TOP7
* **構成要点**:
  * OP: 資産500万を超えると見栄や散財の欲求が消える現象（500万の壁）を提示。
  * 本編: 買わなくなったもの7選（コンビニの新商品／見栄のブランド品／流行りのガジェット／目的のない飲み会／安物買いの銭失いアイテム／リボ・分割払い／不要なサブスク）
  * ED: 資産が増えると心が安定し、無駄遣い自体がストレスになるというマインドの変化をまとめてコメントを促す。

（【実体験】の案は、本人に実際の経験とデータがあるときだけ使う。なければシミュレーションや統計の形に置き換える）

## ショート（Shorts）

```
### 【ショートN】<企画をひと言で>
* **タイトル**: <タイトル> #shorts #<タグ> #<タグ>
* **サムネイル枠内テロップ**: <短い言葉>
* **台本・展開（<秒数>秒）**:
  * 【0:00~0:03（フック）】<最初のひと言。画面の大きな文字も>
  * 【0:03~0:10】<1つ目>
  * 【0:10~0:18】<2つ目>
  * 【0:18~0:25】<3つ目>
  * 【0:25~0:30（オチ/誘導）】<保存・コメント・プロフィールへの誘導>
* **根拠** / **今出す理由**: 長尺と同じ
```

- フックは最初の3秒に入れる。数字、名指し（「〇〇な人」）、損失回避のどれかを入れると止まってもらいやすい。
- 誘導は1つに絞る（保存／コメント／プロフィールの動画）。いくつも頼むと、どれもされにくい。

### 例（ユーザー提供の形式から）

### 【ショート3】新NISAでやってはいけないこと
* **タイトル**: 新NISAで絶対にやってはいけないNG行動 #shorts #新NISA #投資初心者
* **サムネイル枠内テロップ**: 新NISAでコレやってたら即やめて！
* **台本・展開（25秒）**:
  * 【0:00~0:03（フック）】新NISAでコレやってる人、今すぐやめてください！
  * 【0:03~0:10】それは「毎日評価額をチェックすること」です。
  * 【0:10~0:18】株価の上下を見て焦って売却するのが一番の負けパターン。
  * 【0:18~0:25】積立設定をしたら画面を閉じ、存在を忘れるのが一番資産が増えます。忘れないように保存しておこう！

## money-shorts に渡すとき

ユーザーの money-shorts（シリーズ「1分でわかる お金のしくみ」）は、約60秒・18〜22行で、
フック（0〜6秒）→ 本題（数字やしくみ3つ前後）→ まとめ（チェックリスト）→ 締め（プロフィールのリンクへ誘導）の型。
そのまま渡すショート案には、上の形式に次を足す。

- 尺は60秒にし、秒数の区切りをこの型に合わせる。
- 各パートに見せ方の候補を添える（hook / title / number / word / rate / compare / checklist / cta）。
- 数字には一次情報の出典URLの候補を添える（最終確認は money-shorts 側で行う）。
- アフィリエイトにつなぐか（PR）と、TikTok版で外す誘導があるかを書く。
- TikTokの収益化（Creator Rewards）は1分を超える動画が対象とされる（要確認）。TikTok版を61〜75秒に延ばす余地があるなら、足す1〜2行の候補も書く。

## コピー用ページ（ワンタップでコピー）

ユーザーは企画をスマホで見ながら、タイトルや台本をコピーして使う。レポートとは別に、企画をJSONにまとめ、`scripts/make_copy_page.py` でコピーボタン付きのページにする。

```bash
python3 <スキルのフォルダ>/scripts/make_copy_page.py plans.json out.html
```

JSONの形（文章の中の `[ラベル](URL)` は、画面ではリンク、コピーでは「ラベル URL」になる）:

```json
{
  "title": "お金動画 企画コピー帳",
  "eyebrow": "2026年10月版 ・ バズ動画リサーチより",
  "lead": "ボタンを押すと、その部分がコピーされます。",
  "now": [{"id": "plan1", "when": "10月中", "label": "すぐ作る企画の名前"}],
  "sections": [
    {"id": "long", "heading": "長尺", "plans": [
      {"id": "plan1", "kind": "long", "no": "企画1", "when": "10月中", "name": "企画をひと言で",
       "titles": ["案1", "案2", "案3"], "title_types": "型：1＝…／2＝…／3＝…",
       "thumb": {"left": "左の文字", "right": "右の文字"},
       "op": "…", "body": ["①…", "②…"], "ed": "…",
       "caution": "…", "why": {"evidence": ["…"], "now": "…"}}
    ]},
    {"id": "short", "heading": "ショート", "plans": [
      {"id": "short1", "kind": "short", "no": "ショート1", "when": "11月中", "badge": "money-shorts向け", "seconds": 60,
       "name": "…", "title": "タイトル #shorts #タグ", "telop": "…",
       "script": [{"time": "0:00〜0:06", "label": "フック", "text": "…", "visual": "hook"}],
       "ms_notes": ["…"], "caution": "…", "why": {"evidence": ["…"], "now": "…"}}
    ]}
  ],
  "footer": ["数字は◯年◯月時点。制作前に一次情報で確かめる、など"]
}
```

- `id` は英数字だけにする（ページ内リンクに使うため）。
- コピーボタンは、企画まるごと／タイトル1案ずつ／サムネ文字／構成・台本の単位で付く。ショートには「money-shorts に頼む文でコピー」も付く（頼む文の頭は `money_shorts_prefix` で変えられる）。
- 「根拠」「今出す理由」は採るかどうかの判断材料なので、画面には出すがコピーには含めない。
- JSONは `reports/<タイトル>.plans.json` に保存しておく。あとで直して作り直せる。
