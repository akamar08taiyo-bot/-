# サムネイル・バナー・漫画

## 手順

1. **仕様を決める**: サイズ（YouTube 1280×720、X 1600×900、正方形 1080×1080 など）、案件、伝えたい一言（12文字前後）。
2. **案を3つ**: 文字（大見出し・小見出し）と構図の案を3つ出し、人間に選んでもらうか jeb-judge で1つに絞る。
3. **絵を作る**: 背景や人物・モノの絵は `ask-other-ai` で Codex に生成させる。プロンプトに「画像内に文字を入れない」と書く（文字は後から HTML で載せるほうが崩れない）。
4. **文字を載せる**: HTML で文字を組み（色・書体はデザインシステム）、Playwright で指定サイズのPNGに書き出す。
   ```js
   // 例: npx playwright を使い、page.setViewportSize({width:1280,height:720}) → page.screenshot({path})
   ```
5. **見た目の判定**: `node ai-ecosystem/scripts/judge-image.mjs --task "<一言と狙い>" out.png`。文字崩れ・個人情報・読みにくさを確認し、指摘を直す。
6. **漫画の場合**: コマ割り（4コマなど）と台詞を先に決め、コマごとに絵を生成。キャラクターは毎回同じ特徴文（髪型・服・色）をプロンプトに入れて揃える。既存の作品のキャラクターや画風には寄せない。
7. **検品**: `jeb-judge` に出して PASS なら `ai-ecosystem/output/<案件>/` に保存。

## 注意

- 他社ロゴ・有名人の顔・既存キャラクターは使わない。
- スクショを使う場合、個人情報が写っていたらモザイクをかけてから使う。

## 個人情報にモザイクをかける

1. `judge-image.mjs` の結果で `type` が `pii` の指摘を見る。`bbox` は画像の幅・高さに対する割合 `[x, y, w, h]`。
2. 画像のサイズ（`ffprobe -v error -show_entries stream=width,height -of csv=p=0 in.png`）を掛けてピクセルに直し、少し大きめ（上下左右に10px程度）にする。
3. その範囲だけモザイク（ピクセル化）にする（例: x=100, y=40, w=300, h=30 の範囲）。いったん1/10に縮めてから元の大きさに戻すので、文字1行分の細い範囲でも使える。
   ```bash
   ffmpeg -y -i in.png -filter_complex "[0:v]crop=300:30:100:40,scale=iw/10:-2,scale=300:30:flags=neighbor[m];[0:v][m]overlay=100:40" out.png
   ```
   範囲が複数あるときは、この処理を範囲の数だけ繰り返す。（`boxblur` のぼかしは、高さが小さい範囲だとエラーになるので使わない）
4. AIが返す範囲はずれることがあるので、モザイク後の画像をもう一度 `judge-image.mjs` に通し、読めないことを確かめる。
