# 権利・表記・公開のルール

AI で「本物らしい過去」を作るジャンルなので、**実在のものに似せない**ことと、**AIで作ったと分かるようにする**ことが信頼の土台になる。法律の判断が必要な場面では断定せず、ユーザーに専門家への確認をすすめる。

## 目次
1. 商標・実在の商品
2. キャラクター・作品・人物
3. 音楽（旋律・歌詞）
4. 写真の日付・文字
5. AI であることの開示
6. YouTube の方針
7. 概要欄・固定コメントの型

---

## 1. 商標・実在の商品
- 画面に実在のロゴ・商品名・メーカーの印を出さない。生成画像には勝手に出るので、全カットを拡大して確かめ、ぼかす・切る・作り直す（references/quality.md）。
- 指示文にも商品名を書かない。形と機能で書く（`small toy 4WD race car with side guide rollers`、`egg-shaped keychain virtual pet toy`）。
- 題名・概要欄・ハッシュタグで当時の流行として商品名に触れるときは、**登録商標であることを明記**する。実例：「『ミニ四駆』は株式会社タミヤ、『たまごっち』は株式会社バンダイの登録商標です。作中のおもちゃは当時の流行をイメージした架空のデザインで、実在の商品・企業とは関係ありません。」
- 表記の会社名・商標の持ち主は、公開前に検索で確かめる（社名の変更などがある）。

## 2. キャラクター・作品・人物
- 電子ペットの画面などに出すキャラクターは**オリジナル**（実例：ドット絵の「ぴこ」）。実在のキャラクターに似せない。
- アニメ調では `Original character design, not based on any existing anime character.` を入れる。
- 実在の人物（有名人・一般の人）に似せない：`Ordinary-looking people, no celebrities.`。実在の人の声にも似せない（TTS のプリセット声を使う）。
- 実在の店・学校・地名をそれと分かる形で出さない（架空の「海辺の町」にする）。

## 3. 音楽
- BGM は Lyria で生成するか、コードで作曲したオリジナル（synth_music.py）。既存曲のアレンジは使わない。
- 童謡・唱歌などの旋律を使うときは、**作曲者の没年**を確かめて保護期間が終わっているか判断する。日本では、作者の死後50年までだった時代に保護が切れた作品は、2018年の70年への延長で復活しない（1967年以前に亡くなった作者の作品は切れている）。
  - 実例：夕方5時のチャイム「夕焼け小焼け」— 作曲：草川信（1948年没）→ 旋律は保護期間終了。作詞：中村雨紅（1972年没）→ 歌詞は2018年の延長で2042年末まで保護 → **歌詞は使わない**。
- 旋律は複数の資料の階名（ドレミ）で照合してから打ち込む（間違った旋律は「似ているけど違う」違和感になる）。
- 概要欄に、曲名・作曲者・保護期間が終わっていること・歌詞は使っていないことを書く。

## 4. 写真の日付・文字
- 作中の日付（'97 8 2 など）は物語の中の架空の日付。実在の出来事と結びつけない。
- 生成画像に入った崩れた文字・英字はぼかす（読めそうで読めない文字はAIっぽさの元にもなる）。

## 5. AI であることの開示
- 概要欄の最初の方に「実在の記録ではなく、AIで作った再現・フィクションです」とはっきり書く。使ったAI（画像・動画・音楽・声）も書く。
- 写実的なAI映像なので、YouTube のアップロード時に「改変または合成されたコンテンツ」の申告を**オン**にするよう、ユーザーに伝える（ユーザーの操作が必要）。
- 「存在しない記憶」「捏造」という批判がこのジャンルにはある。歴史の記録のように見せない（「〇〇年の実際の映像」などと書かない）。

## 6. YouTube の方針（2026年時点の要点。公開前に最新を確認）
- 収益化：大量生産・くり返しの「オリジナリティのない」コンテンツは収益化の対象外になりうる（2025年7月に「繰り返しの多いコンテンツ」の方針が「inauthentic content（オリジナリティのないコンテンツ）」に改められた）。→ 物語・演出・音を作品ごとに作り込み、テンプレートの使い回しに見せない。投稿者自身の言葉（固定コメントの制作意図）を添える。
- 改変・合成コンテンツの申告（5.）。
- 子どもが出る映像：実在の子どもではないが、子どもを性的・危険に見せる演出は一切しない。

## 7. 概要欄・固定コメントの型
**概要欄**（description_template.txt。`{chapters}` と `{afterglow_start}` は finalize.py が差し込む）：
```
<一行のコンセプト>

<年・時代の一言>。<何を描いたか>を、AIで描きました。
後半（{afterglow_start}〜）は、環境音とピアノだけの時間です。作業や、おやすみ前にどうぞ。

<問いかけ>（例：あなたの1997年の夏は、どんな夏でしたか。<あるあるを3つ>……コメントで教えてください。）

▼チャプター
{chapters}

▼制作について
・これは実在の記録ではなく、AIで作った再現・フィクションです。
・映像：<画像AI> で作った画像を、<動画AI>・プログラムの演出で動かしています。
・音楽：<Lyria／オリジナル>。環境音・効果音：プログラムで合成。声：<TTS>。
・<旋律の出典と保護期間>
・登場人物・お店・出来事はフィクションです。<商標の表記>

#ハッシュタグ（時代・題材・ジャンル・作業用 など）
```
**固定コメント**：制作意図を短く語り、最後に問いかける（参考作で効いていた型）。
```
この動画では、<時代>の<場所>で過ごした<誰>の「<何>」を描きました。
<こだわった所・あるあるを1〜2文>
皆さんの<時代>の<季節>は、どんな<季節>でしたか？ <思い出しやすい例> など、コメントで聞かせてください。
```
