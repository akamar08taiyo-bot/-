# リサーチの手順（参考動画・同ジャンル・時代考証）

目的は「何がなぜ伸びているか」をつかみ、自作で**まねる所**と**変える所**を決めること。結論は `分析レポート.md` に書く（実例：`assets/example/分析レポート_蘇らせた系.md`）。

## 目次
1. 参考動画を読む（Gemini に YouTube を直接見せる）
2. 長さ・終わりの確かめ方
3. 同ジャンルの一覧と再生数（検索つき）
4. 記事・評判・懸念
5. コメント欄について
6. 時代考証（年・流行・発売時期）
7. 分析レポートの型
8. 型の見分け：「蘇らせた」型と「存在しない街」型

---

## 1. 参考動画を読む
このクラウド環境から youtube.com は開けない（403）。代わりに **Gemini に URL を添付**すると、動画の中身（映像・音・字幕）を読んで答える。

```bash
python3 scripts/gem.py --youtube "https://www.youtube.com/watch?v=VIDEO_ID" --start 0s --end 300s \
  --prompt-file research/p_deep.txt --out research/v_VIDEO_ID.md --think low
```
- **読めるのは冒頭およそ5分まで。** それより後ろの区間（`--start 300s` など）は 500 エラーになることが多い。長い動画は冒頭の分析で型をつかみ、残りは検索や概要欄で補う。
- 長い動画全体を粗く見たいときは `--low`（低解像度）や `--fps 0.5`。
- 失敗（500/502）は時間をおいて再試行。`--think low` にすると通りやすい。

分析の指示文（p_deep.txt の例。事実と推測を分けさせるのが大事）：
```
この動画を、同じジャンル（AIで過去の日本を“蘇らせる／再現する”動画）の新作を企画・制作するための資料として、徹底的に分析してください。日本語で、確認できた事実と推測を区別してください。
1. 基本：動画の長さ、画面比率、画質の印象、画面に出る文字（タイトル、年代・場所の表記、字幕、クレジット）を原文で
2. 冒頭15秒：秒単位で何を見せ・聞かせ、どう引き込んでいるか
3. 構成：mm:ss 付きのシーン一覧（全部）。シーン数と平均カット長。章立てや流れ
4. リアルさの作り方：写真風か映画風か、色調、フィルムの粒子、レンズ感、画角、照明、時代考証の小物、人物。AI特有の破綻（手・顔・文字）
5. 動き：人物が動いているか（瞬き・歩く・笑う）、カメラワーク。静止画にカメラ移動をつけただけか、動画生成AIで動かしているか
6. 音：BGM（曲調・楽器）、環境音、ナレーション・セリフの有無と原文
7. 感情の設計：どこで何を感じさせているか
8. 視聴者が「すごい」「懐かしい」と感じるポイントと、コメント欄で語られそうな話題（推測）
9. 弱点・違和感・離脱しそうな箇所
10. この動画の「型」を再現するレシピ（箇条書き）
```

## 2. 長さ・終わりの確かめ方
検索結果の「長さ」はよく間違っている（実例：5分06秒の動画が「11分54秒」と出た）。**終わりの区間を見せて確かめる**：
```bash
python3 scripts/gem.py --youtube URL --start 290s --end 320s --out research/end.md --prompt-file research/p_end.txt
# p_end.txt：「この区間は動画の最後の部分かどうかを判断してください。映っているもの、音、画面の文字を時刻付きで書き、映像が終わる（フェードアウト・黒画面・終了画面）ならその時刻を書いてください。」
```
動画の長さより後ろを指定すると 400 エラーになるので、それも手がかりになる。

## 3. 同ジャンルの一覧と再生数
```bash
bash scripts/gsearch.sh research/q1.txt research/a1.md     # Google 検索つき。出典は a1.md.grounding.json
```
指示文の例：
- 「YouTube チャンネル『〇〇』の投稿動画をできるだけ多く一覧に。タイトル（原文）、動画ID、公開日、再生回数、長さ。推測で埋めず不明は『不明』。出典URLも。最後に再生回数の多い順に上位5本」
- 「『AIで蘇らせた』『AIで再現』『〇〇年前の日本』『平成をAIで』などのタイトルで人気の動画（日本語圏、直近1〜2年）。チャンネル名、タイトル、動画ID、再生回数、長さ、映像の作り（実写風／アニメ風、静止画／動画AI）」
- 気になった上位作は 1. の方法で中身も見る（再生数だけで型を決めない）。

再生数・公開日は資料ごとに食い違うので「目安」と書く。

## 4. 記事・評判・懸念
「AIで昭和を再現した動画が話題」などの記事を検索させ、①人気の理由 ②視聴者の反応（原文） ③批判・懸念（「存在しない記憶」「捏造」「不気味の谷」） ④使われたツール をまとめる。懸念は概要欄の開示や演出で先回りして対処する（references/rights.md）。

## 5. コメント欄について
**YouTube のコメント本文は取れない**（動的に読み込まれるため、Gemini の動画読み込みにも URL 読み込みにも入らない。`&lc=` 付きのリンクも同じ）。
- ユーザーが特定のコメントを参考にしたいときは、**本文を貼ってもらう**よう頼む。取れなかったことは正直に伝える。
- 代わりにできること：投稿者の固定コメント・概要欄を検索で探す（記事やまとめに引用されていることがある）、同ジャンルの記事に引用された視聴者の声を集める、「コメント欄で語られそうな話題」を動画の中身から推測する（推測と明記）。
- 実例：参考作の投稿者は、固定コメントで制作意図を語り、最後に「皆さんにも、音を聴くだけで戻れる『あの夏』はありますか？」と問いかけてコメントを集めていた → 自作でも同じ形の固定コメントを用意した。

## 6. 時代考証
年を決めるときは、題材の流行が**重なる年**を出典つきで選ぶ（例：1997年＝ミニ四駆の第2次ブームとたまごっちブームが重なる）。
- 発売年・ブームの年・当時の価格（駄菓子・お小遣い）・家電（ブラウン管テレビ、扇風機）・車・街の看板の有無などを検索で裏取りする。
- その時代に**なかったもの**を一覧にしておくと、画像の検査（check_images.py）と指示文の禁止事項に使える（例：1997年にスマホ・薄型テレビ・携帯ゲーム機の新しい型はない）。
- 実在の曲を使うなら作曲者・作詞者の没年を確かめる（references/rights.md）。

## 7. 分析レポートの型
```
# 分析レポート：〇〇系動画
調査日・方法（Gemini の動画読み込み＋検索）。再生数は目安。
## 0. 結論（要点）… 伸びている型、型の中身（カット長・字幕・音）、冒頭のフック、自作の方針
## 1. 参考動画の事実（長さの訂正・固定コメントなど）
## 2. 調べた動画（表：動画／再生回数／長さ／作り）
## 3. 型の分解（表：要素／上位作の共通点／理由（推測））
## 4. 視聴者が反応するポイント
## 5. 自作への反映（表：学び／自作での使い方）
## 6. ユーザーの追加要望とその反映先
```

## 8. 型の見分け：「蘇らせた」型と「存在しない街」型
同じ「AIのノスタルジー動画」でも、作りが大きく違う2つの型がある。依頼の参考動画がどちらかを 1. の方法で見分けてから企画する。

| | 「蘇らせた」型 | 「存在しない街」型 |
|---|---|---|
| 例 | 「40年前の昭和の夏をAIで蘇らせた」（実例の参考動画） | 「存在しない街の記憶」（昭和レトロ×空中・海上の巨大都市。2026年10月に調査） |
| 舞台 | 実在した時代のありふれた町（架空の人物・店） | 現実にはない街（重なり合う立体都市など）＋昭和・平成の暮らし |
| 物語 | ひと夏・数日の出来事（友情・初恋・別れ） | 何年分もの人生（学校の四季→社会人の苦労→子の誕生と成長） |
| カット | 8〜12秒、クロスフェード、静止画＋カメラ＋要所だけ Veo | 3〜6秒、ふつうのカット切り替え（章の区切りだけクロスフェード）、ほぼ全カットが動く |
| 文字 | 章の入口に小さな日英キャプション | テロップなし。看板・駅名・黒板など**画面の中の日本語**だけ（正しい日本語で） |
| つかみ | 色あせた写真が色づいて動き出す | 1カット目で「ありえない規模の街」を見せる（校門の奥にそびえる都市） |
| 音 | 環境音中心＋BGM、セリフ少し | ピアノ中心の劇伴＋細かい生活音（ほうき・紙・食器・電車・波）、言葉にならない声（笑い声・赤ちゃん・「パパ」） |

「存在しない街」型で作るときのこのスキルの使い方：
- カットを短く（dur 4〜6、xfade は短く）、`reveal` と章のキャプションは使わない。カット数が増え、ほぼ全カットを Veo で動かすので、費用は Veo だけで 60〜80本×$0.64 ≈ $40〜50。先に伝える。
- 画面の中の文字は「文字なし」と書かず、看板・駅名標・黒板の文字を指示文で**正確に指定**する（実在しない地名・校名にする）。zoom_grid.py で崩れを確かめる。
- 生活音は効果音（sfx）でカットごとに置く。言葉にならない声（笑い声・呼びかけ）は SFX_VOICES の TTS で作る。
- 参考チャンネルの名前・シリーズ名・街の設定（例：「昭和101年」「雲海〇〇」）はまねない。型だけ借りて、街と人生は自分で作る。チャンネル名も似せない（視聴者が混同する）。
