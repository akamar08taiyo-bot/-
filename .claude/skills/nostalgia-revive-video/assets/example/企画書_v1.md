## 2. 企画の芯

- **コンセプト**：「夏休みは、単三電池でできていた。」
  レーサーも、ゲーム機も、電子ペットも、ぜんぶ電池で動いていた。電池が切れると夏も終わる。29年後、新しい電池を入れると――モーターはまた回り、画面にはたまごが現れる。
- **ターゲット**：1985〜1990年生まれ（現在36〜41歳）。実家の片付け・親の家じまいが身近になる年代 → 冒頭の「取り壊し前の実家で缶を開ける」に共感。
- **狙う感情**：懐かしさ → 楽しさ → 夕立と夕焼けの切なさ → 別れ → 「まだ動く」小さな希望 → 余韻。
- **落ち着かせる設計**：1カット8〜9秒の一定リズム／急な大音量なし（雷・花火も遠く）／ナレーションなし／後半5分は物語なしの環境音。

## 4. 映像の仕様
- 画像：Gemini 3 Pro Image（2752×1536）。登場人物は設定画（`assets/chars/`）を毎回参照させて顔・服をそろえる。
- 絵柄：アニメ映画の背景美術風・手描きの質感・逆光と木漏れ日。特定スタジオの模倣はしない指示。
- 動き：ゆっくりズーム／パン（5〜9%）、クロスフェード、光の粒・光の筋・雨・花火のちらつき、フィルム粒子、周辺減光、やわらかいにじみ。プロローグ→1997年は白く抜ける転換。
- 電子ペットの画面：ドット絵はオリジナルキャラクター「ぴこ」をコードで描画（ごはん→ハート、おばけ、たまご）。実在商品のキャラクターは使わない。
- 写真の日付：フィルムカメラ風のオレンジ7セグ数字をコードで描画。
- 色：1997年はやや暖色、2026年は少し冷たく落ち着いた色。

| プロローグ | ピアノの小品（Lyria 3 clip） | 秋風、遠くの鳥、缶のふた |

| 午後 | オルゴール（オリジナル曲・コード合成）※ | アブラゼミ、風鈴、雷、夕立、通信ゲームの電子音、ひぐらし |
| 夕方 | なし（チャイムを主役に） | 5時のチャイム「夕焼け小焼け」（旋律のみ・合成）、ひぐらし、川、テレビのナイター |
| 夜〜晩夏 | ピアノ＋弦（Lyria 3.5） | 祭りのざわめき・太鼓、花火（遠め）、スズムシ、大会のざわめき |
| 別れ〜エピローグ | ピアノ→弦→ピアノ（Lyria 3.5） | トラック、すすきの風、電池・スイッチ・モーター、電子ペットの「ピッ」 |

- 音量：-14 LUFS（YouTube基準）、トゥルーピーク -1.5 dBTP 以下。
- ※ 制作途中で Gemini API の前払いクレジットが尽きたため、午後と余韻のBGMは Lyria の代わりにコードで作曲・合成。環境音・効果音はすべてコード合成（権利フリー）。

## 6. 権利・ポリシーの注意
- **商標**：「ミニ四駆」はタミヤ、「たまごっち」はバンダイの登録商標。映像内の車・電子ペットはロゴなしの汎用デザイン。生成画像に出た実在ブランド風のロゴ・車名（S08の箱、S12の箱、S16の車、S07のロボット風の箱）はぼかし／画面外に。タイトル・概要欄で商品名を使う場合は「当時の流行を指す説明」にとどめる（公式と誤認させない）。最終判断はご自身で。
- **AI生成の開示**：アニメ調で写実的ではないため YouTube の「改変・合成コンテンツ」の開示は必須対象外の可能性が高いが、概要欄に AI 使用を明記する。
- **収益化（量産型コンテンツ方針）**：テンプレの量産に見えないよう、毎回オリジナルの物語・登場人物・構成を変え、投稿者自身の思い出や一言を概要欄に添える。
- **音楽**：Lyria 生成曲・コード合成曲・パブリックドメインの旋律のみ。既存曲は使わない。

## 8. 長時間視聴のための展開
1. **本編（今回）**：11分53秒。後半5分は環境音パート。
2. **1時間版（作業用）**：同じ素材で「あの夏の音」を各カット3〜5分に延ばし、昼→夕→夜→朝の順で約60分。チャプター付き。追加の画像生成なしで作れる。

## 10. 制作の流れ（再現手順）
```
python3 pipeline/storyboard.py      # 絵コンテ → scenes.json / 絵コンテ.md
python3 pipeline/gen_scenes.py      # 画像生成（既存はスキップ、--only ID で作り直し）

python3 pipeline/synth_music.py     # BGMのコード合成分
python3 pipeline/render.py --stills # 確認用の静止画
python3 pipeline/render.py          # 映像
python3 pipeline/mix.py             # 音（-14 LUFS）
python3 pipeline/finalize.py        # 結合・字幕・概要欄・検査
```
