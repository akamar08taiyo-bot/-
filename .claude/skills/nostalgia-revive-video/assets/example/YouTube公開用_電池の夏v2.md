## 6. チャンネル名

**おすすめ：記憶現像所（きおくげんぞうしょ）**

| 名前 | 理由 | 合う型 |
|---|---|---|
| **記憶現像所** ← おすすめ | 毎回の冒頭「色あせた写真が色づいて動き出す」を、そのまま名前にした。「存在しない記憶を現像する」とも読める。写真屋の「現像」は昭和・平成の世代に懐かしい言葉 | どちらの型にも |
| 見知らぬ故郷（みしらぬこきょう） | 行ったことがないのに懐かしい、という気持ちをそのまま名前にした | 架空の街の型（いただいた参考動画の型） |
| 記憶の縁側（きおくのえんがわ） | 座って昔を思い出す場所。物語にも、環境音だけの長い動画にも合う | 蘇らせた型・環境音 |
| おもいで再生 | 「再生」が「動画の再生」と「よみがえる」の両方の意味。いちばん覚えやすい | どちらの型にも |
| 夕方5時のチャイム | 子どもの頃の「帰る時間」の合図。ただし、市町村のチャイムを探す人の検索と混ざる | 蘇らせた型 |

「記憶現像所」にする場合：
- @ハンドルの例：`@kioku_genzosho`（日本語の `@記憶現像所` も使える）
- バナーの一言：「一枚の古い写真から、あの日をもう一度。」
- 動画の通し番号：「現像 No.001 電池の夏 1997」のように、概要欄や画面の端に入れるとシリーズになる
- チャンネルの説明（「チャンネルのカスタマイズ」→「基本情報」→「説明」にコピー）：
```
記憶現像所へようこそ。
ここでは、一枚の古い写真から、あの頃の町と夏休みをAIで「現像」しています。
昭和・平成の、どこにでもあって、もうどこにもない毎日。
作業のおともに、眠る前に、ゆっくりどうぞ。

※映像はAIで作った再現フィクションです。実在の人物・場所・お店とは関係ありません。
```

避けた方がよい言葉：「存在しない〇〇」「架空都市」「昭和101年」「雲海」など、すでにあるチャンネル「存在しない街の記憶」を思わせる言葉（視聴者が混同する）。
決める前に：YouTube で同じ名前のチャンネルがないか検索し、@ハンドルが空いているかを確かめる（ウェブ検索では、どの候補も同じ名前のチャンネルは見つからなかった）。
