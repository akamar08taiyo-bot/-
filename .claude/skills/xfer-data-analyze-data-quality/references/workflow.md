# 実務手順と受入条件

## 定義を固定する
指標は名称、計算式、分母、対象、除外、時間帯、更新周期をセットで扱う。前年比と増減率、割合とパーセントポイントを分ける。
## 前処理の検査
入力件数、主キー重複、欠損、型、単位、更新日時を確認する。結合前後の件数と総額を比較し、多対多結合による増殖を検出する。元データを残して変換規則を記録する。
## 分析を再現する
集計コードと出典を保存し、重要数値は別の式またはサンプル照合で確認する。期間の長さ、季節性、セグメント構成の変化を点検する。相関、仮説、因果の証拠を混同しない。
## 表示と結論
図表に単位と対象期間と欠測の扱いを添える。結論は証拠に対応させ、未確認の要因を断定しない。フィルターや書き出し後にも数値が一致することを確かめる。
