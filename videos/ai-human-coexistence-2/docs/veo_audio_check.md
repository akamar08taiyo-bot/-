# Veo の音の点検（第二章）

スペクトログラム（work/spec/sheet*.jpg、0〜8 kHz・対数）で、頼んでいない音楽（音程が段々に変わる持続音）を探した結果。

| カット | 判定 | 扱い |
|---|---|---|
| C6 柱の傷 | 300〜400 Hz に段々に変わる持続音（旋律の疑い） | Veo の音を使わない（柱時計・蝉・遠い波の合成音） |
| E4 屋上の三人 | 中域に短い音程の並び（旋律の疑い） | Veo の音を使わない（虫・夜の海） |
| P0 2026年の浜 | 200 Hz 台の平らな持続音（ドローンの疑い） | Veo の音を使わない（風・波） |
| R1 神社の秋 | 4秒目以降にサイレン状の音（頼んだ「遠いサイレン」） | 後半は顔が映るため 3.4 秒で切る＝使わない部分 |
| B4・R2・R6 | 子どもの歓声・汽笛・カモメ（聞き取れる言葉ではない） | 使う |
| ほか | 環境音のみ | 使う |
