# 第二章「砂の向こうから来た男」台本

## 作品の顔

- **シリーズ**：AIと人間の共存
- **章題**：第二章「砂の向こうから来た男」（第一章の次回予告で予告済み）
- **テーマ**：変わっていくものと、変わらないもの。僕の大好きなあの頃は、そのままに。
- **ログライン**：祭りの翌朝、スーツの男が砂丘の向こうから継町へ帰ってくる。四十年前、人が減っていく島を、十歳で去った少年だった。島には、残る人たちのために作られた一台のロボットが、今も男の帰りを待っていた。
- **日付**：2080年8月25日（日）。第一章の翌日（序は第一章と同じ祭りの夜、回想は2040年の夏）
- **尺**：8分5秒・31カット（序25秒、結32秒、ほかは16秒、1.2秒ずつ重ねる）
- **語り**：ナレーションなし。短い字幕と町の音だけ。最後にあいさつの声

## あらすじ

祭りの夜、町はずれの砂丘。スーツの男は、ロボットが運転するトラックのそばで、海の向こうに上がる町の花火を見ていた。

夜が明けると、トラックは男を町まで乗せていく。海岸のごみ拾いでは、知らない人の男にも軍手が配られる。男はスーツのままラジオ体操の列にならび、胸ポケットから一枚のカードを出す。四十年前のラジオ体操カード。最後の一日、八月二十五日だけ、はんこが空いている。ロボットの先生が、その枠にはんこを押す。

知らない塔が増えた町。それでも銭湯の下足札は木のままで、子どもの頃の駄菓子屋はロボットが継いでいた。渡し船の乗り場で荷を運ぶ古いロボットの背中を、男は知っていた。

四十年ぶりの島への船。団地の一室の、木の引き戸だけは今も手で開ける。ちゃぶ台には、毎日ふたつ用意されてきた麦茶。縁側で昼寝をする男を、ロボットはうちわであおぎ続ける。けれど、その風がやみ、灯りがふっと消える。柱の背くらべの傷は、十歳で止まったまま。

（回想）四十年前。島から、少しずつ人が減っていった。島に残る人たちのために、一台のロボットが作られた。少年とロボットは毎朝いっしょに島の階段をのぼった。窓の灯りはひとつ、またひとつ消え、その夏で学校は閉じることになった。最後の祭りの夜の約束。八月二十五日の朝、少年は小さな包みを握って、島を出た。

電器店に、替えの部品はもうない。男が鞄から出したのは、あの朝ロボットがくれた「お守り」。ロボット自身の、灯りの部品だった。五時のチャイムとともに、灯りが戻る。

夜。中華そばの味は変わっていない。島へ戻る船から見ると、消えていった窓に、また灯りがともっている。屋上で、第一章の子どもと線香花火をする。ロボットの光の帯に「おかえりなさい」の文字が流れる。四十年前の約束を、男はもう一度口にする。「来年も、いっしょに見ようね。」「ピ。」

## 登場するもの

- **男**：五十歳。濃紺のスーツ、白髪まじりの短い髪、焦げ茶の革の鞄。十歳の夏まで継島で育った。どこで何をしてきたかは語らない。画面では**後ろ姿・遠景・手元だけ**（顔は映さない）
- **少年**（回想、四十年前の男）：十歳。白い半袖に半ズボン、麦わら帽子。祭りの夜は甚平。後ろ姿と遠景だけ
- **古いロボット**：島に残る人たちのために作られた、町でいちばん最初の一台。町のロボットと同じ姿（アイボリーの丸い体、顔の代わりの琥珀色の光の帯、目も口もない）。今は塗装がはげ、色の違う継ぎ当てがあり、肩に手書きの小さな番号がある（回想ではまだ新しくてきれい）。灯りの部品が古くなり、ときどき揺らぐ。話さない（「ピ。」と鳴く／光の帯に文字を流す）
- **トラックのロボット運転手**：第一章の予告と同じ、ミント色の軽トラック
- **ロボットの先生**：第一章の透明な黒板の先生。夏休みはラジオ体操の係
- **駄菓子屋のロボット**：おばあちゃんの店を継いだ
- **電器店の主人**：第一章の「継町電器」。回想でロボットを作った職人の跡継ぎ。後ろ姿
- **中華そばの親方とロボット**：第一章と同じ店
- **屋上の子ども**：第一章の屋上で、ロボットと花火を見ていた子。甚平
- **小道具**：ラジオ体操カード（2040年の夏）、お守り（光の帯の部品を色あせた手ぬぐいで包んだもの）、麦茶のグラスふたつ、柱の傷、がたつく木の引き戸、線香花火

| 古いロボットの部品は製造終了 | 線香花火、屋上の約束 | 四十年前のお守りで灯りが戻り、「おかえりなさい」 |

## 第一章とのつながり

- 予告の砂丘とミント色のトラック → 序と一（同じ夜、男は砂丘から町の花火を見ていた）
- 回覧板「海岸のごみ拾い　8/25（日）朝6時」 → 一の海岸のごみ拾い
- 「牛乳は、今も瓶で届く。」 → 回想で、少年とロボットが牛乳を配っていた
- 「扉は、何もしなくても開く。」 → 「この戸だけは、今も手で開ける。」
- 居間「誰かが、さっきまでここにいた。」 → 「あの日から、麦茶は毎日ふたつ。」（誰が待っていたのかが分かる）
- 「ひとつ、またひとつ、窓に灯りがともる。」 → 回想の「窓の灯りが消えていく。」 → 「消えていった窓に、また灯りがともっている。」
- 電器店「古い扇風機は、捨てずに直す。」 → ロボットも、生まれた作業台で直される
- 「五時のチャイムが、海の向こうまで響く。」 → 灯りが戻る合図
- 中華そば「味は、親方から教わったもの。」 → 「中華そばの味は、変わっていなかった。」
- 屋上の二人「来年も、いっしょに見ようね。」「ピ。」 → 四十年前の同じ約束（回想）→ 男がもう一度口にする
- 町の名前の「継」（受け継ぐ・継ぎを当てて直す） → 町のロボットは最初の一台の姿を受け継ぎ、店はロボットが継ぎ、ロボットはお守りの部品で直される

## 制作メモ

- **原画**：新しく約30枚。第一章と同じ場所（砂丘＝T0、居間＝C6、電器店＝B4、中華そば＝C1、屋上＝E4、深夜の継島＝F0、島の階段＝A2）は、第一章の原画を参照画像に渡して同じ場所に見せる。居間（C3）は第一章の部屋の中をそのまま使い、窓の外だけ島の団地と海にする
- **回想（R1〜R7）の見た目**：2040年の島は今より古び、新しい塔も飛行車もない。黒板は透明ではなく緑の黒板。色を少し褪せさせて暖かく、粒子を強めにし、周辺を暗くする（合成の最後に回想用の質感をかける）。回想の電器店（R2）と今の電器店（D1）は同じ作業台・同じ灯りの構図にする。R4 と E2 も同じ構図にして、灯りが消える／ともるを対にする
- **男と少年**：顔を映さない（後ろ姿・遠景・手元）。男は全カットの指示文に「濃紺のスーツ、白髪まじりの短い髪、焦げ茶の革の鞄」、少年は「白い半袖、半ズボン、麦わら帽子（祭りの夜は甚平）」を入れて、同じ人に見せる
- **古いロボット**：町のロボットと同じ設計（目も口もなく、顔の代わりに琥珀の光の帯）。今は塗装のはげ・色の違う継ぎ当て・肩の手書きの番号で古さを出し、回想ではきれいな新品にする。「光の帯が揺らぐ・消える・戻る」は Veo に頼み、足りなければ合成で明滅を足す
- **手元のカット**（A4・B2・C2・C5・D2）は手の形が崩れやすい。Veo の結果を必ず確かめ、崩れたら動きを小さくする
- **文字**：電子版（A2・A3・D1）。カードとはんこ（A4）は第一章の回覧板と同じ「板に貼る表示＋はんこ」。黒板の「ありがとう　継島小学校」（R5）は第一章の黒板と同じチョークの表示。「おかえりなさい」（E4）は光の帯のすぐ上に小さな電子版でも出して読めるようにする
- **音**：回想は環境音を遠く、こもった音にする（昔の記憶の音）。実在のラジオ体操の曲は著作権があるので使わない（オリジナルの短い伴奏か、波と掛け声だけ）。五時のチャイムは第一章のオリジナル旋律。R7 の汽笛は長く
- **テーマ曲**：第一章の主題を使う。回想はオルゴールだけで静かに、四の「灯りが戻る」で主題を明るく、結で静かに閉じる
- **もうひとつの世界線**：第一章と同じ扱い。砂丘・スーツの男・鞄・ロボットのトラックという雰囲気だけで、作品名・人物・ロゴ・音楽は使わない。公開するタイトル・概要欄・タグにも作品名を入れない
- **費用の目安**：約25〜30ドル（画像 約30枚＋Veo Lite 31本）
