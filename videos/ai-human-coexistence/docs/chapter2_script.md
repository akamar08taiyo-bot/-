# 第二章「砂の向こうから来た男」台本

## 作品の顔

- **シリーズ**：AIと人間の共存
- **章題**：第二章「砂の向こうから来た男」（第一章の次回予告で予告済み）
- **テーマ**：変わっていくものと、変わらないもの。僕の大好きなあの頃は、そのままに。
- **ログライン**：祭りの翌朝、スーツの男が砂丘の向こうから継町へ帰ってくる。四十年前、人が減っていく島を、十歳で去った少年だった。電話を木の箱にあずけて遊ぶ町で、男は昔の遊びと思い出に出会い直す。島では、残る人たちのために作られた一台のロボットが、交換日記を書き続けながら、男の帰りを待っていた。
- **日付**：2080年8月25日（日）。第一章の翌日（序は第一章と同じ祭りの夜、回想は2034〜2040年）
- **尺**：8分34秒・33カット（序25秒、結32秒、ほかは16秒、1.2秒ずつ重ねる）
- **語り**：ナレーションなし。短い字幕と町の音だけ。最後にあいさつの声

## この章で描くこと（作者の想い）

- 時代が進むなかで、昔の懐かしい思い出がよみがえると、懐かしくて切なくなる。
- 時代が変わって進化しても、昔の思い出は消したくない。
- タイムスリップしたかのような体験とともに、一周して、昔の懐かしさや良さ、遊びに気づくときが帰ってくる。
- 携帯電話を手放す。その代わりに、ミニ四駆や遊戯王、将棋で遊ぶ。秋の遊びもある。
- 授業参観、交換日記、夢やお父さんの仕事の発表。回想を交えながら、夢のある未来の世界も日々進化していく。

## あらすじ

祭りの夜、町はずれの砂丘。スーツの男は、ロボットが運転するトラックのそばで、海の向こうに上がる町の花火を見ていた。

夜が明けると、トラックは男を町まで乗せていく。男はスーツのまま浜のラジオ体操の列にならび、胸ポケットから四十年前のラジオ体操カードを出す。最後の一日、八月二十五日だけ、はんこが空いている。ロボットの先生が、その枠にはんこを押す。

知らない塔が増え、今も新しくなり続ける町。子どもの頃の駄菓子屋はロボットが継いでいて、日曜の子どもたちは、電話を木の札と引きかえに箱へあずけて遊んでいる。男も電話をあずける。裏のコースで小さな四駆が走りだすと、モーターの音で時間が巻き戻る。四十年前、同じコースで、少年とロボットが同じ車を走らせていた。縁台ではカードゲームと将棋。時代は一周して、昔の遊びが帰ってきていた。渡し船の乗り場で荷を運ぶ古いロボットの背中を、男は知っていた。

四十年ぶりの島への船。団地の一室の、木の引き戸だけは今も手で開ける。ちゃぶ台には、毎日ふたつ用意されてきた麦茶。机の上には交換日記。少年の字のあとに、ロボットのていねいな字が四十年ぶん続いていた。最後のページは、きのうの日付。「来年も、いっしょに見ようね。」縁側で昼寝をする男を、ロボットはうちわであおぎ続ける。けれど、その風がやみ、灯りがふっと消える。柱の背くらべの傷は、十歳で止まったまま。

（回想）四十年前。島から、少しずつ人が減っていった。残る人たちのために、一台のロボットが作られた。秋には、落ち葉で焼きいもをした。窓の灯りはひとつ、またひとつ消えていく。最後の授業参観、砂漠で働く父のかわりに、ロボットが教室のうしろに立っていた。少年は作文を読む。父の仕事のこと。島に帰ってくるという夢のこと。最後の祭りの夜の約束。八月二十五日の朝、少年は小さな包みを握って、島を出た。

電器店に、替えの部品はもうない。男が鞄から出したのは、あの朝ロボットがくれた「お守り」。ロボット自身の、灯りの部品だった。五時のチャイムとともに、灯りが戻る。

夜。中華そばの味は変わっていない。島へ戻る船から見ると、消えていった窓に、また灯りがともっている。屋上で、第一章の子どもと線香花火をする。子どもの夢は、宇宙でロボットを直す人。ロボットの光の帯に「おかえりなさい」の文字が流れる。四十年前の約束を、男はもう一度口にする。「来年も、いっしょに見ようね。」「ピ。」

## 登場するもの

- **男**：五十歳。濃紺のスーツ、白髪まじりの短い髪、焦げ茶の革の鞄。十歳の夏まで継島で育った。父と同じく「砂の向こう」で暮らしてきたが、何をしてきたかは語らない。画面では**後ろ姿・遠景・手元だけ**（顔は映さない）
- **少年**（回想、四十年前の男）：十歳。白い半袖に半ズボン、麦わら帽子。祭りの夜は甚平。後ろ姿と遠景だけ
- **古いロボット**：島に残る人たちのために作られた、町でいちばん最初の一台。町のロボットと同じ姿（アイボリーの丸い体、顔の代わりの琥珀色の光の帯、目も口もない）。今は塗装がはげ、色の違う継ぎ当てがあり、肩に手書きの小さな番号がある（回想ではまだ新しくてきれい）。灯りの部品が古くなり、ときどき揺らぐ。話さない（「ピ。」と鳴く／光の帯に文字を流す／交換日記に字を書く）
- **トラックのロボット運転手**：第一章の予告と同じ、ミント色の軽トラック
- **ロボットの先生**：第一章の透明な黒板の先生。夏休みはラジオ体操の係
- **駄菓子屋のロボット**：おばあちゃんの店を継いだ。日曜は電話のあずかり係
- **縁台の将棋の相手**：近所のおじいさんとロボット
- **電器店の主人**：第一章の「継町電器」。回想でロボットを作った職人の跡継ぎ。後ろ姿
- **中華そばの親方とロボット**：第一章と同じ店
- **屋上の子ども**：第一章の屋上で、ロボットと花火を見ていた子。甚平。夢は「宇宙でロボットを直す人」
- **小道具**：ラジオ体操カード（2040年の夏）、電話のあずかり箱と木の札、小さな四駆のおもちゃとコース、カード、将棋盤、交換日記、お守り（光の帯の部品を色あせた手ぬぐいで包んだもの）、麦茶のグラスふたつ、柱の傷、がたつく木の引き戸、線香花火

## 第一章とのつながり

- 予告の砂丘とミント色のトラック → 序と一（同じ夜、男は砂丘から町の花火を見ていた）
- 回覧板「海岸のごみ拾い　8/25（日）朝6時」 → 一の浜（ごみ拾いのあとのラジオ体操）
- 透明な黒板のロボットの先生 → ラジオ体操のはんこ／回想では緑の黒板
- 「牛乳は、今も瓶で届く。」 → 古いロボットが島へ牛乳を運ぶ
- 「扉は、何もしなくても開く。」 → 「この戸だけは、今も手で開ける。」
- 居間「誰かが、さっきまでここにいた。」 → 「あの日から、麦茶は毎日ふたつ。」と交換日記（誰が待っていたのかが分かる）
- 「ひとつ、またひとつ、窓に灯りがともる。」 → 回想の「窓の灯りが消えていく。」 → 「消えていった窓に、また灯りがともっている。」
- 電器店「古い扇風機は、捨てずに直す。」 → ロボットも、生まれた作業台で直される
- 「五時のチャイムが、海の向こうまで響く。」 → 灯りが戻る合図
- 中華そば「味は、親方から教わったもの。」 → 「中華そばの味は、変わっていなかった。」
- 屋上の二人「来年も、いっしょに見ようね。」「ピ。」 → 交換日記の最後のページ → 四十年前の同じ約束（回想）→ 男がもう一度口にする
- 町の名前の「継」（受け継ぐ・継ぎを当てて直す） → 町のロボットは最初の一台の姿を受け継ぎ、店はロボットが継ぎ、ロボットはお守りの部品で直される

## 制作メモ

- **原画**：新しく約32枚。第一章と同じ場所（砂丘＝T0、居間＝C6、電器店＝B4、中華そば＝C1、屋上＝E4、深夜の継島＝F0、島の階段＝A2、商店街＝B3・G1）は、第一章の原画を参照画像に渡して同じ場所に見せる。居間（C3）は第一章の部屋の中をそのまま使い、窓の外だけ島の団地と海にする
- **タイムスリップの切り替え**：B3（今のコース）と B4（四十年前のコース）、R4（灯りが消える島）と E2（灯りがともる島）、R2（ロボットが生まれた作業台）と D1（直される作業台）、R6（少年とロボットの屋上）と E4（男とロボットと子どもの屋上）は、それぞれ同じ構図にする。今と昔を同じ構図でつなぐことで、時間が巻き戻る感じを出す
- **回想の見た目**：2034〜2040年の島は今より古び、新しい塔も飛行車もない。黒板は透明ではなく緑の黒板。色を少し褪せさせて暖かく、粒子を強めにし、周辺を暗くする（合成の最後に回想用の質感をかける）
- **男と少年**：顔を映さない（後ろ姿・遠景・手元）。男は全カットの指示文に「濃紺のスーツ、白髪まじりの短い髪、焦げ茶の革の鞄」、少年は「白い半袖、半ズボン、麦わら帽子（祭りの夜は甚平）」を入れて、同じ人に見せる
- **古いロボット**：町のロボットと同じ設計（目も口もなく、顔の代わりに琥珀の光の帯）。今は塗装のはげ・色の違う継ぎ当て・肩の手書きの番号で古さを出し、回想ではきれいな新品にする。「光の帯が揺らぐ・消える・戻る」は Veo に頼み、足りなければ合成で明滅を足す
- **遊び道具は、実在の商品に似せない**：ミニ四駆・遊戯王は商品名・作品名なので、画面には「小さな四駆のおもちゃとコース」「オリジナルの絵柄のカード」として描き、ロゴ・実在のカードの絵柄・キャラクターは使わない。名前は字幕・タイトル・概要欄・タグにも出さない（第一章の VIVANT と同じ扱い）。将棋はそのまま
- **電話**：2080年の電話は薄いガラスの板。電源を切ると画面が暗くなる
- **手元のカット**（A3・B2・B3・C2・C4・C6・D2）は手の形が崩れやすい。Veo の結果を必ず確かめ、崩れたら動きを小さくする
- **文字**：電子版（A2・D1）。カードとはんこ（A3）、交換日記のページ（C4）は第一章の回覧板と同じ「板に貼る表示」で、ページの字は手書き風に。黒板の「さいごの授業参観　ありがとう　継島小学校」（R5）は第一章の黒板と同じチョークの表示。「おかえりなさい」（E4）は光の帯のすぐ上に小さな電子版でも出して読めるようにする
- **字幕**：43行と、第一章（23行）の倍近い。映像にしてから、絵で伝わる所は字幕を減らす
- **音**：回想は環境音を遠く、こもった音にする。授業参観の作文の声は聞き取れない程度に（言葉は字幕で）。実在のラジオ体操の曲は著作権があるので使わない（オリジナルの短い伴奏か、波と掛け声だけ）。五時のチャイムは第一章のオリジナル旋律。R7 の汽笛は長く
- **テーマ曲**：第一章の主題を使う。回想はオルゴールだけで静かに、四の「灯りが戻る」で主題を明るく、結で静かに閉じる
- **もうひとつの世界線**：第一章と同じ扱い。砂丘・スーツの男・鞄・ロボットのトラックという雰囲気だけで、作品名・人物・ロゴ・音楽は使わない
- **費用の目安**：約27〜32ドル（画像 約32枚＋Veo Lite 33本）
