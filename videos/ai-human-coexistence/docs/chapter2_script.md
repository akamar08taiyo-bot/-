> 制作の記録（第8版）は、この文書のいちばん下。作業フォルダは `videos/ai-human-coexistence-2/`。

## 作品の顔

- **シリーズ**：AIと人間の共存
- **章題**：第二章「砂の向こうから来た男」（第一章の次回予告で予告済み）
- **テーマ**：変わっていくものと、変わらないもの。僕の大好きなあの頃は、そのままに。
- **日付**：2080年8月25日（日）。第一章の翌日（序は2026年と2080年の8月24日、あいだに昭和の島の思い出が入る）
- **尺**：7分51秒・30カット（序20秒＋22秒、授業参観20秒、結28秒、ほかは16秒、1.2秒ずつ重ねる）
- **見てほしい人**：40代前半〜50代後半。子ども時代が昭和の終わり〜平成の初めの人
- **語り**：ナレーションなし。せりふもほとんどなし。町の音と、短い字幕だけ。最後にあいさつの声

## 見せ方の決まり（ドラマにしない）

- **説明しない**：物語は、画面の中の物（カードの年、交換日記の日付、柱の傷、写真、お守り）と、同じ構図のくり返しで伝える。見る人が自分でつないで、気づく
- **話さない**：人のせりふの字幕は、第一章からくり返す「来年も、いっしょに見ようね。」の一行だけ。人の声は、遠くの聞き取れないざわめき程度。ロボットは「ピ。」と鳴くだけ
- **字幕は少なく**：日付と、町のことを書いた短い文だけ（全部で15行。第一章は23行）。登場人物の気持ちや、出来事のいきさつは書かない
- **泣かせない**：顔を映さず、表情で見せない。カメラは引きで、ゆっくり。音楽で盛り上げすぎない
- **答えを全部は見せない**：男がなぜ時を越えたのか、あの子がどうなったのかは、言葉では言わない。見る人によって受け取り方が少し違ってよい

## この章で描くこと（作者の想い）

- 時代が進むなかで、昔の懐かしい思い出がよみがえると、懐かしくて切なくなる。
- 時代が変わって進化しても、昔の思い出は消したくない。
- タイムスリップしたかのような体験とともに、一周して、昔の懐かしさや良さ、遊びに気づくときが帰ってくる。
- 携帯電話を手放す。その代わりに、ミニ四駆や遊戯王、将棋で遊ぶ。秋と冬の遊びもある。
- 授業参観、交換日記、夢やお父さんの仕事の発表。回想を交えながら、夢のある未来の世界も日々進化していく。
- 40代前半〜50代後半の人が見とれて、しみじみする映像に。現代的な要素も忘れない。
- 男は時代をタイムスリップして戻ってきた。
- ドラマではない。見ている人が取り込まれて、推察するような感じ。話したりはほとんどしない。
- 動画は7分から8分ぐらい。
- チェーン店の看板などは残す。空中電車、喫茶店、吉野家などは残す。左官屋、建設業でロボットと共存。神社。

## 画面に映ること

2026年8月24日の夕暮れ。通知の鳴りやまないスマートフォンを持ったスーツの男が、人のいない団地の島を対岸に見ながら、砂丘へ入っていく。砂が舞い上がる。砂が晴れると夜で、対岸の島には灯りがともり、花火が上がっている。

2080年8月25日、日曜日。ロボットの運転するトラックが、男を町まで乗せていく。浜のラジオ体操の列に、スーツの男がいる。手には、昭和61年のラジオ体操カード。最後の一枠にだけ、はんこがない。ロボットの先生が、そこにはんこを押す。

商店街の純喫茶の窓ぎわで、モーニング。窓の外には、牛丼屋のオレンジの看板とコンビニの看板、その上を空中電車が渡っていく。坂の途中では、左官の親方がロボットに鏝の使い方を見せ、その向こうで職人たちとロボットが空中の橋を組んでいる。日曜の駄菓子屋では、子どもたちが電話を木の箱にあずけて遊ぶ。圏外のままの男の電話も、箱に入る。裏のコースで小さな四駆が走ると、同じ構図の昭和のコースで、少年と赤い髪どめの女の子が車を走らせている。路地では、めんこ、カード、ロボットとの将棋。

昼の牛丼屋。古いロボットといっしょに渡る、島への船。古い団地の一室のちゃぶ台に、麦茶がふたつ。交換日記の最初のページは、子どものふたりの字。何十年もあいて、大人の女の人の字が毎年一枚ずつ続く。最後の一文はいつも同じ。字はだんだん震え、2069年で終わる。そのあとは、ロボットの四角い字と砂丘の絵。最後のページの絵には、砂丘とスーツの男。柱には、ふたり分の背くらべの線。どちらも昭和61年で止まっている。

昭和の島。炭鉱の櫓が見える神社の境内で、秋の缶蹴り、ゴム跳び、めんこ、落ち葉の焼きいも。雪の正月の、かまくら、凧、羽子板、こま。授業参観の教室の壁には、町のロボットと同じ姿のロボットの絵。消えていく窓の灯り。屋上の花火。朝の桟橋で、女の子が少年の手に小さなお守りをのせる。

高台の神社で、男が手を合わせ、となりでロボットも頭を下げる。社の脇の額の写真。2034年、お年寄りたちと最初のロボット、その真ん中に赤いカーディガンの白髪の女性。五時のチャイムは、昭和の島と同じ旋律。昭和と同じ境内での夕焼けの缶蹴りに、男もまざる。窓から呼ばれて、子どもたちが帰っていく。

夜。消えた窓に、また灯りがともっている。赤い髪どめの子どもと線香花火。男がお守りをほどくと、子どもの丸い字で「おかえりなさい」。ロボットの光の帯が、ゆっくり明るくなる。屋上のベンチに、子どもと、ロボットと、男。

## 制作メモ

- **原画**：新しく約28枚（P1 と R5 はサムネイル用に作った元絵をそのまま使える）。第一章と同じ場所（砂丘＝T0、居間＝C6、屋上＝E4、深夜の継島＝F0、商店街＝B3・G1）は、第一章の原画を参照画像に渡して同じ場所に見せる。居間（C3）は第一章の部屋の中をそのまま使い、窓の外だけ島の団地と海にする
- **実在のチェーン店は、そのまま使わない**：吉野家などの実在の店名・ロゴ・看板の形は使わず（商標のため。生成AIも実在のロゴは崩したり断ったりする）、色と雰囲気で思い出せるこの町のオリジナルの店にする：牛丼「つぎ家」（オレンジの看板、コの字のカウンター）、コンビニ「つぎマート」（白地に色の帯）、純喫茶「しおみ」（窓の金文字、赤いビロードの椅子、サイフォン）。看板の字が崩れたら、板に貼る表示で直す。実在の店名は字幕・タイトル・概要欄・タグにも入れない
- **空中電車**：細い一本のレールにぶら下がって走る、丸みのある二両の電車（白と若草色）。塔のあいだと古い瓦屋根の上を、静かに渡る。これからの章でも同じ姿にする
- **左官と職人**：左官の親方は年配の職人（後ろ姿）、道具は鏝と鏝板、壁は蔵の白い漆喰。鳶と大工はヘルメットとニッカポッカ。ロボットは道具を受け取り、人の手つきをまねる側（技は人から）
- **神社**：島の高台の小さな神社（鳥居、石灯籠、狛犬、大きな銀杏、石段）。昭和の秋（R1）は銀杏が黄色、今の夏（D1・D2）は青い。R1 と D2 は同じ構図
- **2026年の島（P0）**：人がいなくなって40年の、草におおわれた団地の島（実在の島には似せすぎない）
- **昭和の島（R1〜R6）**：昭和50〜60年代の暮らしを細かく入れる（ぎっしりの洗濯物、木の机、黒板、作業着の父親、エプロンの母親、おかっぱ、手編みのセーター、ラムネ、シールを貼ったノート）。秋（R1）と雪の正月（R2）は、遊びを一枚の絵に何種類も入れて、隅々まで見られる絵にする。色は昭和のカラー写真のように褪せさせて暖かく。昭和の絵は「本物の写真」「線画やアニメにしない」「白い縁を付けない」と強く書く（書かないとイラストになった）
- **同じ構図で時をつなぐ**：B4 と B5（コース）、R1 と D2（神社の境内）、R4 と E1（島の窓）、R5 と E4（屋上）は、それぞれ同じ構図にする。言葉の代わりに、構図で時間をつなぐ
- **赤い色**：あの子の赤い髪どめ、2034年の写真の赤いカーディガン、屋上の子どもの赤い髪どめ。人物の持ち物の赤はこの三つだけにして、見る人が気づけるようにする（店の看板や鳥居の赤は、くすんだ朱色にして区別する）
- **男・少年・あの子**：顔を映さない（後ろ姿・遠景・手元）。男は全カットの指示文に「濃紺のスーツ、白髪まじりの短い髪、焦げ茶の革の鞄」、少年は「半袖・半ズボン・野球帽（冬はセーターとマフラー、祭りの夜は甚平）」、あの子は「おかっぱに赤い髪どめ（冬は赤いカーディガン、祭りの夜は浴衣）」を入れて、同じ人に見せる
- **古いロボット**：町のロボットと同じ設計（目も口もなく、顔の代わりに琥珀の光の帯）。塗装のはげ・色の違う継ぎ当て・肩の手書きの番号で古さを出す
- **画面の中の文字**：カード、交換日記、柱、額の札、お守りの紙、店の看板は「板に貼る表示」で重ねる。読めるのは日付と短い言葉だけにして、文章は読ませない。字の書き分けは、あの子の子どもの字が丸文字（Hachi Maru Pop）、少年の字が鉛筆の子どもの字（Yomogi）、大人のあの子の字がペン字（Klee One）、ロボットの字が四角くていねいに（Zen Maru Gothic）。どれも OFL の無料フォント
- **遊び道具は、実在の商品に似せない**：ミニ四駆・遊戯王は商品名・作品名なので、「小さな四駆のおもちゃとコース」「オリジナルの絵柄のカード」として描き、ロゴ・実在のカードの絵柄・キャラクターは使わない。めんこや凧の絵柄もオリジナル。名前は字幕・タイトル・概要欄・タグにも出さない。将棋はそのまま
- **電話**：2026年のスマートフォンは、ロゴのない今風の黒い板。2080年の電話は薄いガラスの板
- **手元のカット**（A2・B3・B4・C4・C5・C6・E3）は手の形が崩れやすい。Veo の結果を必ず確かめ、崩れたら動きを小さくする
- **音**：人の声は、遠くの聞き取れないざわめきだけ（作文、ゴム跳びの歌、夕飯の呼び声も聞き取れない程度に）。昭和の島は環境音を遠く、こもった音にする。実在のラジオ体操の曲は著作権があるので使わない。五時のチャイムは第一章のオリジナル旋律で、昭和の島でも同じ旋律にする（音で時をつなぐ）。R6 の汽笛は長く
- **テーマ曲**：第一章の主題を使う。昭和の島はオルゴールだけで静かに。E3 で主題を少しだけ大きくし、結で静かに閉じる。盛り上げすぎない
- **もうひとつの世界線**：第一章と同じ扱い。砂丘・スーツの男・鞄・時を越えたなぞ、という雰囲気だけで、作品名・人物・ロゴ・音楽は使わない
- **費用の目安**：約22〜26ドル（画像 約28枚＋Veo Lite 30本）
