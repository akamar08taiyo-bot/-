# 第二章「砂の向こうから来た男」台本

## 作品の顔

- **シリーズ**：AIと人間の共存
- **章題**：第二章「砂の向こうから来た男」（第一章の次回予告で予告済み）
- **テーマ**：変わっていくものと、変わらないもの。僕の大好きなあの頃は、そのままに。
- **ログライン**：祭りの翌朝、スーツの男が砂丘の向こうから継町へ帰ってくる。四十年ぶりの町には知らない塔が増え、店はロボットが継いでいた。けれど、柱の傷も、毎日ふたつの麦茶も、あの夏の約束も、そのまま残っていた。
- **日付**：2080年8月25日（日）。第一章の翌日（序だけは、第一章と同じ祭りの夜）
- **尺**：6分51秒・26カット（序25秒、結32秒、ほかは16秒、1.2秒ずつ重ねる）。第一章と同じ型
- **語り**：ナレーションなし。短い字幕と町の音だけ。最後にあいさつの声

## あらすじ

祭りの夜、町はずれの砂丘。スーツの男は、ロボットが運転するトラックのそばで、海の向こうに上がる町の花火を見ていた。

夜が明けると、トラックは男を町まで乗せていく。回覧板にあった「海岸のごみ拾い」では、知らない人の男にも軍手が配られる。男はスーツのままラジオ体操の列にならび、胸ポケットから一枚のカードを出す。四十年前のラジオ体操カード。最後の一日、八月二十五日だけ、はんこが空いている。ロボットの先生が、その枠にはんこを押す。

知らない塔が増えた町。それでも銭湯の下足札は木のままで、子どもの頃の駄菓子屋はロボットが継いでいた。坂の上で朝顔に水をやる古いロボットの背中を、男は知っていた。

ロボットのあとについて入った古い家。木の引き戸だけは、今も手で開ける。ちゃぶ台には、毎日ふたつ用意されてきた麦茶。柱の背くらべの傷は、十歳で止まったまま。縁側で昼寝をする男を、ロボットはうちわであおぎ続ける。けれどその灯りはときどき揺れ、やがて、ふっと消えてしまう。

電器店に、替えの部品はもうない。男が鞄から出したのは、四十年前の別れの朝にロボットがくれた「お守り」。ロボット自身の、灯りの部品だった。五時のチャイムとともに、灯りが戻る。

夜。中華そばの味は変わっていない。屋上で、第一章の子どもと線香花火をする。ロボットの光の帯に「おかえりなさい」の文字が流れる。四十年前の祭りの夜にした約束を、男はもう一度口にする。「来年も、いっしょに見ようね。」「ピ。」

## 登場するもの

- **男**：五十歳。濃紺のスーツ、白髪まじりの短い髪、焦げ茶の革の鞄。十歳の夏まで継町で育ち、四十年前の8月25日の朝、家族と町を出た。どこで何をしてきたかは語らない。画面では**後ろ姿・遠景・手元だけ**（顔は映さない）
- **古いロボット**：町でいちばん古い一台。町のロボットと同じ姿（アイボリーの丸い体、顔の代わりの琥珀色の光の帯、目も口もない）だが、塗装がはげ、色の違う継ぎ当てがあり、肩に手書きの小さな番号がある。男の子どもの頃の友だち。四十年間、男の家を守り、毎日麦茶をふたつ用意してきた。灯りの部品が古くなり、ときどき揺らぐ。話さない（「ピ。」と鳴く／光の帯に文字を流す）
- **トラックのロボット運転手**：第一章の予告と同じ、ミント色の軽トラック
- **ロボットの先生**：第一章の透明な黒板の先生。夏休みはラジオ体操の係
- **駄菓子屋のロボット**：おばあちゃんの店を継いだ
- **電器店の主人**：第一章の「継町電器」。後ろ姿
- **中華そばの親方とロボット**：第一章と同じ店
- **屋上の子ども**：第一章の屋上で、ロボットと花火を見ていた子。甚平
- **小道具**：ラジオ体操カード（2040年の夏）、お守り（光の帯の部品を色あせた手ぬぐいで包んだもの）、麦茶のグラスふたつ、柱の傷、がたつく木の引き戸、線香花火

## 第一章とのつながり

- 予告の砂丘とミント色のトラック → 序と一（同じ夜、男は砂丘から町の花火を見ていた）
- 回覧板「海岸のごみ拾い　8/25（日）朝6時」 → 一の海岸のごみ拾い
- 「扉は、何もしなくても開く。」 → 「この戸だけは、今も手で開ける。」
- 居間「誰かが、さっきまでここにいた。」 → 「あの日から、麦茶は毎日ふたつ。」（誰が待っていたのかが分かる）
- 電器店「古い扇風機は、捨てずに直す。」 → ロボットも、直されて使われ続ける
- 「五時のチャイムが、海の向こうまで響く。」 → 灯りが戻る合図
- 中華そば「味は、親方から教わったもの。」 → 「中華そばの味は、変わっていなかった。」
- 屋上の二人「来年も、いっしょに見ようね。」「ピ。」 → 四十年ごしに、同じ約束がくり返される
- 町の名前の「継」（受け継ぐ・継ぎを当てて直す） → 駄菓子屋をロボットが継ぐ／お守りの部品で直す

## 制作メモ

- **原画**：新しく約24枚。第一章と同じ場所（砂丘＝T0、居間＝C6、電器店＝B4、中華そば＝C1、屋上＝E4、深夜の継島＝F0）は、第一章の原画を参照画像に渡して同じ場所に見せる
- **男**：顔を映さない（後ろ姿・遠景・手元）。全カットの指示文に「濃紺のスーツ、白髪まじりの短い髪、焦げ茶の革の鞄」を入れて、同じ人に見せる
- **古いロボット**：町のロボットと同じ設計（目も口もなく、顔の代わりに琥珀の光の帯）。古さは、塗装のはげ・色の違う継ぎ当て・肩の手書きの番号で出す。「光の帯が揺らぐ・消える・戻る」は Veo に頼み、足りなければ合成で明滅を足す
- **手元のカット**（A4・B2・C1・C3・C5・D2）は手の形が崩れやすい。Veo の結果を必ず確かめ、崩れたら動きを小さくする
- **文字**：電子版（A2・A3・D1・E1）。カードとはんこ（A4）は第一章の回覧板と同じ「板に貼る表示＋はんこ」。「おかえりなさい」（E5）は光の帯のすぐ上に小さな電子版でも出して読めるようにする
- **音**：実在のラジオ体操の曲は著作権があるので使わない（オリジナルの短い伴奏か、波と掛け声だけ）。五時のチャイムは第一章のオリジナル旋律
- **テーマ曲**：第一章の主題を使う。四の「灯りが戻る」で主題を明るく、結で静かに閉じる
- **もうひとつの世界線**：第一章と同じ扱い。砂丘・スーツの男・鞄・ロボットのトラックという雰囲気だけで、作品名・人物・ロゴ・音楽は使わない。公開するタイトル・概要欄・タグにも作品名を入れない
- **費用の目安**：第一章と同じく約20〜25ドル（画像 約24枚＋Veo Lite 26本）
