# 第二章「砂の向こうから来た男」台本

## 作品の顔

- **シリーズ**：AIと人間の共存
- **章題**：第二章「砂の向こうから来た男」（第一章の次回予告で予告済み）
- **テーマ**：変わっていくものと、変わらないもの。僕の大好きなあの頃は、そのままに。
- **ログライン**：2026年の夏、五十歳の男は、四十年前に人がいなくなった生まれ故郷の島を見に、浜を訪れる。砂丘に足を踏み入れた男が出たのは、2080年。昭和の暮らしを残したままよみがえった島で、男は子どもの頃の遊びと、自分を一生待ち続けた幼なじみの想いに出会う。
- **日付**：2080年8月25日（日）。第一章の翌日（序は2026年と2080年の8月24日、回想は昭和の終わり）
- **尺**：9分41秒・37カット
- **見てほしい人**：40代前半〜50代後半。子ども時代が昭和の終わり〜平成の初めの人。男はちょうどその真ん中の世代（1976年・昭和51年生まれ）にしてある
- **語り**：ナレーションなし。短い字幕と町の音だけ。最後にあいさつの声

## この章で描くこと（作者の想い）

- 時代が進むなかで、昔の懐かしい思い出がよみがえると、懐かしくて切なくなる。
- 時代が変わって進化しても、昔の思い出は消したくない。
- タイムスリップしたかのような体験とともに、一周して、昔の懐かしさや良さ、遊びに気づくときが帰ってくる。
- 携帯電話を手放す。その代わりに、ミニ四駆や遊戯王、将棋で遊ぶ。秋と冬の遊びもある。
- 授業参観、交換日記、夢やお父さんの仕事の発表。回想を交えながら、夢のある未来の世界も日々進化していく。
- 40代前半〜50代後半の人が見とれて、しみじみする映像に。現代的な要素も忘れない。
- 男は時代をタイムスリップして戻ってきた。

## あらすじ

2026年8月24日の夕暮れ。五十歳の男は、四十年前に人がいなくなった生まれ故郷の島を、対岸の浜から眺めていた。電話には仕事の知らせが鳴りやまない。砂丘に足を踏み入れると、砂が舞い上がり、景色が変わる。砂の向こうで、無人のはずの島に灯りがともり、花火が上がっていた。

夜明け、砂丘で待っていたロボットのトラックが、何も聞かずに男を町まで乗せていく。2080年8月25日。男はスーツのまま浜のラジオ体操の列にならび、四十年前のカードの空いていた最後の一日に、はんこをもらう。

見たことのない未来の町に、見覚えのある景色が残っていた。男の電話は圏外のまま。子どもたちは電話を木の箱にあずけ、小さな四駆のおもちゃ、めんこ、カード、将棋で遊んでいる。時代は一周して、昔の遊びが帰ってきていた。桟橋では、トラックを運転していた古いロボットが、男を待っていた。

昼。港の中華そばは四十年前と同じ味がした。四十年ぶりの、生まれた島への船。ロボットが案内したのは、隣の部屋のあの子の家だった。毎日ふたつ用意されてきた麦茶。交換日記には、男が消えた日からのあの子の字が、2069年まで続いていた。そのあとを、ロボットが書き継いでいた。最後のページは、きのう。「砂丘で、あのひとを見つけました。」柱の背くらべの傷は、ふたりとも十歳で止まったまま。

（回想）昭和の終わり。島は、海の底の石炭で暮らしていた。秋は日が暮れるまで缶蹴り、落ち葉で焼きいも。冬はかまくらでみかん、正月は凧と羽子板とこま。あの子とは交換日記をしていた。最後の授業参観、少年は父の仕事を、あの子は「ロボットを作る人になる」という夢を発表した。炭鉱が閉じると、窓の灯りはひとつ、またひとつ消えていった。最後の祭りの夜の約束。八月二十五日の朝、あの子はお守りを渡した。「島に帰ってきたら、開けてね。」

夕暮れ。島の高台の写真に、島をよみがえらせた人たちと、最初のロボットを作ったあの子が写っていた。五時のチャイムは、あの頃と同じ歌。子どもたちと、夕焼けが消えるまで缶蹴りをする。「ごはんよー」の声で、遊びはおしまい。

夜。消えていった窓に、また灯りがともっている。屋上で、あの子のひ孫と線香花火をする。ひ孫の夢は、宇宙でロボットを直す人。ロボットの光の帯に「おかえりなさい」の文字が流れる。男は四十年ぶりにお守りを開ける。中には、十歳のあの子の丸い字で「おかえりなさい」。男は、もう一度約束する。「来年も、いっしょに見ようね。」「ピ。」

## 登場するもの

- **男**：五十歳。1976年生まれ、2026年から来た。濃紺のスーツ、白髪まじりの短い髪、焦げ茶の革の鞄、2026年のスマートフォン。画面では**後ろ姿・遠景・手元だけ**（顔は映さない）
- **少年**（回想、昭和の男）：十歳まで。半袖・半ズボン・野球帽、冬は手編みのセーターとマフラー、祭りの夜は甚平。後ろ姿と遠景だけ
- **あの子**（回想、男の幼なじみ）：隣の部屋の同い年の女の子。おかっぱ、赤いカーディガン。字は丸文字。2034年に最初のロボットを作り、島をよみがえらせた人のひとり。2070年に亡くなる。後ろ姿と遠景だけ（D1 の写真も小さく）
- **古いロボット**：あの子が作った最初の一台。町のロボットと同じ姿（アイボリーの丸い体、顔の代わりの琥珀色の光の帯、目も口もない）。塗装がはげ、色の違う継ぎ当てがあり、肩に手書きの小さな番号。毎年8月24日にミント色の軽トラックで砂丘を見回る。話さない（「ピ。」と鳴く／光の帯に文字を流す／交換日記に字を書く）
- **ロボットの先生**：第一章の透明な黒板の先生。夏休みはラジオ体操の係
- **駄菓子屋のロボット**：日曜は電話のあずかり係
- **縁台の将棋の相手**：近所のおじいさんとロボット
- **中華そばの親方とロボット**：第一章と同じ店
- **屋上の子ども**：第一章の屋上でロボットと花火を見ていた子。あの子のひ孫。甚平。夢は「宇宙でロボットを直す人」
- **小道具**：2026年のスマートフォン、ラジオ体操カード（昭和61年の夏）、手縫いのお守り（中に「おかえりなさい」の紙）、交換日記（シールを貼った表紙）、電話のあずかり箱と木の札、小さな四駆のおもちゃとコース、めんこ、カード、将棋盤、麦茶のグラスふたつ、ふたり分の背くらべの傷、がたつく木の引き戸、線香花火

## 辻褄の確認

- **なぜ2080年に？**：2026年8月24日の夕方、砂丘で時を越えた（しくみは語らない。題の「砂の向こう」）。五十歳のまま、54年後の同じ日の砂丘に出た
- **なぜトラックが砂丘にいた？**：あの子の頼みで、ロボットが毎年8月24日の夕方に砂丘を見回っていた（交換日記で分かる）。だから「何も聞かずに」乗せた
- **なぜロボットが男を知っている？**：あの子が写真と交換日記で教えていた
- **なぜ島に昭和が残っている？**：無人になった島を、あの子たちがロボットといっしょに「昔のまま」直してよみがえらせた
- **ロボットが作られた経緯**：人がいなくなった島に、帰りたいお年寄りが暮らせるように。作ったのは、子どもの頃の夢をかなえたあの子
- **なぜカードとお守りを持っている？**：2026年、最後の祭りから四十年目の日に、思い出の箱から出して胸ポケットに入れてきた
- **なぜ麦茶がふたつ？**：あの子が島に帰った2034年から毎日、男のぶんを用意していた。亡くなったあとはロボットが続けた
- **なぜ柱の傷がふたり分？**：隣どうしの部屋で、同じ柱で背くらべをしていた。ふたりとも十歳の夏に島を出た
- **屋上の子ども**：第一章の子どもは、あの子のひ孫。夢は、ひいおばあちゃんのロボットの続き（宇宙でロボットを直す人）
- **第三章へ**：男は2080年の島で、ロボットと暮らしはじめる（元の時代へ戻れるのかは、まだ語らない）

## 第一章とのつながり

- 居間「誰かが、さっきまでここにいた。」 → 毎日ふたつの麦茶と交換日記（誰が、誰を待っていたのかが分かる）
- 「ひとつ、またひとつ、窓に灯りがともる。」 → 回想の「窓の灯りが消えていく。」 → 「消えていった窓に、また灯りがともっている。」

## 制作メモ

- **原画**：新しく約36枚。第一章と同じ場所（砂丘＝T0、居間＝C6、中華そば＝C1、屋上＝E4、深夜の継島＝F0、島の階段＝A2、商店街＝B3・G1）は、第一章の原画を参照画像に渡して同じ場所に見せる。居間（C4）は第一章の部屋の中をそのまま使い、窓の外だけ島の団地と海にする
- **2026年の島（P0）**：人がいなくなって40年の、草におおわれた団地の島（実在の島には似せすぎない）
- **昭和の回想（R1〜R10）**：昭和50〜60年代の暮らしを細かく入れる（ぎっしりの洗濯物、木の机、黒板、作業着の父親、エプロンの母親、おかっぱ、手編みのセーター、ラムネ、シールを貼ったノート、丸文字）。40〜50代が「自分の子ども時代だ」と見入るよう、遊びは一枚の絵に何種類も入れて、隅々まで見られる絵にする。色は昭和のカラー写真のように褪せさせて暖かく
- **同じ構図で時をつなぐ**：B3（今のコース）と B4（昭和のコース）、R2（昭和の缶蹴り）と D2（今の缶蹴り）、R8（灯りが消える島）と E1（灯りがともる島）、R9（昭和の屋上の二人）と E4（今の屋上の三人）は、それぞれ同じ構図にする
- **男・少年・あの子**：顔を映さない（後ろ姿・遠景・手元）。男は全カットの指示文に「濃紺のスーツ、白髪まじりの短い髪、焦げ茶の革の鞄」、少年は「半袖・半ズボン・野球帽（冬はセーターとマフラー、祭りの夜は甚平）」、あの子は「おかっぱ、赤いカーディガン（祭りの夜は浴衣）」を入れて、同じ人に見せる
- **古いロボット**：町のロボットと同じ設計（目も口もなく、顔の代わりに琥珀の光の帯）。塗装のはげ・色の違う継ぎ当て・肩の手書きの番号で古さを出す
- **字の書き分け**：交換日記とお守りの紙は「板に貼る表示」で重ねる。あの子の子どもの字は丸文字（Hachi Maru Pop）、少年の字は鉛筆の子どもの字（Yomogi）、大人になったあの子の字はペン字（Klee One）、ロボットの字は四角くていねいに（Zen Maru Gothic）。どれも OFL の無料フォント
- **遊び道具は、実在の商品に似せない**：ミニ四駆・遊戯王は商品名・作品名なので、画面には「小さな四駆のおもちゃとコース」「オリジナルの絵柄のカード」として描き、ロゴ・実在のカードの絵柄・キャラクターは使わない。めんこや凧の絵柄もオリジナル（実在のキャラクターは使わない）。名前は字幕・タイトル・概要欄・タグにも出さない。将棋はそのまま
- **電話**：2026年のスマートフォンは、ロゴのない今風の黒い板。2080年の電話は薄いガラスの板
- **手元のカット**（A3・B2・B3・C3・C5・C6・C7・E3）は手の形が崩れやすい。Veo の結果を必ず確かめ、崩れたら動きを小さくする
- **字幕**：多い（第一章の倍以上）。映像にしてから、絵で伝わる所は字幕を減らす
- **音**：回想は環境音を遠く、こもった音にする。授業参観の作文の声とゴム跳びの歌は、聞き取れない程度に（言葉は字幕で）。実在のラジオ体操の曲は著作権があるので使わない。五時のチャイムは第一章のオリジナル旋律で、昭和の回想でも同じ旋律にする。R10 の汽笛は長く
- **テーマ曲**：第一章の主題を使う。回想はオルゴールだけで静かに、E3 の「おかえりなさい」で主題をいちばん大きく、結で静かに閉じる
- **もうひとつの世界線**：第一章と同じ扱い。砂丘・スーツの男・鞄・砂丘で消えた男というなぞ、という雰囲気だけで、作品名・人物・ロゴ・音楽は使わない
- **費用の目安**：約28〜33ドル（画像 約36枚＋Veo Lite 37本）
