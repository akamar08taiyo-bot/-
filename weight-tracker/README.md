# 減量ノート（体重管理アプリ）

体重を中心に、筋トレと食事を最小手数で記録して、推移をグラフで見るための個人用アプリ。

## 使い方

`index.html` をブラウザで開くだけ。ビルドもインストールも不要で、オフラインでも動く。
スマホでは、開いたページを「ホーム画面に追加」しておくとアプリのように使える。

## 画面

| タブ | できること |
| --- | --- |
| 今日 | 前回いつ記録したかの表示／体重（±0.1ボタン付き）／筋トレ（やった部位をタップ、時間は任意）／食事（よく食べるものをタップで追加） |
| グラフ | カレンダー（日ごとの体重を数値で表示、減=緑・増=赤、筋トレ部位、タップでその日へ移動）、体重推移（毎日の点＋7日平均、30日/90日/全期間）、前日からの増減（±の棒グラフ）、週ごとのトレーニング時間、部位別回数 |
| 設定 | 目安カロリー、よく食べるものの編集、バックアップ／復元、全消去 |

部位は 肩 / 背中 / 胸 / 足 / 二頭 / 三頭 の6つ（複数選択可）。部位を1つでも選んだ日が「筋トレをした日」になる（行った／行かなかったの入力はしない）。目標体重の設定は持たない。

## データの保存

- 保存先は **その端末のブラウザの localStorage のみ**（キー: `genryo-note-v1`）。サーバーもログインもない。
- 端末をまたぐ同期はしない。機種変更・データ消去にそなえて、設定タブの「バックアップを表示・コピー」でJSONを控えておく。復元は同じ画面から貼り付ける。
- 初回はサンプルの記録が入っている。最初の記録を保存するか「サンプルを消す」を押すと消える。

## 技術メモ

- 単一HTMLファイル。ライブラリ・ビルド依存なし。グラフは手書きのSVG。
- 配色はCSSカスタムプロパティで定義し、ライト／ダーク両対応。
- 押下時のスケール、チップのポップ、グラフの描画アニメ、バイブレーション（対応端末のみ）あり。`prefers-reduced-motion: reduce` で全て無効化される。
- 保存データは `v:2`。旧 `v:1`（目標体重あり・行った/休み形式）は読み込み時に自動変換される。
- カロリーの初期値は一般的な目安であり、正確な栄養計算を目的としたものではない（設定タブで編集可）。
