# デザインシステム

デザインを「型」として固定し、毎回同じ雰囲気・同じ品質で出すための置き場。案件（顧客）ごとにフォルダを分ける。

| フォルダ | 用途 |
| --- | --- |
| `default/` | 指定がないときの標準（落ち着いた青系。解説スライドやレポート向け） |
| `_template/` | 新しい案件を作るときの雛形。複製して `<案件名>/` にする |

各フォルダには次の2つを置く。

- `DESIGN.md`: 雰囲気、使ってよい色・書体・余白、やってはいけないこと、見本の説明
- `tokens.json`: 色・文字サイズ・余白・角丸などの値（スライドやHTMLを作るときにそのまま使う）

スキル（slides / thumbnail-banner / ad-video など）は、案件名が出たら必ずその案件のフォルダを読む。A社のデザインをB社の成果物に使わない。
