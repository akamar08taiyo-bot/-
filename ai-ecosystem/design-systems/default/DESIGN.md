# default デザインシステム

## 雰囲気

落ち着いた青を主色にした、解説向けのすっきりした見た目。白地に濃い文字、強調は青の太字。装飾は控えめにし、情報を読みやすく並べる。

## 色（tokens.json の color）

- 主色 `primary` #1F5FBF: 見出しの下線、強調語、図の主要な線
- アクセント `accent` #F2A93B: 1画面に1か所まで（数字や結論）
- 文字 `text` #1C2330、補助文字 `subtext` #5B6676
- 背景 `bg` #FFFFFF、面 `surface` #F3F6FA、罫線 `border` #D9E0EA

## 文字

- 書体: Noto Sans JP（見出し 700、本文 400）。数字は Inter でもよい。
- スライド: 見出し 40pt、本文 24pt（最小 18pt）。Web: 見出し 28px、本文 16px、行間 1.7。

## レイアウト

- 余白は 8px の倍数。スライドの外周余白は 64px。
- 角丸 8px、影は `shadow` の1種類だけ。
- 1画面で言うことは1つ。箇条書きは3項目まで。

## やってはいけないこと

- 紫〜ピンクのグラデーション、グラデーション文字、すりガラス、絵文字の見出し（`knowledge/dictionary/ng-design.md`）
- 主色とアクセント以外の色を増やすこと
- 画像の中に長い文字を入れること（文字は HTML / スライド側で載せる）
