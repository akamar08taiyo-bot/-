# AIっぽいデザインのNGパターン

AIに画面やスライドを作らせると出がちな「いかにもAI」な見た目。
`.claude/hooks/style-check.mjs` が HTML / CSS / TSX / SVG を書くたびにこの表でチェックする。
色や形はデザインシステム（`ai-ecosystem/design-systems/`）の値を使うのが基本。

| NGパターン | 理由・直し方 |
| --- | --- |
| #667eea | 定番の紫グラデーション。デザインシステムの主色を使う |
| #764ba2 | 同上 |
| /from-(purple\|violet\|fuchsia)-\d{3}/ | Tailwindの紫系グラデーション。主色の単色か、ごく弱いグラデーションにする |
| /to-(pink\|fuchsia)-\d{3}/ | 同上 |
| /bg-clip-text/ | グラデーション文字は読みにくい。見出しは単色で |
| ✨ | 見出しやボタンを絵文字で飾らない |
| 🚀 | 同上 |
| /rounded-(3xl\|\[[3-9]\dpx\])/ | 角丸の付けすぎ。デザインシステムの角丸を使う |
| /box-shadow:[^;]*rgba\([^)]*0\.[4-9]\)/ | 濃すぎる影。影は薄く、1種類に絞る |
| /backdrop-filter:\s*blur/ | すりガラス表現の多用は読みにくい。必要な場所だけに |
