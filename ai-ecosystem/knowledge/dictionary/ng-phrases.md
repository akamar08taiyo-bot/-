# 不自然な日本語の言い回し（AIっぽい表現）

AIが書いた文章で目についた言い回しをここに足していく。
`.claude/hooks/style-check.mjs` がこの表を読み、文章を書くたびに自動でチェックする。
`/正規表現/` の形で書けば正規表現として扱われる。

| NG表現 | 直し方 |
| --- | --- |
| いかがでしたか | 締めの問いかけは消し、要点か次の行動で終える |
| と言えるでしょう | 言い切る（「〜です」） |
| と言っても過言ではありません | 誇張をやめ、事実や数字で示す |
| ではないでしょうか | 根拠があるなら言い切る。推測なら「〜と考えています」 |
| することが重要です | 何をどうするか、具体的な行動に書き換える |
| 重要なポイント | 「ポイント」だけにするか、中身を直接書く |
| さまざまな | 具体例を2〜3個挙げる |
| 多岐にわたる | 具体的に列挙する |
| において | 「〜で」「〜では」 |
| を活用することで | 「〜を使うと」 |
| シームレス | 「そのまま」「つなぎ目なく」など平易に |
| 革新的 | 何が新しいのかを具体的に書く |
| 包括的 | 「まとめて」「全体を」 |
| 深掘り | 「詳しく見る」「掘り下げる」 |
| していきましょう | 「〜します」「〜してください」 |
| させていただきます | 「します」（謙譲の重ねすぎを避ける） |
| 結論から言うと | 最初の一文で結論を書けば前置きは不要 |
| となっております | 「〜です」 |
| ぜひ活用してみてください | 消す。1記事に1回までなら「試してみてください」 |
| 魅力的な | 何がどう良いのかを書く |
| 〜の世界へようこそ | 消して本題から始める |
| /！{2,}/ | 感嘆符は1つまで。多用しない |
| /。{2,}/ | 句点の重ね打ちをやめる |
| /——\|―――/ | 長いダッシュは使わず、読点か括弧にする |
