# 成果物の見直しルール

成果物ができたら、報告する前に必ず見直す。最後の判定は `jeb-judge`。

## 見直す順番

1. **依頼どおりか**: 依頼文をもう一度読み、抜けている要素がないか。
2. **正しいか**: 数字・固有名詞・日付・金額・リンクを元資料と突き合わせる。
3. **動くか**: コードなら lint / build / テスト、Webなら Playwright で表示確認、動画なら再生とズレ確認、スライドなら LibreOffice で画像化して確認。
4. **読めるか**: 日本語ルールとNG表現（フックの指摘はその場で直す）。
5. **見た目**: デザインシステムどおりか、文字崩れ・はみ出し・重なりがないか（画像は `judge-image.mjs`）。
6. **安全か**: 個人情報・APIキー・他社の権利物が入っていないか。お金と公開は人間の確認待ちになっているか。

## 合格の基準

- `jeb-judge` の各項目が 5点中4点以上で、ブロッカー（致命的な問題）が0件なら PASS。
- 1つでも欠けていれば FAIL。直してもう一度 `jeb-judge` に出す。
