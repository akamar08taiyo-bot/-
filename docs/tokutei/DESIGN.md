# 特定福祉用具 販売・申請書作成アプリ — 設計（たたき台）

- 書いた日：2026-10-20（ブランチ `claude/care-insurance-auto-transfer-3z0c9n`）
- 今の状態：**設計だけ**。申請書の様式（保険者ごと）をいただいてから、申請書の差し込みを決めて作り始める。
- いっしょに読むもの：[既存アプリの読み取りメモ](EXISTING_APPS.md)（販売受注簿・見積書・住宅改修・売上伝票の形）

## 0. ひとことで

仕切り一覧表（メーカー・問屋の価格表）を読み込んで **商品マスタ** を作り、いつも使う商品に ★ を付けておく。
案件（お客様1件）で ★ から商品を選ぶだけで、次の3つに **同じ内容・同じ金額** が自動で入る。

1. **見積書**（御見積書。販売受注簿作成ツールの見積書と同じ形）
2. **介護保険の申請書**（保険者ごとの様式。種目・商品名・メーカー名・販売事業者名・購入金額 など）
3. **販売受注簿**（販売受注簿作成ツールに転記。受注区分「給付」）

金額は **定価の2割引き（定価×0.8、1円未満切り捨て）**。
販売受注簿作成ツールの割引率20%、住宅改修の見積（定価×0.8）と同じ決まりにそろえる。

## 1. 全体の流れ

```
 仕切り一覧表（Excel・CSV・PDF・コピーした表）
        │ ① 読み取り：見出しから 商品名・品番・定価・仕切・メーカー・TAIS・税区分 の列を推測
        ▼
 取り込みの確認（取り込む行・★・種目をここで選べる）
        │ ② 商品マスタへ：同じ「メーカー＋品番」は価格だけ新しくする（★と種目はそのまま）
        ▼
 商品マスタ（★お気に入り・よく使う順・種目ごと）
        │ ③ 案件で選ぶ：★が先頭。種目のタブ・検索
        ▼
 案件（利用者・保険者・負担割合・支払方法・明細）
        │ ④ 計算：販売単価・消費税・購入金額・利用者負担・保険者負担（1か所の計算を全部で使う）
        ├──▶ 見積書（印刷・PDF）
        ├──▶ 申請書（保険者ごとの様式に差し込み → Excel を開く／印刷）
        ├──▶ 販売受注簿（販売受注簿作成ツールを開き、受注区分「給付」で入る）
        └──▶（あとで）売上伝票発行依頼書
```

仕事の順番（2026-10-20 の「介護保険申請手続きフロー」のセッションで、ユーザーが説明した流れ）：

```
 ① 商品選び（カタログ）→ 見積書 → ② 申請（福祉用具専門相談員が申請書を作成し、市町村へ）→ ③ 承認
 → ④ 納品（ここで発注・販売受注簿）→ ⑤ 集金（納品後に利用者負担額 1割・2割・3割）
```

- 申請は納品より先。だから申請書は「見積書を作ったところ」で、同じ明細からすぐ作れるようにする。
- 必要なら購入までデモ機を置ける（備考に書く）。

大事な決まり：

- **入力は1か所、出力は3つ。** 見積書・申請書・受注簿で同じことを別々に打たない。
- 案件の明細は、選んだときの商品マスタの値を **書き写して** 持つ。あとで価格表を新しくしても、作った見積書・申請書の金額は変わらない（住宅改修アプリと同じ考え方）。
- 計算は1つの部品（`calc.ts`）だけで行い、見積書・申請書・受注簿へ渡す値はすべてそこから取る（受注簿ツールで「見積書だけ金額が違う」不具合が出た反省。EXISTING_APPS.md の1）。

| 種目の細目 | 入浴用いす | 自動判定 → 直せる |
| 定価（税抜） | 32,000 | 表 |
| 仕切（税抜） | 19,200 | 表 |

### 2.2 取り込める表

- Excel（.xlsx）・CSV（Shift_JIS／UTF-8）・文字の入った PDF・Excel などからコピーした表の貼り付け。
- 読み取りの仕組みは住宅改修アプリの `priceImport.ts` をそのまま使う（作り直さない）。
  - 見出しの行を探し、言葉の点数で列を決める：「仕切」「納価」「卸」「御社」「ネット」などは仕切、「定価」「希望小売」「上代」「標準価格」は定価、「品番」「型番」は品番。
  - 「掛率」「UP率」など「率」の列は金額にしない。改定前・改定後で2組あれば右（新しい方）を使う。
  - 見出しがなければ、数字の多い一番右の列を仕切、その左で金額の大きい列を定価、文字の長い列を商品名にする。
  - PDF は文字の位置を見出しにそろえて列にする（`alignToHeader`）。スキャンした画像だけの PDF は読めない。
  - 推測した列は、取り込みの確認の画面で直せる。
- 特定福祉用具のために足す読み取り：
  - TAIS（「TAIS」「TAISコード」の列。5桁－6桁）。
  - JAN は品番と別に持つ（今の `priceImport.ts` は品番の列がない表だと JAN の列を品番にするので、特定福祉用具では JAN を別の列として読む）。
  - 税区分（「非課税」「課税」の列や印）。
  - 税込の表（見出しに「税込」）は税抜に直す（÷1.1 で四捨五入。受注簿ツールと同じ）。
  - 種目（「種目」「分類」「カテゴリ」の列があれば使う）。
- カタログのスクリーンショットから読むのは、販売受注簿作成ツールの OCR（介援隊・ウェルファン）がすでにある。商品マスタへ画像から取り込むのは後回しにする。

### 2.3 空欄のときの決まり（要確認）

| 空欄 | 決まり（案） | 理由 |
|---|---|---|
| 仕切 | 空欄のまま取り込み、画面で「仕切が入っていない商品が N 件」と知らせる | 販売価格が定価×0.8 なので、住宅改修アプリのように「仕切＝定価×0.8」で埋めると利益0になる |
| 定価 | 定価は空欄のまま。販売単価は 仕切×1.25（1円未満切り捨て） | 受注簿ツールの「利益」モード（仕切×(100＋25)%）と同じ |
| 両方 | 候補には出すが、最初は「取り込まない」 | |

### 2.4 価格表を新しくしたとき（同じ商品の見分け方）

- 同じ「メーカー＋品番」（品番がなければ「メーカー＋商品名」）は同じ商品 → 定価・仕切・商品名だけ新しくする。表に金額がなければ今の金額のまま。
- ★お気に入り・手で直した種目・よく使う回数はそのまま残す（★を付け直さなくてよい）。
- 色違い・サイズ違いで品番が同じものは、商品名で分けて別々に残す（住宅改修アプリの `mergeMaterials` と同じ）。
- 前の価格は「価格の履歴」に残しておくと、価格改定のときに「いつから変わったか」が分かる（任意）。

### 2.5 種目の自動判定

商品名（と表の分類・TAIS）から、下の表で種目・細目を決める。決まらなければ空にして、取り込みの確認で選ぶ。
手で直した種目は、次に価格表を取り込んでも残す。種目は申請書・見積書・売上伝票の「種目」に使う。

| 種目（申請書に書く名前） | 細目 | 商品名のことば（例） |
|---|---|---|
| 腰掛便座 | 和式便器を腰掛式に・洋式便器の高さを補う（補高便座）・立ち上がりを補助（電動・スプリング）・移動できる便器（ポータブルトイレ） | ポータブルトイレ、補高便座、便座、トイレチェア |
| 自動排泄処理装置の交換可能部品 | レシーバー・チューブなど尿や便の通り道 | レシーバー、チューブ、タンク（自動排泄処理装置の） |
| 排泄予測支援機器 | | 排泄予測、排尿予測 |
| 入浴補助用具 | 入浴用いす | シャワーチェア、シャワーベンチ、入浴用いす、バスチェア |
| 入浴補助用具 | 浴槽用手すり | 浴槽手すり、バスグリップ、浴槽用手すり |
| 入浴補助用具 | 浴槽内いす | 浴槽台、浴槽内いす |
| 入浴補助用具 | 入浴台 | バスボード、入浴台 |
| 入浴補助用具 | 浴室内すのこ／浴槽内すのこ | すのこ（浴室・浴槽） |
| 入浴補助用具 | 入浴用介助ベルト | 入浴用介助ベルト |
| 簡易浴槽 | | 簡易浴槽、ポータブル浴槽 |
| 移動用リフトのつり具の部分 | | つり具、吊り具、スリングシート |
| 固定用スロープ | | スロープ（敷居など小さい段差の解消・持ち運ばないもの） |
| 歩行器 | 歩行車を除く（車輪・キャスターのないもの） | 歩行器、固定型歩行器、交互型歩行器 |
| 歩行補助つえ | カナディアン・クラッチ、ロフストランド・クラッチ、プラットホームクラッチ、多点杖 | 多点杖、四点杖、4点ステッキ、三点杖、ロフストランド、カナディアン |

- 固定用スロープ・歩行器・歩行補助つえは、2024年4月から「貸与か販売かを選べる」種目（2024年4月1日以降の購入が対象）。
- **T字杖など1本の杖は対象外。** 「杖」「ステッキ」だけでは歩行補助つえにしない（「多点」「4点」「ロフストランド」などがあるときだけ）。
  同じく、車輪やキャスターのある歩行車は歩行器にしない。種目が決まらない商品は、申請書に出す前に知らせる。
- 排泄予測支援機器は、申請に医学的な所見が分かる書類と試用の確認の書類が要る（自治体の資料）。申請書の添付の案内に出す。
- 種目の範囲は自治体の資料（北九州市・和歌山市など）で確かめた。細かい条件（座面の高さなど）は保険者で違うことがあるので、申請書の様式とあわせて確かめる。
- 種目の正式な書き方（「入浴補助用具」だけか、「入浴補助用具（入浴用いす）」か）は、申請書の様式で決める（8章）。
- 売上伝票発行依頼書は「シャワーチェア」「浴槽手すり」「浴槽台」のように細目で持っているので、転記するときは対応表で変える（5.4）。

### 2.6 ★お気に入り・よく使う商品

- ★は商品マスタの一覧と、取り込みの確認の画面で付け外しする。
- 案件で商品を選ぶ画面は「★お気に入り」→「最近使った」→「すべて（検索）」の順。種目のタブ（入浴・トイレ・歩行 など）で絞れる。
- 案件で使うたびに「よく使う回数」が増え、★の中でもよく使う順に並ぶ。
- よく一緒に出る組み合わせ（例：シャワーチェア＋浴槽手すり＋浴槽台）は「セット」として登録し、一度に入れられるようにする（住宅改修アプリの「部材＋施工費（常用）」と同じ考え方。任意）。

## 4. 金額の計算（見積書・申請書・受注簿で同じ計算を使う）

### 4.1 販売単価（2割引き）

- 販売単価（税抜）＝ 定価（税抜）×（100 − 割引率）÷ 100。**1円未満は切り捨て**。割引率の初期値は 20（＝2割引き）。
- 定価がない商品は 仕切×1.25（1円未満切り捨て。2.3）。
- 案件で販売単価を手で直したら、その単価を使う（見積書の備考に「×0.8」を付けない）。
- 利益額（販売金額 − 仕切×数量）・利益率も出し、利益がマイナスか利益率が20%より低いときは知らせる（受注簿ツールの最低利益率 20% と同じ）。

### 4.2 消費税・購入金額

- 金額（税抜）＝ 販売単価 × 数量
- 消費税 ＝ 金額 × 税率（10%・8%・非課税は0）。**1円未満は切り捨て**。商品（行）ごとに計算する（受注簿ツール・その見積書と同じ）。
- 購入金額（税込）＝ 金額 ＋ 消費税。申請書の「購入金額」はこれ。

### 4.3 介護保険の負担

- 支給の対象 ＝ 購入金額の合計 と 今年度の残りの小さい方。超えた分は全額自己負担。限度額は1年間（4月〜翌年3月）で10万円。
- 今年度の残りが空欄なら、10万円として計算する（ユーザーの指示「未記入の場合の保険者負担の上限は 90,000円。150,000円・1割なら自己負担 60,000円」。
  売上伝票発行依頼書のブランチ `claude/insurance-burden-limit-gjzl3v` で同じ直しが入っている。master にはまだ入っていない）。
  空欄と 0 は別：0 は「もう残っていない」（全額自己負担）。
  10万円は購入金額にかかる限度なので、保険者負担の上限は 1割で 90,000円・2割で 80,000円・3割で 70,000円になる。
- 利用者負担 ＝ 対象 × 負担割合（1・2・3割）。**1円未満は切り上げ**。
- 保険者負担 ＝ 対象 − 利用者負担（＝対象×(10−割合)÷10 の1円未満切り捨てと同じ）。利用者負担と足すと、いつも対象と同じになる。
- **計算は整数で行う**（対象×割合÷10 を切り上げ、保険者負担は引き算）。`Math.floor(対象×(1−0.3))` のように小数をかけると、
  3割のとき 1〜300,000円のうち 4,676通りで保険者負担が1円少なくなる（例：対象 90円 → 62円になる。正しくは 63円）。
- みやこ町は、品目ごとに利用者負担を切り上げて足す。保険者負担 ＝ 対象 − 利用者負担（売上伝票発行依頼書の「みやこ町」と同じ）。
- 生活保護のときは利用者のお支払い 0（受注簿ツールの「生活保護」と同じ）。負担割合の分（1割）は介護扶助になるので、保険者負担には足さない。どこへ請求するかは要確認。
- 利用者のお支払い ＝ 利用者負担 ＋ 超えた分。

### 4.4 計算の例（数字は確かめ済み。作るときはテストにする）

1. シャワーチェア 定価 32,000円（税抜）・仕切 19,200円・1割
   - 販売単価 25,600円 → 消費税 2,560円 → 購入金額 28,160円
   - 利用者負担 2,816円・保険者負担 25,344円（粗利 6,400円）
2. 浴槽台 定価 13,800円 ＋ 浴槽手すり 定価 15,800円・1割
   - 12,144円 ＋ 13,904円 ＝ 26,048円
   - 合計で計算：利用者 2,605円・保険者 23,443円
   - みやこ町（品目ごと）：利用者 1,215円＋1,391円＝2,606円・保険者 23,442円
3. 購入金額 150,000円・1割・今年度の残りが空欄（＝10万円）
   - 対象 100,000円 → 保険者 90,000円・利用者 10,000円＋超えた分 50,000円＝60,000円（ユーザーの指示の例と同じ）
4. 対象 90円・3割（小数で計算するとずれる例）
   - 利用者 27円・保険者 63円（`Math.floor(90×0.7)` だと 62円になってしまう）

## 5. 出力（転記）

### 5.1 見積書

- 見積書は申請の前（商品選びのとき）に要る。受注簿は納品のときに作るので、見積書は受注簿ツールを通さず、このアプリで作る。
  金額は同じ計算（4章）なので、あとで受注簿ツールから作った見積書とも合う。
- 形は販売受注簿作成ツールの「御見積書」に合わせる（A4・明朝・太字を使いすぎない）：
  宛名・見積番号・発行日・会社と営業所（住所・TEL・FAX・登録番号・所長・担当）・所長印／担当印・御見積金額・
  品目／数量／単価／金額／消費税・小計・備考。
- 品目の下の行：「定価32,000円（税抜）×0.8」と種目（例：入浴補助用具（入浴用いす））。
- 特定福祉用具なので、下に介護保険の内訳を足す：負担割合・購入金額（10割・税込）・利用者負担額・保険者負担額
  （受注簿ツールの「給付内訳」と同じ言葉）。受領委任払いなら「お支払いいただく金額」をはっきり出す。
- 印刷・PDF。Excel で保存したいときは住宅改修アプリの `xlsxWrite.ts` を使う。

### 5.2 申請書（様式をいただいてから仕上げる）

様式は保険者ごとに違うので、**「何を書くか（差し込み項目）」と「どこに書くか（様式の置き場所）」を分けて持つ**。
新しい保険者は「置き場所」を足すだけで増やせる。

**差し込み項目（どの様式でも同じ名前）**

| まとまり | 項目 |
|---|---|
| 利用者 | 被保険者番号・氏名・フリガナ・生年月日・住所・電話・要介護度 |
| 明細（行ごと） | 種目・細目・商品名・品番・メーカー名（製造事業者名）・販売事業者名・数量・購入金額・購入日・TAIS |
| 合計 | 購入金額の合計・保険給付額（保険者負担）・利用者負担額 |
| 販売事業者 | 太陽シルバーサービス株式会社 ○○営業所・所在地・電話・代表者（所長）・事業所番号・担当（福祉用具専門相談員） |
| 申請 | 申請日・支払方法（受領委任払い／償還払い）・購入が必要な理由 |

**様式ごとの決め（申請書の定義）の例**（置き場所は様式を見てから決める）

```
保険者: 行橋市
様式: 行橋市の福祉用具購入費支給申請書（Excel・シート「申請書」）
置き場所:
  被保険者番号 → C5（1文字ずつのマスなら C5〜L5 に1字ずつ）
  明細1：種目 → B20、商品名 → D20、製造事業者名及び販売事業者名 → H20、購入金額 → L20、購入日 → N20
  明細は3行まで（4行目からは別紙）
書き方:
  商品名 ＝「{商品名} {品番}」
  製造事業者名及び販売事業者名 ＝「{メーカー名}／{販売事業者名}」
  種目 ＝「{種目}（{細目}）」
  日付 ＝ 令和の年月日
```

- 様式が **Excel** のとき：いただいた .xlsx のセルに書き込んで、そのまま Excel を開く（罫線・文字の大きさ・印刷の設定はそのまま）。
  住宅改修アプリで予定している「申請書を作成」と同じ形。
- 様式が **PDF・紙** のとき：様式の画像を下に敷き、決めた位置（mm）に文字を置いて印刷・PDF にする。
- どちらも同じ差し込み項目を使う。欄に入りきらない長い商品名は文字を小さくする。明細が欄より多いときは別紙。

### 5.3 販売受注簿（販売受注簿作成ツールへ）

- 住宅改修アプリの「📤 販売受注簿に転記」と同じ仕組みにする：同じサイト（akamar08taiyo-bot.github.io）の

  受注簿ツールで「受注簿に入れる／入れない」を選ぶ。
- 送る内容（`kind` で住宅改修と見分ける）：

```json

  "kind": "taiyo-tokutei-order", "v": 1, "createdAt": 1792540000000,
  "customerName": "山田 花子", "furigana": "ヤマダ ハナコ", "address": "福岡県行橋市…", "tel": "",
  "sales": "久保", "supplier": "ケアマックス",
  "orderType": "給付", "burdenRatio": 1, "careInsuranceBalance": 100000,
  "smartRentaSalesCategory": "特定福祉用具",
  "insurer": "行橋市", "insuredNo": "", "payMethod": "受領委任払い",
  "items": [
    {"productName": "シャワーチェア ○○", "maker": "アロン化成", "modelNumber": "536-xxx", "tais": "",
     "category": "入浴補助用具", "subCategory": "入浴用いす",
     "quantity": 1, "unit": "台", "listPrice": 32000, "cost": 19200, "taxType": "10%",
     "discountRate": 20, "saleUnitPrice": 25600, "color": "", "size": "", "note": ""}

```

- 受注簿ツール（taiyo-hacchu-scan の `src/main.jsx`）で直すこと。住宅改修の受け取り口（`jutaku-import-begin`〜`end`）の隣に同じ形で作る：
  - `kind: 'taiyo-tokutei-order'` も読む。**今は知らない kind を黙って消す**ので、先に受け取る側を直して公開してから、こちらから送る。
  - 1点1ページ。受注区分「給付」・給付割合・介護保険の残り・SMARTれん太の販売分類「特定福祉用具」・税区分・販売単価を入れる。

データの形（案）：

```ts
type TaxType = '10%' | '8%' | '非課税';

/** 商品マスタの1件（仕切り一覧表から取り込む） */
type Product = {
  id: string;
  name: string; maker: string; code: string; tais: string;
  category: string; subCategory: string; categoryByHand: boolean; // 手で直した種目は取り込みで上書きしない
  listPrice: number; cost: number; // 税抜。分からなければ 0
  taxType: TaxType; unit: string; supplier: string; color: string; size: string;
  favorite: boolean; useCount: number; lastUsedAt: number;
  source: {file: string; row: number; importedAt: number};
  updatedAt: number;
};

/** 案件の明細（選んだときの商品マスタの値を書き写す） */
type SaleItem = Omit<Product, 'id' | 'favorite' | 'useCount' | 'lastUsedAt' | 'source' | 'updatedAt' | 'categoryByHand'> & {
  id: string; productId: string | null; qty: number;
  discountRate: number;      // 20 ＝ 2割引き
  unitPrice: number | null;  // 販売単価を手で直したとき。null なら計算
};

/** 案件（お客様1件） */
type Sale = {
  id: string;
  customer: string; furigana: string; insuredNo: string; birthDate: string; address: string; tel: string; careLevel: string;
  insurer: string; burdenRatio: 1 | 2 | 3; payMethod: '受領委任払い' | '償還払い'; remaining: number | null; welfare: boolean;
  staff: string; careOffice: string; careManager: string;
  estimateDate: string; applyDate: string; approveDate: string; deliveryDate: string; collectDate: string; // 納品日＝購入日
  reason: string; note: string; status: '見積' | '申請' | '承認' | '納品' | '集金';
  items: SaleItem[];
  createdAt: number; updatedAt: number;
};

/** 保険者ごとの決まり */
type InsurerRule = {
  key: string; label: string;            // 'miyako' / 'みやこ町'
  burdenRounding: 'total' | 'perItem';   // みやこ町は perItem
  forms: FormDef[];                      // 申請書の様式（受領委任払い用・償還払い用 など）
};

/** 申請書の様式1つ（5.2 の「様式ごとの決め」をデータにしたもの） */
type FormDef = {
  id: string;                            // 'yukuhashi-juryo'
  title: string;                         // 様式の名前（いただいた様式のとおり）
  payMethod?: '受領委任払い' | '償還払い';
  kind: 'xlsx' | 'overlay';              // Excel に書く／画像の上に文字を置く
  template: string;                      // 様式のファイル（Excel・画像。端末の IndexedDB に保存）
  sheet?: string;                        // Excel のシート名
  maxItems: number;                      // 明細の行数（超えたら別紙）
  fields: FormField[];
};

type FormField = {
  key: string;                           // 差し込み項目：'customer.insuredNo' / 'item.category' / 'item.name' / 'item.maker' /
                                         // 'dealer.name' / 'item.amount' / 'item.purchaseDate' / 'total.amount' / 'apply.date' など
  at: string | {x: number; y: number; w?: number}; // Excel はセル（'C5'）、画像は mm
  step?: number;                         // 明細の2行目以降：Excel は何行下、画像は何 mm 下
  format?: string;                       // '{category}（{subCategory}）'・'{maker}／{dealer}' など
  chars?: string[];                      // 1文字ずつのマス（被保険者番号など）：['C5','D5',…]
  date?: 'reiwa' | 'ymd';                // 令和7年10月20日／2025/10/20
  shrink?: boolean;                      // 入りきらないときは文字を小さく
};
```

申請書の Excel への書き込み（`xlsxFill.ts`）の考え方：
- いただいた .xlsx を開き（fflate）、決めたセルだけ値を書き換えて、ほかの部分（罫線・結合・文字の大きさ・印刷の設定・画像）は一切さわらない。
- 文字は `inlineStr` で書く。金額は数字で書く（様式の「#,##0」などの表示がそのまま効く）。セルの書式（`s`）は残す。
- 様式に式があれば、開いたときに計算し直すようにする（`fullCalcOnLoad`）。結合したセルは左上のセルに書く。
- 住宅改修アプリの「申請書を作成」（これから）も同じ仕組みで作れるので、共通の部品にする。

## 8. あとでいただきたいもの・決めること

1. **申請書の様式**（保険者ごと：行橋市・苅田町・みやこ町・広域連合、ほかにもあれば）。Excel があれば Excel、なければ PDF。記入済みの例があれば、どの欄に何をどう書くかが分かる。
2. 申請書のどの欄を会社が書くか（利用者・ケアマネが書く欄は空けておく）。受領委任払い用か、償還払い用か（両方か）。
3. 「販売事業者名」の書き方（例：太陽シルバーサービス株式会社 行橋営業所）、事業所番号、代表者名。
4. **仕切り一覧表の見本**（どこの表か：ケアマックス・ウェルファン・メーカー）。価格表はリポジトリに入れず、テストには自分で作った見本を使う。
5. 金額の決まりの確かめ：
   - 2割引き ＝ 定価（税抜）×0.8・1円未満切り捨て でよいか
   - 定価がない商品は 仕切×1.25 でよいか
   - 非課税の商品（身体障害者用物品に当たるもの）の扱い
   - 生活保護のときの扱い
