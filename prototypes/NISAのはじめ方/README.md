# NISAのはじめ方（動画の最後で配る3つの無料特典）

「おかねの地図」のサイトに足す、入口ページと3つの特典のページです。

| 特典 | ページ | 中身 |
|---|---|---|
| 入口 | `start.html` | 特典1〜3を上にぎゅっと並べ、すぐ下で、おすすめ順の証券会社から申し込めるページ（わからない人は3つの質問で選べる） |
| 特典1 | `goal.html`（`goal.js`） | 未来が見える 資産シミュレーター。目標の金額 → 毎月の積立額 → 期間のつまみ、の順に入れると、元本と投資で増えた分の推移がグラフでその場で変わる |
| 特典2 | 動画（完成・サイトにはまだ）・PDF `downloads/NISA-complete-guide.pdf`・Web `guide.html` | ゼロからわかる NISA完全攻略ガイド。解説の動画と、PDF「NISAはじめての完全ガイド」（45ページ。サイトにもとからあるもの）のセット |
| 特典3 | `choose.html`・`support.html`・動画 `videos/` | 30秒で選べる 証券会社診断。3つの質問で証券会社を決めて、申し込みを12のステップで最後まで案内する。口座の作り方（申し込み方法）の動画もつける。会社名（入口の一覧・診断の結果・紹介している証券会社の表）を押しても、その会社のページが開く |

2026年10月6日に、特典1を「毎月いくら？逆算アプリ」から「資産推移アプリ」に作り直し、特典1と特典2の順番を入れ替えました（前は 1＝ガイド、2＝逆算アプリ）。

### 特典の動画の方針（2026年10月7日）

特典の動画は、別のセッション「ショート動画作成」で作って YouTube・Instagram に投稿した動画と、その投稿文（目次・申し込み先のリンク・PR表記）を合わせて、そのまま特典にする。

- 特典2「ゼロからわかる NISA完全攻略ガイド」：「動画で見る」「資料で見る」の2つのボタンから選ぶ。資料は PDF（45ページ）。
  - 動画は3章（第1章 しくみと準備 10分17秒・第2章 何を、いくら買う？ 9分23秒・第3章 続け方・守り方・使い方 12分42秒。720×1280、各29〜30MB）。「ショート動画作成」のセッションで作ったものを、2026年10月7日にユーザーから受け取った。
  - 「動画で見る」（入口の特典2・特典の一覧）を押すと、ページの上に再生画面が開く（`video.js`・見た目は `video.css`）。下の章ボタンで切り替え、1章が終わると次の章へ進む。
  - 動画の一覧は `gift-videos.js`。サイトには `videos/nisa_ch1_720.mp4`・`nisa_ch2_720.mp4`・`nisa_ch3_720.mp4`（届いた3本をそのままの名前で）と表紙の `videos/nisa_ch1〜3.jpg` を置く。動画をやめるときは `build_pages.py` の `GUIDE_VIDEO` を False にする（「準備中」に戻る）。
  - プレビューは1ファイル15MBまでなので、`guide_split.py` で1章を3つに分け（作り直さずにキーフレームの所で。声の途切れている所を選ぶ）、`gift-videos.preview.js`（`build_all.py` がプレビューにだけ `gift-videos.js` として置く）で続けて再生する。
  - 動画の中の題は、まだ前の名前（「NISA はじめての完全ガイド」）のまま。
- 特典3「30秒で選べる 証券会社診断」：3つの質問の診断 ＋ 証券会社ごとの「口座の作り方」の動画。今は 楽天証券編（6分23秒）・SBI証券編（6分15秒）・三菱UFJ eスマート証券編（6分）を `videos/` に置き、`broker-config.js` のその会社の `video`・`videoPoster` に入れている。動画のある会社は、次の3か所に「口座の作り方を動画で見る」が出る。
  - 入口の「おすすめの証券会社」のその会社の欄（動画のある会社が1つでもあれば、特典3の下に「口座の作り方の動画（会社ごと）」も出る）
  - 3つの質問の診断の結果（「動画のとおりに進めるだけ」の枠。サイトに置いた動画ファイルならその場で再生、YouTube なら新しいタブで開く。動画ができていてまだ URL がない会社は `videoSoon: true` で「準備中」と出す。診断の結果からは「申し込みを最後まで一緒に進める」のボタンを外し、動画で見せる形にした）
  - 申し込みサポートのいちばん上
  - 入口の会社の欄と申し込みサポートでは、押すとページの上に再生画面が開く（`video.js`。閉じると止まる）。YouTube の URL のときは新しいタブで開く。
- `video` が空のあいだは、どこにも出さない。入れたら `python3 build_all.py …` で作り直す。
- サイト用の3本は、「お金のしくみ 動画一覧」の `videos/koza_1〜3.mp4`（576×1024・約290kbps・13〜14MB）から、YouTube向けの「口座を開くページは、概要欄のリンクから」の場面（3〜4秒）だけを `koza_cut.py` で抜いたもの。抜く場面の手前のキーフレームまでは元の映像をそのまま使い、後ろの数秒だけを元と同じ設定で作り直してつなぐので、画質は元と変わらない。最後の「これで完了！」の場面は残している。
  - 作り直すとき：`python3 koza_cut.py 元のフォルダ 書き出すフォルダ`（元のフォルダに `videos/koza_1〜3.mp4` と `posters/koza_1〜3.jpg`）。できた `videos/` をサイトにそのまま置く。
  - 動画ファイルは大きいので、リポジトリには入れていない（サイト用zipには入っている）。

2026年10月6日に、離脱を減らすため短くしました。

- 上から：見出し → 小さな「このページはPRを含みます。」の1行 → 特典1〜3（1行ずつの説明。特典2は「Webで読む」も）→ 口座の申し込み → 注意書き。元本割れの注意は、どのページにもあるフッターに入っているので、本文には書かない。
- 証券会社診断（choose.html）：上の大きな見出しと説明文はなくし、PRの1行のすぐ下から1つ目の質問が始まる（見出しは読み上げ用にだけ残す）。診断の結果と表の並びの決め方は、下の「紹介している証券会社」の表のところに書く。
- 広告の表示（3ページとも）：「このページはPRを含みます。」の小さな1行。小さくしても、ページの上・ふつうに読める文字の色・「PR」という言葉は残す。気づけないほど小さくしたり、背景にまぎれる色にしたりすると、ステマ規制で「表示していない」と同じ扱いになり、ASPや証券会社との提携が切られることもある。
- 口座の申し込み：「NISA口座の申し込みは、スマホで約10分」の見出しのすぐ下に、おすすめの証券会社を並べる。
  - 上から3社を出し、残りは「ほかの◯社も見る」の中。「申し込む」を押すと、その会社の申し込みページが新しいタブで開く（`applyUrl` があれば広告リンクと「PR」、なければ公式サイト）。一覧は `start.js` が `broker-config.js` の並び順で作る。
  - 一覧の下に、小さなタブ「どの証券口座がおすすめかわからない場合」。開くと3つの質問（カード・買い物・大事にしたいこと）が始まり、合いそうな会社と申し込みボタンが出る（中身は `choose.js` を同じページで使う。特典3の行を押しても、このタブが開く）。
  - 押した会社・診断の結果は覚えておき、「手順を見ながら申し込む」（`support.html`）を開くと、その会社のチェックリストになる。
  - 「10分」は申し込みにかかる時間。口座ができるのは審査のあと（数日）なので、「10分で開設」とは書かない。

## 証券会社の並び順（単価・おすすめ順）

`broker-config.js` の並び順が、入口の「おすすめの証券会社」の順番になる（証券会社診断で点数が同じときも、上の会社を出す）。2026年10月6日に、口座開設のアフィリエイト報酬の単価が高い順に並べた。

| 順 | 証券会社 | 口座開設1件の報酬（目安） | 提携できるASP（目安） |
|---|---|---|---|
| 1 | 三菱UFJ eスマート証券 | 約3,000円 | アクセストレード |
| 2 | 松井証券 | 約1,000円 | A8.net・アクセストレード・JANet・TCS |
| 3 | 楽天証券 | 500円 | 楽天証券のアフィリエイトプログラム（ASP経由） |
| 4 | SBI証券 | 約300円 | アクセストレードのみ |
| 5 | マネックス証券 | 約300円 | アクセストレードのみ |
| 6 | PayPay証券 | 提携できる案件が見つからない | ― |
| 7 | tsumiki証券 | 提携できる案件が見つからない | ― |

- 単価は、Webの公開情報（各社のアフィリエイトの案内・ASPの特集・ブログの記事）で調べた目安。単価や成果の条件（申し込みだけか、入金・取引までか）は変わるので、ASPの管理画面で確かめてから並びを入れ替える。
- 収益は「単価 × 申し込む人の数」。楽天証券・SBI証券は申し込む人が多いので、単価が低くても収益が上になることがある。数か月ためして、ASPの成果を見て並びを見直す。
- 並びに広告の条件を使っているので、ページに「並びは、広告の条件や使いやすさなどをもとに、このサイトが決めています。」と出している（ステマ規制・景品表示法のため、決め方を隠さない）。

## 未来が見える 資産シミュレーター（goal.html）

- ページはアプリから始まる（上の見出しと説明文はなくし、見出しは読み上げ用にだけ残している）。
- 入れるもの：①目標の金額（1,000万・2,000万・3,000万円のボタンつき）、②毎月の積立額（1・3・5・10万円）、③今の年齢、はじめにあるお金（スタート時の元金・すでにNISAで投資している金額。どちらも0円から。空にしても0円）、④何歳まで積み立てるか（つまみ。右の端は80歳で、期間は10〜60年の間）、増える割合（年3・5・7%）。「増える割合を自分で入れる」で、割合を細かく入れられる。
- はじめにあるお金（2026年10月6日に追加）：スタート時の元金と、すでにNISAで投資している金額を足した額から増えていく計算（どちらも元本）。入れたときは、元本の行が「自分で入れた元本」になり、「はじめの150万円 ＋ 毎月の積立1,080万円」と内わけを出す。グラフの0年のところに点と金額を出す。
  - NISAの枠：すでにNISAで投資している金額も、元本1,800万円の枠に数える。こえるときは、何歳ごろに枠がいっぱいになるかを出す。スタート時の元金は、NISAでまとめて入れられるのが1年に240万円（成長投資枠）、毎月の積立とあわせて年360万円までなので、こえるときは注意を出す（そのときは「NISAなら税金がかからない」の文は出さない）。
  - はじめるのが5年おそい場合：すでにNISAで投資している分はそのまま増え続け、おくれるのはスタート時の元金と毎月の積立として計算する。
- 年齢から計算：表示は「65歳（30年後）」「61歳ごろ（26年8か月後）に届く」のように年齢を先に出す。年齢を変えても「何歳まで」は保つ（例：70歳までにしてから年齢を40歳にすると、30年に変わる）。
- 出るもの：期間の終わりの資産、その内訳（投資で増えた分・自分で積み立てた元本）、目標までの進み具合と届く時期。届かないときは「その期間で届かせるなら毎月いくら」と、その額にするボタン。
- グラフ：元本（青 #2a7aa8）と増えた分（橙 #ca743a）を重ねた面グラフ。目標は点線。つまみの中心とグラフの年の位置がぴったり重なるように、つまみの幅（28px）から位置を計算している。グラフを横になぞっても期間を変えられる。指のときは、横に10px以上はっきり動かしたときだけ変わる（ふれただけ・縦のスクロールでは変えない。スクロールのたびに期間が動いてしまわないように）。マウスは、押した所の年になる。
- 入れた数字・「何歳まで」・くらべる線は、そのタブを開いているあいだ覚えておく（sessionStorage）。読み込み直しても元に戻らない。新しく開いたときは、最初の数字から。
- その下：NISAなら増えた分に税金がかからないこと（ふつうの口座なら約20.315%）、はじめるのが5年おそい場合との差、NISAの枠（年360万円・元本1,800万円）をこえるときの注意、5年ごとの表。
- 金額を決める手がかり：FIREに必要な金額（`goal.html#fire`）、いまの家計から毎月いくら回せるか（`goal.html#budget`）。出た金額は、ボタンでそのまま上のアプリに入る。
- 見える化（2026年10月6日に追加）：
  - 「今から育つ様子を再生」ボタン：つまみが今（0年）から自動で進み、目標に届いた瞬間に「到達！」が出る。ゆっくり見せるため、1年あたり0.4秒（30年なら約12秒。5〜16秒の間）。動きを減らす設定の人には、5年ずつ進める。
  - チェックポイント：100万・500万・1,000万円…に届く時期をグラフの点と一覧で出し、「最初の1,000万円は17年6か月、次の1,000万円は9年2か月」のように、あとになるほど早く増えることを見せる。
  - 置きかえ：毎月の積立額を「1日あたり約◯円」、増えた分を「生活費（月20万円）の約◯年分」に。
  - 積み木：1個100万円（金額に合わせて10万〜5億円）のブロックで、元本（青）と増えた分（橙）の数をくらべる。
  - くらべる：「毎月あと1万円」の線か「年3%〜7%」の幅を、ボタンで1つだけ重ねる。値はグラフの上の文でも出す。
- 計算：毎月の積立は月末、増える割合は毎月の複利（年5%なら毎月5÷12%）。税金・手数料・物価は入れていない。入力した数字は端末の外に送らない。

## 作り直し方

1. 文と並びを変えるときは `build_pages.py`、動きは `goal.js` などの JS、見た目は `start.css` を直す。ヘッダーとフッターは、サイトの既存ページから抜き出した `_header.html`・`_footer.html`。
2. `python3 build_all.py サイトのフォルダ プレビューのフォルダ` で、4ページを書き出し、JS・CSS を写す。サイトのフォルダは、サイト一式（`okane-no-chizu-website-v26.zip` を展開したもの。動画は `okane-no-chizu-videos-1.zip`・`-2.zip` を同じ所に展開し、特典2の動画3本を `videos/` に置く）。プレビューのフォルダには、プレビュー専用の `preview.css`・`preview.js` を足したページができる（実際のサイトには入れない）。
3. サイトに上げるのは、サイトのフォルダの中身（zip に入っている一式）。
