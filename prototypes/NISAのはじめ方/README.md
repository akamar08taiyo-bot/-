# NISAのはじめ方（動画の最後で配る3つの無料特典）

「おかねの地図」のサイトに足す、入口ページと3つの特典のページです。

| 特典 | ページ | 中身 |
|---|---|---|
| 入口 | `start.html` | 3つの特典を、おすすめの順に並べたページ |
| 特典1 | `goal.html`（`goal.js`） | 資産推移アプリ。目標の金額 → 毎月の積立額 → 期間のつまみ、の順に入れると、元本と投資で増えた分の推移がグラフでその場で変わる |
| 特典2 | PDF `downloads/NISA-complete-guide.pdf`・Web `guide.html` | NISAはじめての完全ガイド（NISAのはじめ方。サイトにもとからあるもの） |
| 特典3 | `choose.html`・`support.html` | 3つの質問で証券会社を決めて、申し込みを12のステップで最後まで案内する |

2026年10月6日に、特典1を「毎月いくら？逆算アプリ」から「資産推移アプリ」に作り直し、特典1と特典2の順番を入れ替えました（前は 1＝ガイド、2＝逆算アプリ）。

## 資産推移アプリ（goal.html）

- 入れるもの：①目標の金額（1,000万・2,000万・3,000万円のボタンつき）、②毎月の積立額（1・3・5・10万円）、③投資する期間（1〜40年のつまみ）、増える割合（年3・5・7%）。くわしく設定するで、今ある資産・年齢・割合を細かく入れられる。
- 出るもの：期間の終わりの資産、その内訳（投資で増えた分・自分で積み立てた元本）、目標までの進み具合と届く時期。届かないときは「その期間で届かせるなら毎月いくら」と、その額にするボタン。
- グラフ：元本（青 #2a7aa8）と増えた分（橙 #ca743a）を重ねた面グラフ。目標は点線。つまみの中心とグラフの年の位置がぴったり重なるように、つまみの幅（28px）から位置を計算している。グラフを横になぞっても期間を変えられる（縦のスクロールはそのまま）。
- その下：NISAなら増えた分に税金がかからないこと（ふつうの口座なら約20.315%）、はじめるのが5年おそい場合との差、NISAの枠（年360万円・元本1,800万円）をこえるときの注意、5年ごとの表。
- 金額を決める手がかり：FIREに必要な金額（`goal.html#fire`）、いまの家計から毎月いくら回せるか（`goal.html#budget`）。出た金額は、ボタンでそのまま上のアプリに入る。
- 計算：毎月の積立は月末、増える割合は毎月の複利（年5%なら毎月5÷12%）。税金・手数料・物価は入れていない。入力した数字は端末の外に送らない。

## 作り直し方

1. 文と並びを変えるときは `build_pages.py`、動きは `goal.js` などの JS、見た目は `start.css` を直す。ヘッダーとフッターは、サイトの既存ページから抜き出した `_header.html`・`_footer.html`。
2. `python3 build_all.py サイトのフォルダ プレビューのフォルダ` で、4ページを書き出し、JS・CSS を写す。サイトのフォルダは、サイト一式（`okane-no-chizu-website-v5.zip` を展開したもの）。プレビューのフォルダには、プレビュー専用の `preview.css`・`preview.js` を足したページができる（実際のサイトには入れない）。
3. サイトに上げるのは、サイトのフォルダの中身（zip に入っている一式）。
