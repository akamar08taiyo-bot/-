# 制度ガイドの動画の台本（16本）

ショートの5本を、無料プレゼントのページ（入口の「動画で見る」）で流す動画として作り直すための台本です（2026年10月5日）。

| ファイル | 中身 |
|---|---|
| `gift_eps.py` | 16本の台本データ（配役・字幕・場面・読み・足したポイント・注意・出典）。1行30字以内かを `check()` で確かめる |
| `add_gift.py` | 台本帳の `reports/偉人編 損する制度シリーズ.plans.json` に「制度ガイドの動画」の節を足し、`reports/制度ガイドの動画 台本.md` を書く（何度実行しても同じ） |
| `regen_book.py` | 台本帳のページ（https://claude.ai/artifact/393v7w1BTGuUvnP3rHmDCV）を plans.json から作り直す。これまで手で直した言い方（場面・演出、制作セッション、約○秒など）もあてる |

台本を直すとき：`gift_eps.py` を直す → `python3 add_gift.py` → `python3 regen_book.py 出力.html` → 台本帳を公開し直す。
