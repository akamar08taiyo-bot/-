# 分析レポート：「AIで蘇らせた」系動画

調査日：2026-10-10。方法：Gemini による動画そのものの解析（YouTube URL を直接読ませる）＋ Google 検索。

## 0. 結論（要点）
1. **再生数を取っているのは「古い写真が、色づいて、動き出す」型**。Unknown World の上位3本（約210万・44万・33万回）はすべてこの型。
2. 型の中身はほぼ固定：**白黒（またはセピア）の古写真 2〜3秒 → カラー化 3秒 → 人物が瞬き・笑う・手を振る 6秒**＝1カット約12秒 × 14〜18カット ＝ **約3分半**。字幕は**左下に「題材／年」を日英併記**。ナレーションなし、静かなピアノ（＋笑い声の効果音）。
3. 冒頭3秒で「変化（白黒→カラー→動く）」を見せ、**何が起きる動画かを一瞬で分からせる**のが最大のフック。
4. 「懐かしさ」で見せる物語型（参考動画＝1986年の夏、約28万回）はアニメ調で、**話の筋と環境音**で引きつける。同じチャンネルの写実系モンタージュ「1990年の日本」（約7万回）は**話の筋がなく、題材が地味**で伸びが小さい。
5. → v2 は **「写実（フィルム写真風）」×「物語」×「写真が動き出す」演出** を組み合わせる。1997年の“プリント写真”から場面が色づいて動き出す、を章の入口ごとに使う。

## 3. 「蘇らせた」型の分解
| 要素 | 上位作の共通点 | 理由（推測） |
|---|---|---|
| 冒頭 | 0:00 白黒写真 → 0:03 カラー化 → 0:08 笑う | 変化を最初に見せる＝離脱を防ぐ |
| リズム | 1カット11〜12秒で完全に一定 | 見方が分かると安心して見続けられる |
| 動き | 画像→動画AI（瞬き・視線・笑み・手を振る・歩く）。カメラはほぼ固定 | 「生きていた人」と感じる決め手は**人物の小さな動き** |
| 字幕 | 左下に「題材／年」日英併記 | 何を見ているか分かる＋海外視聴者 |
| 音 | 静かなピアノ＋（人物に合わせた）笑い声。ナレーションなし | 説明しない余白 |
| 締め | カメラに向かって歩き手を振る少女 | 余韻と温かさ |
| 弱点 | 同じ演出の繰り返しで中盤がマンネリ／汎用の笑い声SE／手指の崩れ | 物語や変化をはさむと改善できる |

## 4. 視聴者が反応するポイント（コメント傾向）
- 「教科書の写真が生身の人間として笑いかけてくる」驚き
- 「存在しないのに、なぜか懐かしい」「タイムスリップしたみたい」
- 家族への共感（「ひいおばあちゃんもこんな世界で生きてたのか」）
- 地元・ゆかりの場所の今昔
- 懸念：「存在しない記憶」「歴史の捏造」→ 作り手は概要欄に「記録映像ではなくAIによる再現」と明記している

## 5. v2 への反映
| 学び | v2 での使い方 |
|---|---|
| 「写真が動き出す」が最大のフック | 冒頭で**1997年のプリント写真（色あせ・オレンジの日付）→ 色が戻り → 場面が動き出す**。章の入口（朝・午後・夜・晩夏・別れ）でも同じ演出をくり返す |
| 写実の質感 | 画像を**90年代の35mmカラーネガ（フィルム写真）風の写実**に作り直す。2026年の場面はデジタル写真風で対比 |
| 人物の小さな動き | Veo 3.1 Lite（画像→動画、1080p 8秒で約$0.64）を試す。子どもが写るカットは制限（大人のみ）で動かせない可能性 → 試験して判断。だめならカメラ移動＋光・風・雨の動きで補う |
| 字幕 | 章の入口に「1997年7月 海辺の町」などの小さな表記（日英） |
| 題名の型 | 「29年前の平成の夏休みをAIで蘇らせた｜1997年、電池の夏」 |
| 固定コメント | 制作意図＋「あなたの1997年の夏は？」の問いかけ |
| マンネリ対策 | 物語（友情・初恋・別れ）と季節の変化で単調さを避ける |
| 誠実さ | 概要欄に「実在の記録ではなく、AIで作った再現・フィクション」と明記。写実的なAI映像なので YouTube の「改変・合成コンテンツ」の申告をオンにする |
