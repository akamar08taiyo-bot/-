## 3. 音の検査
| 項目 | 結果 |
|---|---|
| 合成した環境音・効果音の聞こえ方 | スペクトログラムで確認（セミの帯域4〜8kHzとパルス、ひぐらし約4.5kHzの断続、雨の広帯域ノイズ、チャイムの音程、モーターのドップラーなど）。※AIによる「何の音に聞こえるか」の目隠しテストは、クレジット切れで未実施 |
| 「夕焼け小焼け」の旋律 | 3つの資料の階名（ソソソラ ソソソミ ドドレミレー…）と照合して入力。前半2フレーズを使用 |
| 落ち着き（急な大音量） | 修正前は4か所（タイトル直前、5:34の曲の盛り上がり、余韻パート8:40・8:48）＋5時のチャイムが全編で最大（-9 LUFS）→ チャイムを5dB下げ、3秒窓でゆっくり効く平準化（大きい所は差の半分だけ下げる）を入れ、タイトルの曲を1.2秒前から重ねた。修正後は冒頭のフェードインのみ |
| 余韻パート | アンビエントピアノの低音が強く音量の上下が±12dBあった → 低音を弱め、ゆるいコンプで±7dB程度に |
| 小さな修正 | 時計の秒針が目立つ → 6dB下げて音色を丸く／缶のふたの音を4dB下げる |
| セリフ | Gemini TTS の3本（ハルト10歳・ユウスケ・大人のハルト）。指示文を読み上げてしまう不具合をテスト時に発見 → 英語の構造化プロンプトで解決し、文字起こしで「台本どおりの言葉だけ」と確認済み |
