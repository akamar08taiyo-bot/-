作り直すとき

台本を直す: video/scripts/keiba-ocean-s.json の文言と dur（秒）を書き換えるだけ。シーンの種類は intro / horse / reason / punch / cta。

別のレースを作る: 同じJSONをコピーして、レース名・馬番・馬名・理由を差し替え。npm run render:all で全部まとめて書き出します。

cd video npm install node render.mjs --script scripts/keiba-ocean-s.json --landscape # 縦型と横型を書き出し node render.mjs --script scripts/keiba-ocean-s.json --preview 7,12,26 # 静止画だけ確認（数秒）

ナレーションを載せる場合: --no-audio で書き出して、SRTを読み上げ原稿にして収録 → 音声に合わせて各シーンの dur を微調整。
