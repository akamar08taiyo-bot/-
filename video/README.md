# 日本×世界 データ比較ショート動画

台本集「日本×世界 データ比較ショート動画 台本集」の6本を、そのまま投稿できる
縦型ショート動画（1080×1920 / 9:16）として書き出すレンダラーです。

## 成果物

`video/out/` に6本のMP4を書き出します。

| ID | 内容 | 尺 |
|---|---|---|
| `01_sleep` | 世界の睡眠時間のリアル | 29.5秒 |
| `02_income` | 世界の年収のリアル | 29.5秒 |
| `03_worktime` | 世界の労働時間のリアル | 29.5秒 |
| `04_commute_world` | 世界の通勤時間のリアル（国際比較） | 22.6秒 |
| `05_commute_japan` | 47都道府県 通勤・通学ランキング | 27.2秒 |
| `06_bigmac` | 世界のビッグマック価格 | 29.5秒 |

仕様: H.264 / yuv420p / 30fps / 1080×1920 / 無音AACトラック付き（SNS側の処理系対策）。

## 台本集の共通仕様との対応

| 台本集の指定 | 実装 |
|---|---|
| 解像度・比率 1080×1920（9:16） | 固定 |
| セーフゾーン 下250px・右端120px | テロップ・パネルをすべてこの外側に配置（下端の描画は y=1650 まで、右端は x=950 まで） |
| 15〜30秒の3ゾーン構成 | フック2.4秒＋3ゾーン＋クロージング3.2秒。最長29.5秒 |
| ゾーンごとに演出を変える | ゾーンごとにアクセント色・背景グロー・チャントを変更（短い/安い=シアン、普通=アンバー、長い/高い=ローズ） |
| 極太ゴシック＋太縁取り・画面中央に大きく | Noto Sans CJK JP **Black** ＋ stroke 6〜11px |
| 音源やアフレコに口パクを合わせる | 動画は無音。ナレーション・BGMは編集ソフト側で重ねる想定（下記） |
| 調査年が異なる場合の注記 | 各動画のフッターに出典と注記を常時表示 |

## 使い方

```bash
pip install Pillow imageio-ffmpeg
sudo apt-get install -y fonts-noto-cjk fonts-noto-cjk-extra   # 極太ゴシック

python3 render_shorts.py                   # 6本すべて
python3 render_shorts.py 01_sleep          # 1本だけ
python3 render_shorts.py --overlay         # 背景透過の合成用（WebM / VP9 alpha）
python3 render_shorts.py --fps 60 --out /path/to/dir
```

`--overlay` は背景を透明にしたWebMを書き出します。台本集にある
「背景は無地かグリーンバック合成」の運用で、自分で撮った実写の上にデータ部分だけを
重ねたいときに使います（Premiere / DaVinci / CapCut などにそのまま読み込めます）。

## 投稿時の仕上げ

動画自体は無音です。台本集の演出（「短い、短い、短い！」の掛け声、ゾーンごとの動き）は
撮影・アフレコ側の担当なので、投稿前に次を足してください。

- ナレーションまたはBGM（TikTokは音源、YouTube Shortsは規約上使える音源を選ぶ）
- TikTok：ハッシュタグ3〜5個
- YouTube Shorts：タイトルに `#Shorts` を含める

## データの出どころ

数値・国名・出典・注記はすべて台本集からの転記で、`scripts_data.py` に集約しています。
このリポジトリ側で新しい数値を作ったり、出典を推定で補ったりはしていません。
数値を直す場合は `scripts_data.py` だけを編集して再実行してください。

各行の3要素は `(表示名, 棒グラフ用の数値, 補足ラベル)` です。棒グラフの長さは
台本ごとの `bar_min` / `bar_max` で正規化しており、差が見えるようにゼロ基点では
ない台本があります（睡眠時間・労働時間・都道府県通勤）。
