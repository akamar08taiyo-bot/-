# 日本×世界 データ比較ショート動画

台本集「日本×世界 データ比較ショート動画 台本集」の6本を、そのまま投稿できる
縦型ショート動画（1080×1920 / 9:16）として書き出すレンダラーです。

## 構成（視聴維持率のための作り）

日本（＝答え）がすぐ出てしまうと最後まで見る理由がなくなるので、カウントダウン形式にして
答えを最後まで伏せています。

1. **フック（2.5秒）** 答えを言わず問いかけるだけ。「日本は何位だと思う？」「答えは最後に発表」
2. **カウントダウン** 各行に残り番号（15→1）。1が来るまで終わらないと画面から分かる
3. **伏せ札** 最後の「1」＝日本の行は `？？？` のまま置いておく（台本⑤は全国最長の県）
4. **常時ティザー** 画面上部に「日本は ？？？」を最後まで出し続ける
5. **進捗バー** 残りの量を見せて「あと少し」を可視化
6. **答え合わせ（2.2秒）** 「答えは…」→フラッシュ→伏せ札をその場でめくる
7. **クロージング（3秒）** 順位・出典・次への誘導

**6本とも、カウントダウンの「1」が日本になるようそろえています。** 日本は必ず最後の1行なので、
最後まで見ないと答えが分かりません。画面上部に「1に出てくるのが日本」と明示して、
最後まで見る理由を先に渡しています。

そろえ方は `zone_order` と、答えの行をゾーン末尾へ回す処理の2段構えです。

| 台本 | ゾーンの表示順 | 最後の「1」 |
|---|---|---|
| ① 睡眠 | 長い → 普通 → 短い | 日本 |
| ② 年収 | 安い → 高い → 普通 | 日本 |
| ③ 労働時間 | 長い → 短い → 普通 | 日本 |
| ④ 通勤（国際） | 短い → 長い → 普通 | 日本 |
| ⑤ 都道府県 | 短い → 普通 → 長い | 神奈川県 |
| ⑥ ビッグマック | 高い → 普通 → 安い | 日本 |

日本が中位にいる台本（②③④）は、両極のゾーンを先に見せてから日本のいる「普通」ゾーンで
締める形になります。台本集のゾーンの中身は変えていません。

ネタバレ防止のため、フックのティザーと常時表示の注記からは順位を外してあります
（順位は答え合わせとクロージングでのみ出します）。

カウントダウンの数字は「この動画で紹介する15か国」の中の通し番号で、世界順位ではありません。
誤読されないよう、画面上部に「全15か国カウントダウン｜1に出てくるのが日本」と明示しています。
実際の順位（33か国中 最下位 など）は台本集の記載どおり答え合わせで出します。

`video/out/` に6本のMP4と、各本のサムネイル `*_cover.png`（1080×1920）を書き出します。
投稿用のタイトル・キャプション・ハッシュタグ案は `posting_kit.md` にまとめてあります。

| ID | 内容 | 尺 |
|---|---|---|

| `02_income` | 世界の年収のリアル | 28.3秒 |
| `03_worktime` | 世界の労働時間のリアル | 28.3秒 |
| `04_commute_world` | 世界の通勤時間のリアル（国際比較） | 22.2秒 |

## 台本集の共通仕様との対応

| 台本集の指定 | 実装 |
|---|---|
| 解像度・比率 1080×1920（9:16） | 固定 |
| セーフゾーン 下250px・右端120px | テロップ・パネルをすべてこの外側に配置（下端の描画は y=1650 まで、右端は x=950 まで） |
| 15〜30秒の3ゾーン構成 | フック2.5秒＋3ゾーン＋答え合わせ2.2秒＋クロージング3秒。最長28.3秒 |
| ゾーンごとに演出を変える | ゾーンごとにアクセント色・背景グロー・チャントを変更（短い/安い=シアン、普通=アンバー、長い/高い=ローズ） |
| 極太ゴシック＋太縁取り・画面中央に大きく | Noto Sans CJK JP **Black** ＋ stroke 6〜11px |
| 音源やアフレコに口パクを合わせる | 動画は無音。ナレーション・BGMは編集ソフト側で重ねる想定（下記） |
| 調査年が異なる場合の注記 | 各動画のフッターに出典と注記を常時表示 |

## 使い方

```bash
pip install Pillow imageio-ffmpeg
sudo apt-get install -y fonts-noto-cjk fonts-noto-cjk-extra   # 極太ゴシック

python3 render_shorts.py                   # 6本すべて
python3 render_shorts.py 01_sleep          # 1本だけ
python3 render_shorts.py --cover           # サムネイルPNGだけ書き出す
python3 render_shorts.py --overlay         # 背景透過の合成用（MOV / QuickTime Animation）
python3 render_shorts.py --fps 60 --out /path/to/dir
```

`--overlay` は背景を透明にしたMOV（QuickTime Animation / RLE・可逆）を書き出します。
台本集にある「背景は無地かグリーンバック合成」の運用で、自分で撮った実写の上に
データ部分だけを重ねたいときに使います（Premiere / DaVinci / CapCut などにそのまま
読み込めます）。可逆圧縮なので20秒強で約28MBと大きく、Gitには含めていません。

> アルファ付きWebM（VP9）も試しましたが、同梱ffmpegのlibvpxではアルファプレーンが
> 落ちて不透明になったため採用していません。

## 投稿時の仕上げ

動画自体は無音です。台本集の演出（「短い、短い、短い！」の掛け声、ゾーンごとの動き）は
撮影・アフレコ側の担当なので、投稿前に次を足してください。

- ナレーションまたはBGM（TikTokは音源、YouTube Shortsは規約上使える音源を選ぶ）
- TikTok：ハッシュタグ3〜5個
- YouTube Shorts：タイトルに `#Shorts` を含める

## データの出どころ

数値・国名・出典・注記はすべて台本集からの転記で、`scripts_data.py` に集約しています。
このリポジトリ側で新しい数値を作ったり、出典を推定で補ったりはしていません。
数値を直す場合は `scripts_data.py` だけを編集して再実行してください。

各行の3要素は `(表示名, 棒グラフ用の数値, 補足ラベル)` です。カウントダウン演出の設定は `zone_order` / `countdown_reverse` / `countdown_label` / `answer_name` / `teaser_label` / `count_noun` で台本ごとに指定します。答えがカウント1に来ていない場合は書き出し時に落ちるようにしてあります。棒グラフの長さは
台本ごとの `bar_min` / `bar_max` で正規化しており、差が見えるようにゼロ基点では
ない台本があります（睡眠時間・労働時間・都道府県通勤）。
