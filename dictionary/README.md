# 福祉用具 ユーザー辞書（Google日本語入力用）

福祉用具貸与の計画書・記録で使う定型文（選定理由・留意事項・担当者会議・モニタリング・相談記録）を、
Google日本語入力のユーザー辞書として登録できる形に1つにまとめたものです。

| ファイル | 内容 |
| --- | --- |
| `ユーザー辞書_統合版_公開用.xlsx` | 一覧で確認するためのExcel（辞書一覧／よみ早見表／変更履歴／使い方・ルール） |
| `ユーザー辞書_統合版_公開用.txt` | 辞書ツールで取り込むファイル（UTF-8・タブ区切り：よみ／登録する言葉／品詞／コメント） |

## 公開用について

このリポジトリは公開されているため、人名・住所・メールアドレス・社内関係者名など個人情報を含む登録（69件）は除いています（616件）。
全件版（685件）はリポジトリには置いていません。

## 追加した文

元の辞書を整理したうえで、次の文を新しく追加しています（Excelの「辞書一覧」の備考欄に「追加」と表示）。

- 選定理由・留意事項：各用具に3件ずつ
- 担当者会議：新規・中間見直し・更新・福祉用具追加・サービス内容変更・ケアプラン長期切れの各種類に3件ずつ
- モニタリング：利用目標・点検結果・身体状況・意欲・家族・サービス利用・住環境・総合評価・今後の方針などの各記入欄に3件ずつ
- 相談記録（ご本人の言葉）：3件

## 取り込み方（Google日本語入力）

1. タスクバーの「あ」（または「A」）を右クリック →「辞書ツール」を開く
2. 念のため、今の辞書を「管理」→「選択した辞書をエクスポート」でバックアップする
3. 「管理」→「新規辞書にインポート」→ `.txt` を選び、辞書名を入れて「インポート」
4. 古い辞書（統合前のもの）は「管理」→「選択した辞書を削除」で削除する（残すと候補が二重に出ます）

## よみのルール

| 種類 | よみ | 例 |
| --- | --- | --- |
| 選定理由 | 用具名＋「せ」 | てすりせ／しゃわーちぇあせ／べっどせ（提案の文は てすりていあん） |
| 留意事項 | 用具名＋「りゅ」 | てすりりゅ／しゃわーちぇありゅ／べっどりゅ（福祉用具全般の共通の文は りゅうい） |
| 担当者会議 | 種類＋「たんかい」 | しんきたんかい／ちゅうかんたんかい／こうしんたんかい／ついかたんかい／へんこうたんかい／ちょうきたんかい |
| モニタリング | 記入欄ごと | りもく／てんけん／しなし／いなし／かなし／さなし／じゅうかんきょう／ひょうか／てきぎ／こんけい／しんきのうひん／ついかのうひん |
| 相談記録 | そうだんきろく | ご本人の言葉 |

事業所名・定型文などのよみは統合前と同じです。使わなくなった旧よみと新しいよみの対応は、Excelの「よみ早見表」にあります。

## 文章のルール（誰から誰への文章か）

- **選定理由**：担当者（福祉用具専門相談員）が、ご本人・ご家族・ケアマネジャーに選定の理由を説明する文。「〜のため、〇〇を選定しました。」にそろえています。
- **留意事項**：用具の点検（ロックピン・ゴムの摩耗・固定の緩みなど）はモニタリング時に担当者が行います。ご本人・ご家族にお願いするのは「使うときの注意」と「ぐらつき等の異常を感じたら担当者へ連絡」です。すべての文の先頭に（手すり）（シャワーチェア）（床ずれ防止用具）のように用具名を付けています（共通の文は（福祉用具全般））。
- **担当者会議・モニタリング**：担当者が記録・報告する文（です・ます調）。「更新担当者会議。〜」で始まる短い文は、である調のメモ用です。
- **相談記録**：ご本人が担当者に話した言葉として、へりくだり過ぎない自然な話し言葉にしています。

## 100文字のルール

Google日本語入力は1語あたり最大300バイト（全角100文字）までです。すべての登録を100文字以内にしています。
Excelの「文字数」「判定」列は自動計算なので、文章を書き換えたときも100文字を超えていないか確認できます。
